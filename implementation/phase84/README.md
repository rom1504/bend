## Completed initial screens

Each experiment has a checked B1 build and36 frontend cases, then two rotated
fresh-request rounds on Numeric, Map, Functions65 and Small. All48 C outputs
match the previous per-role outputs exactly. Explicit Base preparation and
imports remain separate from request clocks. These are screens, not confidence
intervals or a new qualified upstream ratio.

## Correctness evidence and failures

- Fusion compares complete annotated definitions and complete NR_Request values
  on all four sources, including the private cache and runtime closure order.
  All match the original producer; final C is exact too.
- Report reuse passes17 focused cases:13 full old/new report comparisons, three
  direct false-readiness fallbacks, two explicit-API comparisons, unsafe imports,
  cycles, type/field references, law fills, freshening and parse/check refusals.
- compiler02 failed checking because a local Con lacked its List annotation.
  compiler03 fixes it; the failure is retained.
- report-controls01 contained a malformed test (Type where a Data field was
  required). report-controls-v2 fixes the fixture, preserving the original.

## Next bounded discriminator

Test a stronger refusal shortcut at the actual non-tail binding boundary,
requiring an exact self-call and absence of a product route. Avoid constructing
the continuation before the inevitable refusal. This is a narrower mechanism
than classifying arbitrary recursion syntactically. Root runs all targets
serially on CPU3 with the existing resource limits; agents inspect source and
prepare patches/controls only.

No generated-program change, installed release, full conformance improvement,
or qualification is claimed. Earlier Phase82 ratios remain1.673× B1/1.328× B2
upstream for the qualified three-source compilation workload.
