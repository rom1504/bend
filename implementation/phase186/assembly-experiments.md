# Phase186 assembly experiments

The first ten-case assembly screen reduced geometric-mean runtime by **19.63%** against the retained Phase185 final N2 products. Local-fold improved **33.45%**, local-pair **27.99%**, and all ten selected cases improved. Candidate assembly remained **4.163× C** geometrically on this screen. These are three serial rotated rounds with exact output/count oracles, not a full45 result, a significance claim, or an attribution to individual passes. Exact inputs, ratios and instruction lists are in [first-screen-analysis.json](first-screen-analysis.json); [the analysis](first-screen-analysis.md) records the measurement limits.

The initial assembly bundle combines the following general transformations with the shared inline-F32 effect summary and selective callee saves:

| Mechanism | Admission and semantic boundary |
|---|---|
| Scratch forwarding | An unrelated fixed Alloca preserves other buffer facts; redefining a buffer or captured source kills dependent facts. Exact inline F32 kills destination-dependent facts; unknown calls retain their barrier. |
| Private memory removal | Scan setup and every branch for bounded reads and escaping addresses. Remove only stores to globally unread cells and allocations with no reads or escape. Four-byte cells preserve overlapping U32/U64 observations. Unknown aliases and calls retain affected buffers. Setup is unchanged; combined setup/body size must be below 4096. |
| Again parallel moves | Schedule at most 64 full-word assignments by physical home. Remove self moves and write a destination only after pending reads of that home are consumed. Cycles, malformed homes and oversized vectors discard the entire plan and retain the original snapshot path. |
| Existing cleanup | Run dead assignment removal after private memory removal, then place registers using the complete setup/body frame. No ownership operation, heap access or runtime fallback is removed by these rules. |

The measured local-fold positive iteration shrank from **123 to 80 static instructions**. Its 17 scratch address LEAs, six indirect scratch loads and eleven indirect scratch stores disappeared. Explicit frame references fell from 29 to 12; direct frame loads/stores remained 8/4. The native array load/store remained 1/1, with no calls on this path. These counts support the mechanism without proving its isolated timing contribution.

The later candidate adds bounded pure expression reuse in `expression-reuse.bend`: at most 16 expression facts and 16 copy aliases, with the same strict 4096-statement admission. Original copies retain their snapshot semantics; local writes invalidate dependent operands, results and aliases. Stores, calls and control edges reset facts; loads invalidate their destination. Bin keys include exact operand type, operation and full-word values. Comparison copies produce U32. Offset declarations remain intact because replacing one with a pointer copy would lose verifier capacity metadata; only their value equivalence informs later keys. The integration runs private removal, expression reuse, stable copy cleanup and dead assignment removal before placement.

Direct physical Set/Load selection and the existing binary selector for Offset addition remove additional scratch-register copies. U32 self-copies still clear the upper word; memory addresses are captured before destination writes, including unsigned offsets above INT32_MAX. Stack destinations retain the earlier paths. This record assigns no timing result to these later changes or expression reuse.

[Fourth checked API acquisition](../../selfhost/build/phase186/fourth-api01/report.json) completed. [Fourth controls](../../selfhost/build/phase186/fourth-controls01/report.json) passed arguments, expression, inline, callee, private and parallel groups. Private controls cover overlap, setup/branch/address escape and unknown-call mutation; parallel controls cover cycles, discarded scheduled prefixes, fanout, mixed homes, 100001 iterations and setup snapshots. Expression controls include 17 structural rows and 2160 machine invocations with 8064 exact product words, mutation, shifts, comparison widths, pointer bounds and canaries. Isolated opcode36 stubs test routing/clobbers, not runtime sqrt semantics. These finite controls and independent source reviews do not replace broad conformance or native qualification.

An unhooked branch-entry forwarding prototype was not selected, measured or retained. Inspection found no tuple-buffer fallback observer in local-fold's hot body: the entry fallback receives original parameters and the cold loop arm calls the error helper. After private memory removal, sinking those tuple stores into fallback arms offered no demonstrated remaining fold benefit. The actual remaining loop instead showed duplicate address expressions, Boolean materialization and scalar copies. The speculative `branch-forward.bend` file was removed; this finding is its experiment record.

All compiler, target and measurement jobs were run by the root execution lane. This record was written from retained artifacts and source inspection, with no new jobs.
