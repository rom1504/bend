# Independent controls for text split/join fusion

These are newly authored semantic fixtures for the Phase200 rewrite. They are not compiler acceptance or target-execution results. No compiler, Lean process, machine program or benchmark was run while preparing them; no commits were made. `manifest.json` explicitly records `checked:false` and `executed:false` for every source.

The historical Phase200 source adapter recognized two exact known Unicode benchmark sites. These fixtures use independent `frame.*` names and an unrelated packet-framing application. A general matcher must prove structure and semantics; failing to recognize a renamed but equivalent source is a coverage limitation, while accepting a semantic near miss is a correctness failure. The fixtures do not require blanket rejection of an entire program when a smaller pure region is safe to transform.

| Sources | Purpose | Expected admission |
|---|---|---|
| `packet-{baseline,onepass,distributed}.bend` | Independently authored record-separator framing, dynamic function size and word parameters, four ordinary invocations | Baseline and both manual rewrites produce identical complete sequences. Repeat distribution requires invariant delimiter, replacement and block. |
| `word-boundaries-{baseline,onepass}.bend` | Empty input, leading/trailing/consecutive delimiters, empty replacement and replacement containing delimiter; NUL, surrogate words, maximum Unicode scalar, words above Unicode and `0xffffffff` | All exact U32 word comparisons, no UTF-8 normalization or validity assumption. |
| `alias-{baseline,onepass}.bend` | Shared input printed before transformation and again afterward | Pure fusion allowed, but neither alias may be mutated, consumed prematurely or replaced by the transformed value. |
| `observed-parts.bend` | Counts the five chunks before joining `,a,,b,` | Single-use producer elimination must refuse. A compiler may retain the split/count and independently optimize another use if separately proved. |
| `drop-empty-nearmiss.bend` | Removes empty chunks before join | Cannot replace this pipeline by ordinary character substitution: output is `a\|b`, not `\|a\|\|b\|`. |
| `varying-separator.bend` | Separator depends on each repetition counter | Local join/split fusion is sound; replace-once followed by repetition is not. |
| `effect-boundary.bend` | Three effectful block acquisitions before the pure consumer | May fuse the pure consumer after IO. Must preserve exactly three `read` lines in order; cannot hoist or deduplicate acquisition. |

The packet workload uses ASCII record separator 30, includes NUL and unit separator 31, and substitutes a multiword string which itself contains the delimiter. It repeats complete blocks and serializes every output character word. Its four points are `(count,word) = (0,0), (1,30), (3,0x10ffff), (7,0xffffffff)`. This differs from the original comma/pipe Unicode fixture. No performance-transfer claim follows from the fixture's existence, and these finite points are not a replacement for the generic sequence theorem.

`build-fixtures.py` is a metadata/source materializer. Its oracle is an independent forward list-of-integer scanner followed by an imperative chunk join, rather than the Bend code's right-recursive splitter or replacement. The expected files include IO.print's implicit newline. `frame.words` emits decimal ASCII for each raw U32 value, avoiding the runtime's Unicode encoding policy when testing arbitrary character words. The alias/negative expected values also have directly inspectable short full sequences; no digest hides a mismatch.

Before physical use, run the ordinary independent zero-hole source check on every chosen source. Retain any refusal before correcting it. Then compare complete stdout from the original compiler and mature C against each `.stdout`, including all effects. Compile the same baseline source with the candidate matcher and independently compare against its manual onepass/distributed sibling. Record whether the intended rule actually fired; equal outputs alone do not establish activation. For a negative, inspect the relevant rewritten IR or machine region rather than inferring refusal from unchanged timing. A shared input's output equality is necessary but does not replace ownership/lifetime validation.

The completed Phase200 list law remains separate at `research/phase200/text-laws/`: replacement over split/join and concatenation/repetition. It proves neither matching, ownership lowering nor machine execution for these new sources.

## Guarded native runner (prepared, unexecuted)

`run.py` is catalog independent. It accepts `--baseline` and `--candidate` compressed native compiler images and verifies their decompressed ELF hashes against supplied/sibling `results.json` receipts. Compiler executables live in memfds. The exact retained native command supplies ABI11102, the private Base cache and cache identity; their byte identities and the GCC linker are independently checked against the retained ABI receipt. Each new top-level application object is linked against the same explicitly pinned runtime, then executed through the normal single-threaded native RTS entry.

For each role, input and spelling, the runner retains source, compiler/linker/execution argv, complete stdout/stderr, exit status, wall interval, object and ELF hashes. It rejects any stdout mismatch, stderr, timeout or nonzero exit. These per-command durations are operational diagnostics, not performance measurements. The output directory must be fresh. The outer guard restricts CPU3, disk, memory, wall time and the standard available-space floor, and seals failed as well as successful jobs.

`--reprint-scon` creates an additional source spelling which replaces quoted literals with explicit `SCon{Chr{word},...}` and `SNil{}`. It leaves comments alone, rejects unsupported literal escapes instead of guessing, retains each reprinted source, and checks exactly the same complete oracle. This is an independent spelling/admission control, not claimed compiler equivalence before execution.

`--upstream auto|required|off` optionally runs the installed pinned upstream CLI. Its IO path checks the book and rejects unresolved holes, then executes generated JS through `Comp.io_run`; it is **not** a pure term interpreter. This independent backend runs the same top-level `main`. These fixtures use only `IO.print`, `IO.pure`, `IO.bind`/do notation. All exist in the retained Base; print appends one newline, already accounted for in `.stdout`. The effect test uses three explicit prints and pure return, not a filesystem, clock, network or unsupported custom provider. Raw boundary words are observed through ASCII rendering before printing, so native/JS Unicode encoders cannot obscure them.

`--apps additional.json` accepts further arbitrary source/expected products using the same `fixtures` schema; paths are relative to that manifest. `--cases` bounds a scheduled job. `argv-template.json` gives a proposed first four-control guard with explicit image/runtime placeholders. It is a template, not an executable claim; the parent supplies exact frozen paths/hashes and schedules it. No runner or guard has been dispatched by this agent.

## Independent character-escape homomorphism

`escape-{baseline,distributed}.bend` adds a separate application: an audit-wire encoder for NUL, LF, quote and backslash. `wire.prefix` performs a four-way word pattern match and emits two fixed literal SCon cells for escaped characters, or the original cell otherwise. `wire.escape` recurses once on the tail and passes the result as the continuation. The encoder contains no split, join, delimiter parameter, captured replacement string or String.append. This is structurally distinct from the first split/join rule.

The baseline computes `wire.escape(frame.repeat(n,block))`; the manual distributed sibling computes `frame.repeat(n,wire.escape(block))`. A general rule would need to certify that every helper branch emits a fixed pure prefix, forwards the continuation exactly once at the end, performs no effect or mutable read, and does not depend on position/history. The suffix case must be empty. It cannot recognize the name `wire.escape` or rely on these test values.

Both sources expose `bench(size,seed)` which consumes the full encoded result into a rolling U32 hash, suitable for a later scheduled timing harness without printing the full text in its timed kernel. Their ordinary `main` additionally serializes every word and prints the independent digest at 0,1,5,64 blocks. `escape-points.json` records those oracle values. Distribution reduces encoder calls from proportional to repetitions times block length to one block; repeat construction and final consumption remain. No measured gain is claimed. `build-escape.py` materializes these two fixtures after `build-fixtures.py` and updates the manifest to 13 sources.
