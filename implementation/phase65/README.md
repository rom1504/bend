The [Base census](base-products.md) identifies repeated annotation work on Map;
[the transport contract](cache-contract.md) keeps semantic production and
admission in Bend. The candidate retains only definitions with at least **64
body terms**, a generic work threshold. Its optional sidecar contains 12 Base
products: 437,464 product bytes and 520 key bytes. Seven Map annotations qualify;
Numeric and Lexer have no hits in the initial census. Instrumented avoided-work
and warmed materialization figures are not clean request savings.

State08 has the four private product APIs and 99 exports. It retains world3;
the rejected constructor-index/world change is excluded. The owned successful
prepared-world route, exact source/API/Base/ABI and parent graph identities are
required. Stops take priority, and missing, malformed, stale or ineligible
products preserve ordinary annotation. Header/key selection precedes heavy
product reading, so a no-hit request must not decode that body.

The compiler semantic gate must prove complete annotation/output equality,
actual cached-object activation on Map and no heavy reads on Numeric/Lexer,
plus stop/admission/collision and injected-API fallbacks. The transport gate
checks the actual writer/reader and malformed inputs. A separate latency-method
successor pins the sidecar and directory inventory for every worker, including
no-hit requests. These gates and net whole-request time remain pending; the
strict build alone does not qualify the feature.
