# Canonical source identity outside x86

The five non-x86 profiles assemble to byte-identical source **and source maps**
against HEAD `f31d219e260daccb81a12430f40483ee09ae6f4e` (the Phase193 design
checkpoint, before the compiler changes). This is an offline source transport
result; no compiler, Bend/Bun, generated target or checker was executed.

| Profile | Source bytes | Declaration entries | Source/map equal |
|---|---:|---:|---|
| js-api | 3,213,640 | 8,577 | yes / yes |
| native-c | 3,213,858 | 8,578 | yes / yes |
| qbe | 3,213,774 | 8,578 | yes / yes |
| qbe-policy | 3,213,773 | 8,578 | yes / yes |
| qbe-policy-test | 3,213,746 | 8,578 | yes / yes |

All 225 canonical modules and 8,578 canonical declaration entries retain exact
bytes and order. All 112 protected declarations retain exact bytes and their
manifest-pinned normalized hashes: 101 verifier declarations and 11 proof
declarations. The protected declaration metadata is itself unchanged.

Across canonical and profile source inputs, the only changed existing module
is `src/back/x86/program.bend`; the only added profile module is
`src/back/x86/public-composition.bend`. No tracked diff exists in
`bend2/bend.ts` or `selfhost/src/runtime` against the same baseline. These
observations establish unchanged source boundaries, not new proof strength.

The durable [receipt](profile-source-audit.json) records all five exact source
and map hashes, protected entries, input hashes and inventory. The retained
run is `selfhost/build/phase193/profile-source-audit02`, including exact old
and current manifests. Reproduce using the maintained source assembler:

```
python3 selfhost/tests/phase193/profile-source-audit-v2.py \
  --baseline f31d219e260daccb81a12430f40483ee09ae6f4e \
  --out selfhost/build/phase193/profile-source-audit-FRESH
```

The script reads baseline blobs through `git cat-file`, copies them into a
temporary confined overlay, invokes only `source.py`'s metadata assembler,
compares complete generated bytes/maps in memory, and checks current inputs
again before completing. No maintained source is rewritten.

The initial script attempted to share identical modules using symlinks; the
maintained assembler correctly rejected those as paths escaping its root.
The [initial refusal](profile-source-audit-initial-refusal.json), original
script and run01 manifests remain preserved. V2 copies the authenticated
baseline bytes inside the temporary root instead. The confinement check was
not disabled or bypassed. Both runs, scripts and durable receipts total
2,343,917 bytes before this short note, below the 20 MiB requested bound.
