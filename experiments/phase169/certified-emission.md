# Restore source-authorized renderer capabilities

The experimental fast route discarded an existing semantic capability at its
render boundary. `p169s_seeded` chose mode0/1 from function-list emptiness, while
the maintained `p134e_admitted` also carries the actual checked request's array
certificate into mode2. This is a general missing compiler capability, not a
special case for editdist. The [independent product audit](editdist-quality-audit.md)
identifies missing array templates and separate missing local composition.

The frozen six-family screen in
`selfhost/build/phase169/program-screen-timing01/report.json` is a correctness
pass but a performance rejection: editdist is19.192×, raytrace1.566×,
lexer1.250× and tree-bitonic1.141× the Phase152 reference. RLE is0.983× and
Map0.863×; the six-case geometric mean is1.820×. These measured generated-program
ratios are distinct from the faster complete compiler-build observations.

## Single optional treatment

[`certified-emission.bend`](../../selfhost/tests/phase169/certified-emission.bend)
overrides only the experimental `p169s_lowered` boundary. It retains actual
generic/static/adapter validation, the private-function obligation, the complete
borrowed/direct verifier on the actual public view, and the existing failure
rerun that preserves original diagnostic priority. The immutable request derives
`p113a_certificate` unchanged: `ns_definitions` and guarded `nr_unshared`.

For an enabled certificate, the actual final program passes the unchanged
`p113a_verify_after` and `p114t_verify_done` namespace obligations. Only then does
render preparation select mode2 and call `p117p_tables`, keeping storage ABI and
template selection together. The import-seeded registry, forwarding and streaming
cursor stay unchanged. A false certificate calls the exact original
`p169s_seeded`; an empty direct-function list keeps mode0. No caller can force a
certificate through the native entry.

This treatment neither restores cold-constructor facts nor changes inlining.
The [cold audit](constructor-cold-audit.md) explains their independent authority.
The full canonical compiler has File effects and its mature capability word is5;
its current array permission is false. Therefore the desired result for that
input is unchanged QBE, not a new specialized compiler-runtime claim. The extra
certificate computation itself still needs cost measurement if integrated.

## Fast gate and preserved attempts

The source-only preparer
[`prepare-certified-emission-v2.py`](tools/prepare-certified-emission-v2.py)
reuses the authenticated v5 preparation and performs one metadata extraction.
It renames the old experimental entry into a fresh input copy, adds this one
replacement and preserves all original source files. The inverse rename is
checked. It does not emit JS, QBE or machine code.

The first checked API attempt failed on an inherited finite fixture's untyped
String literal, before any semantic or performance claim. API01 and its methods
remain unchanged. The fresh protocol fixture v3 adds explicit `NR_Request` and
`String` local annotations; inverse comparison proves there is no other edit.
All active new control modules were scanned for untyped literal-bound locals.
