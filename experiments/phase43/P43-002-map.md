behind repeated descriptor/dependency checks. A single guarded fresh scalar
component should isolate guard amortization; direct paired-child graph workers
may then remove the dominant remaining matcher/build control.

this owner. Root serializes execution under memory bounds. Native String/proof
obligations were coordinated with the String owner; no active proof or wider

or whole does not improve enough over amortized to justify compiler/source cost.

is a hypothesis, not an estimated measured gain.
