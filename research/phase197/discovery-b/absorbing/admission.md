# Bounded admission for a decreasing tail loop

Apply the transformation to structured direct-worker IR after existing local copy/dead-value simplification and before register allocation. The x86 path's `x185_function_copied` receives parameters, one-time setup and the body with `P113DIf`, `P113DAgain` and `P113DResult` still distinguished. The source representation is in [model.bend](../../../../selfhost/src/back/qbe/model.bend) and this join is in [function.bend](../../../../selfhost/src/back/x86/function.bend). Checking at this level can preserve the parallel snapshot semantics of `Again` without proving register assignments.

## Minimum rule

1. Identify a loop parameter F and a dominating exact comparison testing F against zero at its declared word width. Establish that the selected edge is reachable only when F is positive in the unsigned domain. The next F must be exactly F−1 at that same width, with no other carried value derived from F or the predecessor count. In particular, refuse a predicate that also tests F against another threshold, passes its value into the live state, or publishes it before returning to the header.
2. Trace one path from the positive edge to its unique tail backedge. For a first implementation, admit only local copies, constants, integer equality and fixed-width bit extraction, a statically certified branch, and the single decrement. Prove every RHS refers to its reaching definition. Reject calls, IO, heap or frame reads/writes, allocation, take, keep/sink, checked operations that might trap, foreign effects and another loop edge on the trace. Materialization of private spill slots occurs later in register allocation. Keep the first absorbing step in place, including canonicalization.
3. Let S denote all carried parameters except F. The old stable step produces S′. Prove the same path is selected on S′ for **every** remaining positive F and that it produces exactly S′ again. The smallest useful certificate permits each carried word to be its corresponding incoming parameter or a constant, and evaluates guard expressions on the resulting state. Check complete backedge arity, types and order. Disallow unknown predicate inputs, redefinitions after the guard, permutation cycles, nontrivial duplicated owned values, changing keys/paths, or any dependency on previous non-parameter locals. The old machine's repeated path reads only F and parameters/proven definitions. Setup must execute once.
4. On the certified branch insert an `Again` with the *original next-state expressions* and F replaced by zero. Keep the old shared `Again` available to all other branches. Every RHS is evaluated in the old environment before any rebinding. The next header runs the original zero-fuel arm exactly once. That arm may observe zero, the stable state, or the result buffer because each receives the value it would receive after natural exhaustion. Apply this last statement only after checking its live-in set; a non-parameter scratch local read before definition across iterations must force refusal. In the narrowest implementation, require the entire base arm to be a `P113DResult` of carried parameters/constants. Directly jumping to the existing return block is a later selection optimization.

For a remaining count r, r=0 takes the existing base edge. If r>0, one pure application of the invariant step yields the same stable state and r−1. Ordinary induction proves equality of the final state at zero. The guard establishes positive unsigned input before every subtraction, including at the largest representable input. No wraparound argument for negative values or decrement by a larger constant is implied.

## Refusal controls

| Mutation of an admitted positive example | Required outcome |
|---|---|
| Zero initial fuel plus a raw matching tag carrying noncanonical bits | Original zero branch returns all input bits unchanged |
| Constant canonical leaf substituted in the carried position | Successful first step still performs canonicalization |
| Next tag differs from tested tag, or bit-extraction width differs | Refuse; next iteration may take another path |
| Guard or next path uses F, remaining F−1, or another changing counter | Refuse |
| Step copies from a different nonconstant parameter, rotates or increments another argument | Refuse |
| Reference-count operation, allocation, runtime failure or store anywhere on the repeated path | Refuse |
| Base arm reads a nonparameter carried scratch, or Again passes arguments in a different order | Refuse |
| Different result arity, extra edge, aliasing write, conflicting definition or unresolved constructor identity | Refuse |
| Another arm allocates or calls and the selected arm is fully isolated | Other arm retains its exact code and behavior |

A second guarded capture finished in **14.712 s**. The copied hosted API records the input to `x185_function_copied` and continues normal compilation. [Selected typed nodes](typed-witness.json) · [Full typed trees, re-rooted source, stage and guard receipts](typed-capture02.tar.gz)

The evidence identifies an actual cross-join obligation in the BST product worker. After the outer U64 fuel comparison against zero, its zero arm directly returns two parameters. Its nonzero branch contains the complementary comparison against zero, the exact subtract-one, a fixed frame declaration, shift-right 40, AND 65535, and equality against an `N111CtorId`. The matching arm assigns a constant to one local and copies the incoming path to another. A **single shared `P113DAgain` after the join** reads those two branch-defined locals, the decreased fuel and the incoming key. The other arm assigns the same two destinations after executing ownership operations. The sibling direct BST worker calls a separately emitted step and lacks a pure local positive path.

A production rule therefore needs to resolve the constructor ID through the actual `N111Ids` map, check the canonical literal's tag, and prove the two reaching definitions and all backedge parameters *on this predecessor*. It must also treat the U64 countdown's two guards coherently. The captured `N111Alloca` declares a statically assigned x86 frame field; x181_scalar emits no instruction for the node. The narrow rule could explicitly permit only that compile-time declaration after checking names and excluding any address use on the absorbing path. A blanket permission for allocations would be incorrect. Existing per-function use counts and adjacent comparison certificates do not establish this cross-join invariant. Preserving the join for its effectful sibling and rechecking allocation/stores on the rewritten branch needs independent finite refusal controls. We deferred the Bend implementation at that boundary.

The re-rooted text-search case is a concrete refusal. Its `$direct.occurs.go` is a public state-machine segment with **zero `P113DAgain` nodes**. It takes apart two product nodes, and its False path reconstructs two pairs with `p125_rt_ctor2` before a runtime transfer. There are two runtime jump sites in the function. The narrow local rule cannot admit this worker. This experiment demonstrated the source-level transfer pattern and the current compiler boundary; the separately compiled BST32 and BST64 remain the measured positive cases.
