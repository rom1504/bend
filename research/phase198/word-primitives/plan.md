# Recover primitive semantics before allocating a register

The dynamic observer measured 344,460 calls to U32.from_nat at one private nearest-surface site in raytrace. A second site called it another 9,024 times. ABI11102 implements this operation with a low-word projection. Input identity for U32.to_nat is the *full* word in this runtime. Nat subtraction saturates at zero and Nat comparison returns a numeric predicate. These operations have no allocation or state-dependent effect on verified arguments. Nat addition and multiplication have separate overflow behavior and remain on their checked path.

Test two stages. First, substitute already-established immutable scratch-cell values for primitive arguments while the verified direct IR still records the argument identity. This lets the allocator place the actual result and avoid call-interference edges. Second, when value identity is unavailable, inline the recorded ABI operation using the original local buffer and the reserved machine scratch registers. Compute the result before storing it so destination/address aliases retain their original ordering. Keep the original arity, symbol, state, type and argument-width checks. Later shrinking of dead scratch writes is independent of this experiment.

Use the object and GNU assembly encoders on the same typed instructions and compare with an independent full-width C arithmetic oracle. Include nonzero upper words, wraps, unsigned ordering and undershoot. Compare whole-program runtime to the existing native image and mature Bend C for ray tracing, a Map workload and a control. Demonstrate activation in the authenticated emitted object. The frequency of these calls estimates their reach. It does not measure their share of execution time.
