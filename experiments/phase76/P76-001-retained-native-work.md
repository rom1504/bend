# P76-001: retained native work

Prospective hypothesis: stable native facts can remove repeated subtree analysis
and construction while emitting exactly the current C. First discriminator:
attribute current CPU samples and use bounded diagnostic images to estimate
avoidable work. Reject an expensive rewrite whose saving cannot materially
reduce whole-request time. Diagnostic results do not qualify production.

[Design](../../design/phase76/native-work-reuse.md). Results will be recorded in
[report](../../implementation/phase76/README.md), with all attempts retained.
