# Packet-window scan transfer

**The actual integrated native compiler lowered and accelerated the transfer.** On the two-segment 64-cell ring, median integrated/scalar elapsed time per packet was **0.28281** for the primary input and **0.53768** for the alternate. This corresponds to 71.72% and 46.23% less elapsed time. Every one of the eight paired observations favored the integrated program. Both programs used the same live runtime and scan support object. The candidate compiler image was `4c5ef960f02e803826801dcc47f12b1cbed2261708440a02d6707d1739cab0de`. [Raw native timings and compiler identity](evidence/transfer-native01/report.json).

All 65 observable U32 words matched the independent Python oracle at ten inputs for each of the integrated native, incumbent scalar native and separately compiled mature Bend-C programs. The mature C and existing native local-fold binaries also returned 1,660,901,827 at the newly specified alternate input. [Native complete-state outputs](evidence/transfer-native01/integrated-checks.json) and [mature C and original-input controls](evidence/transfer-base03/report.json).

The candidate's renamed 511-byte worker contains a relocation to `p199_rt_u32_scan4`. Separate execution counting recorded both real calls at each timed point. On the primary input both masks were 63. The first call used fuel 6,147 at timestamp UINT32_MAX and changed carry 3,079,795,678 to 1,704,506,432. The second used fuel 1,232 at timestamp 3,989,547,403 and returned 157,497,327. The workload validates a second use of the same arithmetic recurrence in a program with different ring size, data distribution, segment ordering and observable output. [Selected worker](evidence/transfer-native01/integrated-worker.json) and [primary call trace](evidence/transfer-native01/counter-6147.json).

The frozen program integrates two segments of timestamped U32 samples into a circular telemetry window. The first segment and the resumed segment write the same 64 cells at different absolute timestamps. They share the final carry. Three seeded positions differ from the initial fill. The ordinary point wraps the U32 timestamp in the first segment, wraps the ring many times, and resumes at another offset. It uses independent names and data from the 128-cell local-fold benchmark. The per-cell contract retains the ascending ring traversal, modular addition, XOR with the full timestamp, and array-first result required by the proposed four-lane rule.

The initial source attempt ended in the pinned upstream checker before code generation. The hash and render observers tried to destructure a computed `Array.get` result. The corrected source passes each read result into the next function call and destructures that parameter. Both observers perform one extra ordinary read after the final observed cell, whose value is discarded at the zero-count exit. The scanner, ring construction, both segment calls, all 65 logical outputs and the independent oracles remain identical. [Rejected source](evidence/source01-refused.bend) and [source gate](evidence/source01-check.json).

The corrected source passed the pinned checker with zero holes and emitted the baseline direct x86 object `34372546c1b773b83d220d9f60d6e581a1c760fc4060c083c6c56b2cc24d342f` in transfer-base02. An overstrict path/digest validator then rejected an extra metadata field on the authenticated linker. The repaired driver verifies size and SHA-256 at the resolved artifact path. The baseline optimized worker is 445 bytes, identical to the original local-fold optimized body in the two relocatable objects. A second, 773-byte scalar fallback is also present. This transfer changes ring size, state, segment ordering and its externally observed result while keeping the recurrence itself.

The integrated native validation uses `sh research/phase199/scan-transfer/run-native.sh`. It compiles the validated source with the actual Phase199 native N1 image, links both candidate and retained baseline objects against the same live runtime and vector leaf, checks ten complete states per executable, and compares four balanced pairs on each of the primary and alternate inputs. It separately wraps the real vector helper to observe the two calls in a complete program, including mask, fuel, absolute timestamp and incoming/outgoing carry. The process expects 1,843 complete four-cell groups on the primary and 78 on the alternate based on the independent source counts. The independent mature Bend-C oracle can be run immediately afterward with `sh research/phase199/scan-transfer/run-c-oracle.sh`. Both wrappers take a fresh run name to reproduce their artifacts.
