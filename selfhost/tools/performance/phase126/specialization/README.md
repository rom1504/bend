# Finite scalar selector prototype

Source-only prototype; no compiler, API, target, or benchmark was executed by its author.

Compose `plan.bend`, `lower.bend`, `emit.bend`, `entry.bend`, `inlining.bend`, `render-entry.bend`, and optionally `diagnose.bend` after the selected Phase125 source. Exact existing declaration overrides are **p113pl_boxed_candidate**, **p113i_eligible**, and **p113ah_function**. The original candidate body is retained verbatim (apart from its name) as `p126s_original_candidate`. All final program verifiers and the checked-request factory remain unchanged.

The selected `render-entry.bend` makes final private-function rendering call `p126s_emit(function)` first. A nonempty result is a complete private function plus its immutable data declaration; empty means call the existing renderer unchanged. The current Phase126 typed renderer sends these non-float-formal, scratch-free functions to this same existing heap-renderer fallback. If that dispatch changes, preserve the table check before its generic renderer. Table functions have a Nat parameter, so no float-formal ABI is introduced. Rendering must remain downstream of the unchanged final verifier. `p126s_projection_control()` is a small pure projection check; `p126s_inspect(request,name)` reports rows from the actual checked request.

The source recognizer accepts unary canonical Nat-to-F32/U32 definitions with 4–64 consecutive Zero/Succ rows and a closed default leaf. It reuses the mature `j_region_nat_select` shape/type premises. It does not infer a finite input range: all values at or above the last row select the final value. Dependent/default-remainder uses, effects, owning helper arguments, higher-order helpers, unsupported primitives, non-finite F32 constants, excessive shape/depth, or a failed proof keep the previous lowering.

Constant evaluation occurs in Bend. Supported scalar operations are canonical U32-to-F32 and F32 add/subtract/multiply/divide, plus literals and bounded closed helpers with one or two canonical scalar inputs. Every helper actual is evaluated in source order before substitution, including discarded actuals. Each arithmetic step uses the language's F32 operation and checks finite output; signed zero bits are retained. The evaluator has depth 8, helper syntax cap 64, root syntax cap 4096, and at most 64 rows. These are refusal bounds, not claims that arbitrary constant evaluation is cheap. NaN payload folding, transcendental functions, float reassociation, and arithmetic strength reduction are outside this prototype.

The lowering first creates ordinary P113D full-U64 equality decisions returning exact word constants. The normal unchanged verifier therefore checks the actual candidate. The emitter independently recognizes that exact decision structure, including equal destinations, consecutive indices, immediate returns, low-32-bit results, and no intervening effects. It then clamps the full U64 input before an 8-byte-stride load from an immutable `P111QData` table derived from those same constants. No caller-supplied table certificate, C parsing, host evaluation, runtime ABI extension, or new IR constructor is used. Locals use a private function-local prefix; data symbols use the existing injective function-name encoder. Small tables below four cells stay with the existing renderer.

The optional inlining hook excludes only this exact table shape. Otherwise a small decision would be inlined into the caller before table emission, losing the opportunity. Every other inlining eligibility check is unchanged. This first version retains a direct selector call; it does not promise the upstream backend's fully inlined table load. A later first-class typed table operation could expose that without preserving the branch IR until emission.

`ordinary.bend` and its fixed 17-line oracle cover both scalar result kinds, helper arithmetic, rounding at 2^24, negative zero, full-width Nat indices 2^32/2^40, and ordinary remainder/owning/higher-order/recursive-helper fallbacks. Root should check both unchanged and candidate complete stdout, inspect admitted rows, assemble the candidate QBE, and then compare the already frozen ray workload. No performance prediction is inferred from static branch counts.

`manifest01.json` freezes the initial source modules. `emit-entry.bend` is an unused alternative at the narrower private renderer; it is not part of the selected v1 composition. `cases.json` / `ordinary.observe.json` use the existing functional observation schema; `ordinary.expected.json` explains the independent expected values.
