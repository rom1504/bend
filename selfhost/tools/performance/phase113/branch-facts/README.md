# Optional Boolean branch facts

Range19 removed all five high-tag shifts from the scalar `mit` worker but left
seven unreachable Boolean-exhaustiveness failure blocks in the generated
assembly. Their native calls force preservation of live registers even though
the input Booleans were generated by comparisons. Source inspection found two
missing facts: `(unknownConstructorId | 65536)` is nonzero, and the false arm of
`b == 1` implies `b == 0` when operations already prove `b` is either 0 or 1.

This optional extension addresses those two facts without specializing source
names or assuming source ownership kinds imply a numeric representation.

For nonexact `P113KFact`, `lo`/`hi` now mean mandatory-one masks. All recorded
values remain below the unsigned bit-width bound and contain every mandatory
one bit. Copies and width truncation preserve this invariant, joins intersect
mandatory bits, and OR unions them. Other transfers conservatively discard
mandatory bits. Zero compared with a mandatory-one value is provably unequal.

A hidden predicate record relates a comparison result to a subject whose
operation-derived range is 0..1. It records both the condition and subject write
versions. Every ordinary fact replacement increments its local version, so
rewriting either local invalidates stale relationships. Copies, OR/XOR with 0,
and XOR with 1 preserve or invert valid predicates. Joins discard relationships;
no condition is inferred across a loop backedge. Hidden keys contain `@`, which
the admitted local-identifier grammar excludes.

A branch assumption refines only a valid relation whose subject still has a
0..1 range. Calls, loads and multi-result destinations still invalidate facts
through the existing replacement helper. Runtime effects and ABI stay intact.
Original full-width unknown Terms, packed constructor words and arbitrary
U32/U64 inputs receive no Boolean assumption.

## Composition

Use these exact paths with `phase113/prepare.py` after the existing source20
scalar-facts/bottom-up composition:

- `--module selfhost/tools/performance/phase113/branch-facts/base.bend`
- `--override selfhost/tools/performance/phase113/branch-facts/known.bend`
- `--override selfhost/tools/performance/phase113/branch-facts/provenance.bend`
- `--override selfhost/tools/performance/phase113/branch-facts/walk.bend`

Place these three overrides after other scalar-facts overrides. `base.bend`
contains exact renamed copies of scalar19's three functions (binary transfer,
comparison transfer and scalar walker). The wrappers reuse their unchanged
behavior and add facts; source19 files are untouched. `manifest.json` pins each
module and source dependency. Public entry remains `p113k_optimize`; existing
pre/post structural verification and candidate rollback remain in force.

This is source prepared for checked qualification. Independent finite controls
must cover mutation of either predicate endpoint, copied/inverted predicates,
branch joins, full-width unknown values, mandatory-bit soundness and preservation
of effects. Root owns target execution and performance measurements.
