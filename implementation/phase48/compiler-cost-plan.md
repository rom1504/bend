# Selected compiler request cost

This is a small fresh-process compilation comparison against installed Phase47
array06 and pinned TypeScript, separate from generated-program runtime. Root owns
execution. No self-emission or persistent compiler service is involved.

The default is `test-rle-roundtrip,lexer`: one aggregate-transport workload and
one ordinary compiler workload. If a different mechanism is selected, replace
RLE with `test-morning-program` (finite functions), `test-evening-program`
(typed arrays), or `local-fold` (entry/Array changes). Treat lexer as an ordinary
comparison, not as proven unaffected code until its output is inspected. Three
sources are allowed when two independent changed mechanisms merit coverage.

Two sources mean18 requests; three mean27. Every source gets three rotated rounds
of TypeScript/baseline/candidate, baseline/candidate/TypeScript, then
candidate/TypeScript/baseline. The unchanged Phase30 worker includes normal
`inspect`/Base-cache handling, excludes separately performed disk-cache priming,
and checks each emitted output against an independently checked acquisition.

The [data-only method factory](../../selfhost/tools/performance/phase48/compiler-cost-method.py)
preserves the old full array06 acquisition and its emission receipts, relabels
only a new manifest's role to baseline, and copies the proven Phase47 planner.
Its runner derivative changes the dependency anchor, baseline API/runtime pins,
descriptive labels and immediate parent identity. Worker, verification, sampling,
request boundaries and resource limits remain unchanged. Existing phase labels
inside the copied planner describe inherited methodology; exact attempt/API/runtime
bindings identify this comparison. Original closed evidence is never edited.

```sh
P48_COST_CASES=test-rle-roundtrip,lexer
P48_COST_ATTEMPT=selfhost/build/phase48/checked-SELECTED
P48_COST_PREPARATION=selfhost/build/phase48/acquired-SELECTED/manifest.json
P48_COST_METHOD=selfhost/build/phase48/compiler-cost-method-SELECTED
P48_COST_PLAN=selfhost/build/phase48/compiler-cost-plan-SELECTED
P48_COST_OUT=selfhost/build/phase48/compiler-cost-SELECTED
python3 selfhost/tools/performance/phase48/compiler-cost-method.py \
  --cases "$P48_COST_CASES" --out "$P48_COST_METHOD"
python3 "$P48_COST_METHOD/planner.py" \
  "$P48_COST_ATTEMPT" "$P48_COST_PREPARATION" "$P48_COST_PLAN" \
  --baseline-attempt selfhost/build/phase47/checked-array06 \
  --baseline-preparation "$P48_COST_METHOD/baseline/manifest.json" \
  --typescript-preparation selfhost/build/phase37/typescript01/manifest.json \
  --catalog selfhost/tools/performance/phase37/catalog.json \
  --cases "$P48_COST_CASES"
python3 "$P48_COST_METHOD/runner.py" "$P48_COST_PLAN/config.json" "$P48_COST_OUT"
```

All output paths must be fresh. The selected preparation must already contain the
chosen unadapted sources from the exact selected API/runtime. Reuse the final full
acquisition when available; do not compile those sources again just to create a
new cost manifest. The factory's frozen baseline is
`selfhost/build/phase47/array06-full/manifest.json`, API
`28f9eb983b2ba3603a9af703d832d4a301efe32182b468e090db6b728a47d12f`,
runtime `880bce50e3194b9ee9d99bd57c18ef88bcb8925d9d1668dec6765040a4d3219b`.
The planner verifies both checked attempts and their existing API-specific Base
caches. Missing cache requires an independently recorded preparation job before
measurement; it is not an excuse to time the first cache-building request.

Both planner and runner already own the shared ExecutionGuard: do not wrap them
in `phase46/job.py`. They run serially on CPU3, Node24.18.0, stack4096,1GiB heap,
2GiB polled process-tree RSS ceiling and4GiB available-memory floor. Measurement
has a60-second child deadline and240-second overall deadline. Preparation is
separate: report its wall time too. No compilation, runtime measurement or archive
compression overlaps this campaign.
