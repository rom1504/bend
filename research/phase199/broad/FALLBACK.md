# Frozen timing gates and optional fallback

The preferred integrated campaign retains three timed roles and three rounds. Every one of the 45 frozen cases executes; 44 are ratio eligible. No runtime decision depends on whether a case is expected to improve or whether its object is unchanged. Source, workload, expected output, runtime arguments and original fixed-catalog weights come from the same catalog.

Before timing, native45 executes independent outputs on actual default-linked products; preparation authenticates the exact source/image/object lineage and identical original-plus-scan relinks, then checks all 135 C/incumbent/candidate outputs. Runtime input pins include the frozen manifest, method, catalog and role/product dependencies. Any changed input refuses admission. Pilots and timed samples both validate complete stdout, stderr, count and exit code. Calibration targets 140 ms, while every eligible measured interval must still reach 100 ms. Failed or short observations cannot be hidden by a successful median. Dispersion flags never remove cases.

The strict main summary requires 45 unique cases, 44 eligible cases, three rounds, balanced positions and 405 authenticated timed observations. It binds every timed ELF to the frozen prepared product. All C and incumbent values are freshly measured in that campaign; no earlier timing is substituted.

Only if the preferred campaign cannot fit, the coordinator may choose `fallback-argv.json`. This runs the same shared prepared manifest's two native roles for two balanced rounds, all45/44 eligible, 140/100 ms policy and 180 timed observations. Mature C remains independently preflight checked on all45 but is not freshly timed in this fallback. No matched candidate/C performance ratio is reported. Three timed roles cannot have equal positions within only two rounds. The fallback result is an explicitly shorter, lower-confidence native comparison, never a silent replacement for the three-role result. Cap: 150 s / 32 MiB; internal runtime deadline: 135 s.

`pack-evidence.py` copies exact receipt and output bytes into a deterministic, verified gzip archive. It requires successful closed guards for N1 acquisition, all45 construction, preparation and the chosen timing run. It preserves source, runtime bundle objects, small receipts and full pilot/timed/preflight streams. Large native images, program ELFs/objects and toolchains stay explicitly pinned external dependencies. It does not claim that this compact archive can independently rerun or reauthenticate those absent binaries.

```sh
python3 -B research/phase199/broad/pack-evidence.py \
  --summary research/phase199/broad/integrated-summary01.json \
  --out research/phase199/broad/integrated-evidence01
```

For the fallback, pass `selfhost/build/phase198/p199-integrated-pair02/summary.json` instead. Add `--placement` only when the optional placement guard has completed and closed. Outputs must be fresh. No target execution occurs during packaging.
