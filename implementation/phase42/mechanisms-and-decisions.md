This account explains the selected checked15 candidate and the experiments that
led to it. It is written while broad qualification is pending; it does not claim
installation, final catalog-wide performance, or release admission. Checkpoints
[01](checkpoint01.md), [02](checkpoint02.md), [03](checkpoint03.md),
[04](checkpoint04.md), [05](checkpoint05.md), and [06](checkpoint06.md) retain the
chronology. Machine tables [01](prototype-summary01.json),
[02](prototype-summary02.json), [03](prototype-summary03.json),
[04](prototype-summary04.json), [05](prototype-summary05.json),
[06](prototype-summary06.json), and [07](prototype-summary07.json) retain exact
screen samples, ranges and parent identities. Historical statements that a

The starting denominator is Phase41 checked01, with the unchanged pinned
TypeScript reference. Some later screens deliberately compare adjacent Phase42
images to isolate incremental changes; checked07 or checked13 must not be
relabeled Phase41. Saved JavaScript establishes a mechanism hypothesis; only
fresh checked compiler emission establishes that the source implements it.
Diagnostic counters and scopes are kept separate from clean timing modules.

## Reduce dispatch inside a proved private graph

A closed scalar entry already proves its complete original source dependency
graph and validates public bindings, metadata, captured host intrinsics and
canonical scalar arguments. Phase42 reuses that coverage inside the admitted
operation. Component-to-component edges whose exact original definitions are
covered can call existing private workers directly. Small saturated acyclic
helpers receive bounded typed direct lowering. This removes repeated public
closure dispatch and repeated dependency-proof work without caching mutable
host state across public calls. Public entry guards, generic fallback and proof
cleanup remain in place.

The initial leaf-only, leaf-plus-key, proof-only and combined saved-output roles
separated contributions. The combined role gave a material tree improvement,
then actual checked output reproduced the improvement. The three tree points
still trailed TypeScript substantially, directing the next experiments toward
representation and continuations rather than more dispatch speculation.

Helper admission has total expansion fuel and exact original graph coverage.
Partial applications, first-class values, unsupported effects and graph backedges
refuse. Annotation types remain original; rewriting only the annotation value
prevents private value-call plans from entering type applications. Covered
rewriting also preserves any original application shell containing the structural
owner's recursive reference. That restriction was necessary for correct
continuation classification, not a performance preference. See [calls](calls.md)
and [frames](frames.md).

## Eliminate private intermediate lists when scalar work is total

The fusion recognizer accepts a nested scalar use of a closed
producer/filter/map/fold chain. It verifies the exact empty/link owner, canonical
U32 fields, structural Nat predecessor, exact recursive reconstruction/selector,
and fold update in original argument positions. The total scalar whitelist is
restricted to existing native U32 arithmetic/comparisons, with existing emission
owning per-operation wrapping and modulo-zero behavior. Purity alone does not
permit this transformation: changing traversal demand can change errors or
foreign observations. Let-bound, retained, returned or shared intermediates and
unsupported scalar operations refuse.

For the accepted source form, one loop computes the producer head and next state
from the same original seed, applies the predicate and mapping, then performs the
original ordered accumulator update. The lists and extra traversals disappear.
A Number countdown is justified only by an exact native U32.to_nat operand;
this does not weaken the separate 48-bit private Nat counter guard. U32
multiplication/addition/subtraction keep their original individual wraps; no
associativity or cycle shortcut is inferred.

The direct unfused Phase41 module is the denominator. The saved-output512-point
screen motivated integration, and actual checked07 emission then passed complete
stages, values, hostile boundaries, arithmetic and deep controls. A renamed
independent Chain fixture changes the producer, predicate, mapping and initial
accumulator; it adds noncommutative multiply/subtract accumulation and modulo
zero. Its three ordinary roots require actual emitted fusion entry. Supplemental
1024/4096/8192 and irregular1025/4097 screens showed increasing benefit in this
same workload family. Smaller inputs still expose fixed public-entry cost; these
observations do not establish application-wide parity. See [fusion](fusion.md).

## Construct and consume private data without generic crossings

Precisely proved eager nonnative constructors can emit the original tagged
representation directly, preserving field order, erased slots, freshness and
child aliases. Deferred generic construction stays on its original path. This
removes generic constructor dispatch before changing representation itself.

A partial flat-layout experiment crossed generic/public boundaries and added
provenance tracking; it regressed strongly and was rejected. A separate bounded
whole-private-graph diagnostic approached TypeScript on two tree points, but
combined layout and native recursion, so it was an architectural ceiling rather
than a source result. Orthogonal array/flat and BigInt/Number variants implicated
representation materially; Number countdown substitution had no consistent
benefit.

The selected source instead audits a complete closed scalar-owned graph and
creates lexical private clones with one fresh tagged object and direct fields.
No private object escapes into public results or generic representation bridges.
Original public G workers retain their array ABI. Normalized emission audits
reject residual generic construction/projection/call paths in the selected
clone graph. Missing, stale, duplicate or malformed context metadata refuses;
ordinary plan-only context cannot activate layout. Canonical root identity is
stored only after the original full graph audit, so typed selected definitions
do not bypass identity checks. Actual checked09 output demonstrated an
incremental gain while retaining structural stack machines. See [layout](layout.md).

The later closed native extension separately proves exact List-of-records,
nondependent Sigma/tuple and Bool ABIs, including quantities and field/result
types. Shared proof/equality work budgets bound alias-DAG analysis. Selected15
uses canonical native literal layouts for precisely marked owned eager
constructors, with the original typed argument emitter preserving evaluation
order, erased slots and aliases. Its actual BST assay replaces Tuple12/Con8/
True4/False4 generic constructor sites with corresponding literals, with all
bytes outside six admitted private bodies unchanged. It does not authorize
arbitrary native families, String or Array specialization.

## Admit sequential structural work and bound recursive fast paths

BST component plans were valid before its ordinary scalar root could enter
them. Native data proof alone was insufficient: the original local selector and
Nat setup remained barriers. A narrow finite-root useful-component policy
reuses existing full scalar entry proof and guards when an original self-recursive
callee has its separately admitted canonical component plan. It does not widen
the local flat-layout grammar or introduce another ownership framework.

Sequential proper-child continuations handle down/up/inorder-style work while
preserving original prefix, child and resume order. Independent BST controls
compare complete trees, pairs and ordered zipper paths, duplicates, partial fuel,
wrapped results and pointer aliases. Actual ordinary root and phase-two entry
counters establish activation. Deep left/right witnesses distinguish private
success from refused public fallback; generic stack failures remain recorded.
The Nat.add admission repair captures inert local metadata for the existing
checked callable. It does not replace its arithmetic, limits or Error behavior.

Initial live-frame and native-recursion screens on the earlier cost distribution
were weak or inconsistent; helper hoisting, lazy stacks and pruning were not
promoted. After dispatch and flat layout changed the cost distribution, a new
bounded hybrid became useful. Selected checked14/15 uses native recursion with
budget16 only inside an already admitted private flat graph. At budget zero it
calls the original iterative worker before evaluating a source prefix. Original
binary evaluation and combination order remain; the existing full graph proof
excludes intercomponent cycles, bounding budget resets independently of input
depth. A30,000-depth witness records actual iterative fallback rather than merely
passing a shallow checksum. Public workers remain unchanged. See [frames](frames.md)
and [calls](calls.md).

## Reuse exact planning facts within one compiler request

The planner-cache work follows a fresh compiler-request profile, independently
of generated-program timing. Request preparation stores exact canonical component
and direct plans using private existing KDef metadata. Ordered successful and
failed graphs, remaining fuel and validity are preserved; same-name rewritten
helpers cannot borrow a canonical fact. Original source-index/rest and binder
identity remain unchanged. book_put and fresh request preparation discard prior
facts. Discovery has bounded work; exhaustion reduces reuse and normal misses
still execute unchanged logical planners. Runtime coverage and host guards are
not cached.

Identity/invalidation/refusal controls support this equivalence, but the early
combined checked13 compiler-cost screen is mixed: tree requests improve while
list requests regress. It cannot causally attribute either result to caching
alone, and no compiler-throughput gain is concluded here. The selected-image
four-case cost gate remains a separate final obligation. See [facts](facts.md).

## Rejected and unpromoted alternatives

| Experiment | Observation and decision |
| --- | --- |
| Partial layout with public/generic crossings | Strong regression; reject. WeakSet and crossings are plausible causes, not individually measured attribution. |
| Handwritten whole-private recursive graph | Useful ceiling; never a checked source result or general stack-safe implementation. |
| Number counter substitution | No consistent orthogonal benefit; exclude the broader representation change. |
| Compact/live frames, hoisted helpers, lazy/pruned stacks | Small/null or inconsistent gains, including largest-point regressions; do not promote these variants. The later budget16 hybrid is a distinct mechanism. |
| Map String comparator edge substitution | Complete-content controls pass, but only small timing improvement; native String observation obligations remain unresolved. |
| Map.bit dispatch worker | Full values/traces pass, but paired timing regresses30–44%; reject production Map change. |
| Native constructor plus transfer-array changes | Constructor-only role wins; extra transfer changes do not improve it and are excluded. |
| Removing fusion proof scope | Equal scalar results hide extra public changed-code events under a pre-import callback. No useful gain established; shortcut unused. This diagnostic lies outside supported initialization, as described below. |

## Bugs and evidence corrections caught before qualification

Complete public-stage controls caught a real compiler interaction that root
checksums missed: rewriting a unary reconstruction App to JDirectCall hid its
recursive child, leaving undefined saved operands. Owner-aware preservation of
original App shells fixed it; failed checked03/05 outputs remain retained.
Fusion initially emitted no marker because a U32 domain was unnormalized;
normalizing it through existing weak-head reduction repaired admission without
stripping annotations or weakening type proof. Checked12 contained the Nat.add
source repair with an old assembled runtime; activation assertions caught that
mismatch despite equal value oracles. Runtime regeneration and a fresh checked13
attempt repaired it.

Other failures concern tools or fixtures and are not reported as compiler gains:
invalid type/match syntax and unrestricted-scalar affinity; overlapping saved-JS
edits; a missing cache-let type annotation and owner-thread arity typo; prototype
grouping syntax; an unscoped deep fusion diagnostic that used a generic recursive
filter; unbounded accessor reentry; cross-module bounce-function identity; and
boundary controls mutating a dependency outside the invoked root's exact graph.
Successors preserve the failed versions and exact assertions while correcting
the premise or route. Array.isArray observation was separated from strict
zero-entry controls because that sequential path does not guard/use it;
meaningful slice/push/iterator protocol controls remain.

Selected15's native Bool literals alter exactly two private bsort constructor
sites. Therefore raw checked13-to15 fallback identity is false for that body.
The corrected witness normalizes only one empty True and one empty False AST
constructor in a temporary nonexecutable comparison string. Baseline execution
stays byte-identical; other three fallback bodies remain raw-identical. Public
G assignments are checked separately. This preserves the earlier strict13-to14
witness and full behavioral tests rather than presenting a normalized body as a
checked executable baseline. See [review](review.md) and [validation](validation.md).

## Host contract and remaining limits

Executed pre-import BigInt/Math.imul callbacks expose real event/value differences
in old and new optimized regions. In one witness public proxy reentry changes
26 to30 and changed-code callbacks change seven tozero while the outer result
stays47. Those observations remain visible. Independent review traced the
standard-intrinsics-at-module-initialization assumption to published pre-Phase42
documentation and commits44a36083/88619d9c; it also exists in the Phase40 release.
The earlier unconditional promotion hold is superseded by that contract
classification, not by relabeling the diagnostics as parity.

Supported post-import replacement/getter, public foreign/raw/partial entry,
changed binding/code/metadata, Error callback reentry, demand order, proof cleanup,
complete value, freshness/alias and deep fallback controls remain mandatory.
Nat failure suspends private proof before Error observation. No claim is made
for arbitrary host replacement before import, unsupported generic data, arbitrary
callbacks, all native families, universal stack safety or diagnostic error ABI
identity with TypeScript. TypeScript string exceptions and existing Error ABI
are recorded separately. Bounded controls establish their specified domains,
not full-language equivalence.

Final broad semantic/CLI qualification, selected-image compiler cost, complete
fresh paired45 runtime coverage, installation and archive closure belong to the
release account. Full timing requires three serial15-point600-second batches:
669 mandatory one-second warmups alone exceed one600-second deadline. Exact
closure must bind all roles, Node identity, rounds and outputs; no partial batch
can establish final coverage. This mechanism account intentionally ends at the
selected frozen candidate and leaves those aggregate conclusions to final reports.
