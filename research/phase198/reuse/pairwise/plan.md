# Fuse recursive constructor production and consumption

For two equal-shaped trees, the checked warp base arm returns the two packed input leaves in ascending or descending order under one Node. Its Node/Node arm recurses on corresponding children, then warp_zip rearranges the results under one outer Node. By induction the two result children have the input topology and differ only in corresponding leaf placement. The outer Node is the only necessary new allocation. This property concerns the complete recursive worker and its consumer: changing only warp_zip leaves all recursive takes, intermediate outer allocations and H stack transport.

Test a named C projection on the single actual H invocation symbol of the qualified tree-bitonic assembly. Enter only fresh mode/depth/default result, with canonical boolean, two raw dynamic, unshared cold node children or a pair of packed U32 leaves. Walk both trees in a bounded explicit stack, requiring every internal pair raw unique, dynamic and distinct, every leaf packed and U32, matching tags, and bounded leaf changes. Record the changed leaf slots in private storage. Commit them after the entire region passes. Otherwise tail into the exact previous H function with all seven original arguments and untouched heap/state. Real Bend programs provide the linear raw ownership invariant; the pair may instead be aliased via RFC, which declines. The root leaf boxes are local words, the final outer Node is made by the exact original sized constructor. Test held aliases, sharing/mismatch below an already-proposed swap, small independent leaf permutations, stack/fresh-entry properties and ordinary checksums. Count actual H entries, input leaves, exchanges and original fallback separately from timing. Compare both assembler layouts against the original baseline and the two-parent field swap projection. Require median <=0.90 and at least five of six pairs favorable against baseline in both layouts. A win authorizes work on generic proof, not a name-based compiler replacement.
