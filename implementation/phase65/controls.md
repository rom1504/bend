## First discriminators

- **Typed facts:** Compare the complete enclosing document, call/SCC facts,
  layouts, host wrappers and emitted module under the old and new private
  producers. A weak-head-normalized annotation type is convertible to its
  original type but changes the public annotation structure; retain original
  public behavior and isolate ownership. Include recursive parameterized aliases,
  partial/overapplication, erasure, rewrites, native/generic layouts and refusal
  budgets. Check actual emitted API declarations before instrumentation.
- **Prepared Base products:** First partition observed work by exact Base
  definition identity, then compare complete annotations in Base-only and real
  request contexts. The annotation environment does not allocate fresh IDs;
  suffix-dependent native stop sets, checked-versus-raw Base, generated
  specializations and request-global SCC facts remain distinct boundaries.
  Annotation equality does not prove lowering or call-graph reuse sound.
- **Structured output facts:** Preserve physical-line marker recognition,
  duplicate-edge ordering, unknown/malformed refusal and full scan budgets.
  Concatenated chunks can split or form markers. Emitter-owned structured facts
  may avoid rediscovery; public/raw text keeps its exact scanner fallback.
- **Composite term reuse:** Substitution canonicalizes every App even when the
  target binder is absent. An unchanged return therefore requires canonical
  metadata, exactly two children and no newly exposed lambda. Nonmatching Var
  nodes do not traverse their attached children. Preserve source spans, removed
  names and KLambda quantity-presence metadata. Compare entire terms and full
  compilation results, not only semantic tags or reduced query counts.

`controls/prefix-world-constructor-v1.mjs` is a successor of the passed Phase64

eight maximum controls and the new membership cases; that receipt is not a full
matrix qualification. The actual State03 checked API has all 29 required
function declarations. No compiler target was run by this reviewer.

The small substitution candidate is justified by a constant-size structural
predicate: at most two leaf children, unchanged mismatching Var payloads, and
exactly canonical Apps whose function is not a lambda. Returning the outer term
preserves spans and KLambda quantity-presence metadata. The old substitution
remains the fallback. This proof does not support a recursive rescan on every
substitution entry or a generic semantic-equivalence shortcut.

The normalized-annotation-head candidate changes the stored public annotation
type. It remains a diagnostic snapshot experiment. Its controller compares full
plan documents, call/SCC facts, layouts, complete modules and independent values
against the original recursive annotation formula; it also binds the actual
snapshot source and verifies that intended aliases were genuinely pruned.

Base annotation reuse has a narrower possible ownership contract. The current
annotation call chain uses exact name lookup and term operations, without book
maximum allocation or whole-book constructor scans. Closure checks must include
implicit literal type names as well as explicit Ref/ADT nodes. Precomputing
stopped or unselected unsafe bodies can change termination, so a pinned Base
producer observation cannot establish arbitrary public-prefix demand equivalence.
Native stop selection must precede reuse.
