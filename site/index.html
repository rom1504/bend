THE NATIVE COMPILER GENERATIONS

Two native compilers. One C fixed point.

The same compiler source, with each generation tied to its actual build artifacts.

UPSTREAM → NATIVE B1

First-stage compiler

Upstream TypeScript compiles the Bend source to C. Clang builds the first native executable.

→
NATIVE B1 → NATIVE B2

Second-stage compiler

B1 emits the compiler's C. Clang builds B2, which runs as a native executable too.

→
NATIVE B2 → IDENTICAL C

Reproduced build input

B2 emits exactly the same C and clock-stripped diagnostic. A third native executable has not been built.

The public CLI has its own build bridge. It adds a Bend entry point to the promoted native compiler core; the fixed-point claim above belongs to the matched-source core. The separately maintained JavaScript command uses a genuine B2 compiler. Both histories remain below.
