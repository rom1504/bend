## Why the proposed small repairs are insufficient

Suspending proof around BigInt would address the demonstrated callback entry if every relevant call used that barrier. It is not a complete repair for the admitted domain. Numeric Math.imul and generic runtime spread/iterator/protocol operations can also invoke preimport observers. These additional channels are source inspection findings, not executed counterexamples in this report.

Rechecking after a callback also needs phase-correct resumption. j_direct_guarded emits a conditional that checks coverage before evaluating the selected private call's arguments. A callback during argument evaluation can invalidate the proof after the private branch has already been chosen. Inherited rewritten JDirectCall nodes and structural self/frame continuations can bypass a fresh public guard entirely. If the callback changes G.code, continuing their fixed source loses the original dynamic call. Revalidating only at the next outer root entry is too late; restarting the root repeats evaluated operands and effects.

The bad() error barrier is a different case: it clears the proof while Error executes and then throwing unwinds the active computation. A returning observer requires an explicit generic continuation at the exact interrupted phase, preserving already computed arguments, call lookup order, aliases and frame state. Existing frames provide traversal continuations, not this deoptimization contract.

Moving only scalar BigInt setup outside the proof could be a narrow future ablation. It would need to preserve original setup order and cannot discharge observer operations inside weighted workers or generic calls. A clean-realm assumption or function.toString test would alter the contract and is not proposed.

## Revised contract decision and future obligation

The initial recommendation to reverse the matched set solely because of this witness is superseded by the established initialization contract. Retain all frozen proof/emission/control artifacts and this witness as an unsupported-domain boundary test. Resume the narrow Nat.add metadata candidate without changing arithmetic, errors or ordinary runtime dispatch; require supported postimport mutation, bounds and Error-hook reentry evidence before promotion. No BST gain is established by this contract clarification.

A future design that expands support to arbitrary preimport observers would need two independently demonstrated properties: public reentry cannot inherit internal argument ownership, and returning host callbacks cannot let an already executing worker retain stale private dispatch after graph mutation. A lexical private-call capability with explicit propagation could address the first; exact observer barriers plus continuation/deoptimization or conservative source-domain refusal must address the second. Neither is implemented or validated here. The cheap first falsifier for any successor remains this unchanged two-mode witness, followed by Math/iterator and callback-in-argument controls, complete values and final compiler-cost measurement.
