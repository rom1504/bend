# Can algebraic fusion remove most of a program's work?

Use two original native45 families where a computed intermediate value has only one consumer. First measure a source-level ceiling on the current combined Phase197 compiler. Preserve the sources of the ordinary benchmarks and all timing, argument, result-validation, reachability and output instructions in their drivers. All alternatives depend on the actual runtime arguments.

For expressions, interpret the generated tree in the evaluator's U32 algebra during construction. A separate more ambitious version summarizes pending scalar arithmetic as an affine map on a single recursive result. Wrapping addition, subtraction and multiplication in this program support exact composition modulo 2^32. No corresponding rewrite on floating-point operations is implied.

For the records program, feed each generated record to the original ordered Map update, keeping the numerical amount's format/parse round trip in one variant. A second variant also eliminates that proven-by-spec round trip for valid unsigned words. Both retain Map cost, Unicode keys and exact ordered readback. Generated code is free to differ; mature C executable outputs and the original ordinary native products supply independent controls.

These are hand-written counterfactuals to guide compiler design. Measure separate workloads and sizes. A useful ceiling justifies testing a general, source-name-independent admission rule against the actual checked IR. Preserve unavailable or rejected implementations in the report.
