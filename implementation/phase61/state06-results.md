This is one exploratory round, not a confidence interval or a generated-program speed result.

All requests freshly match complete raw output bytes from the qualified catalog. The 45 runtime-point values are inherited qualification, not newly executed benchmarks. ## Next useful falsifiers

For Map/Set, `jd_doc_definition` ancestry across both passes accounts for 23.13% of sampled CPU. Its **final-library portion is only 7.91%**; initial emitted-reach construction accounts for 15.23%. Final call-fact construction is another 2.16%. Reusing final text and facts therefore targets about 10.07% of this observed CPU, before any proof, lookup or retention cost. Numeric's final definition portion is only 0.54%. These shares are not promised elapsed-time gains.

The current reach pass already builds structured `JDText`; it then retains only definitions. Initial emission overlays all annotated source-selected definitions, while final emission overlays only retained definitions. Removed entries revert to the original unannotated book. Equal runtime `JD_REF` closure alone does not prove equal normalization, inlined-chooser, arity or layout lookups. A sufficient tail-graph condition is unchanged retained `JDCall` rows plus closure under their initial edges; this preserves ordered SCCs and unknown-tail bounce reachability. It does not discharge the separate body/type lookup obligation.

The diagnostic [reuse probe](../../selfhost/tools/performance/phase61/latency/reuse-probe-v1.mjs) captures one ordinary request's actual initial/retained arguments, checks its complete raw output, then compares retained rendered text, call facts/components/bounce and initial tail closure. [The three-input run](../../selfhost/build/phase61/reuse-probe01/report.json) and [the complete 23-input run](../../selfhost/build/phase61/reuse-probe-all01/report.json) passed. The latter found 873 equal retained texts: 671 emitted function definitions and 202 empty ADT entries, totaling 619,101 emitted bytes across cases. It found no retained call-row/fact differences or tail edges outside the retained set. Potential changed lookup values were Word in 23 cases, Pair in 13 and Set in 2; only each definition's value field differed. These are potential dependencies, not recorded accesses. The probe does not implement caching or establish a universal invariant.

A shortcut accepting every universe-returning definition whose body matches after stripping annotations is not yet justified. Head normalization can leave annotated descendants, and later helpers inspect raw term shape. The conservative general requirement is exact equality of every compile-time dependency actually observed by a cached artifact, plus the call-graph closure proof; otherwise regenerate it. A complete-context equality gate is safe but would reject all current cases because Word differs. A useful type-alias relaxation therefore needs a separately audited consumer-equivalence proof, not a name whitelist or an inference from 23 passing cases. Any implementation must preserve original budget failures and traversal order, retain only actual successful reach visits, emit in retained definition order, and fall back when a cache/resource bound or context proof fails. Keeping text alive also needs an RSS check.

Numeric's remaining first-window cost is primarily fixed work: module parsing under API load 16.26%, Base cache ancestry 21.27%, and checker ancestry 18.60%. Map/Set has broader completion/checker/emission work. Blanket host memoization is no longer the dominant opportunity. The request-local host converter memo is deferred; definition-context reuse remains a separate proof-dependent hypothesis. Neither is implemented or credited with additional improvement here.
