## Questions and order

1. **Prepared Base:** can a fixed-width carrier remove decimal decoding without
   changing reconstructed checked preparation or relaxing bounds/authentication?
   All three requests repeat 1,087,899 `p88_digits`, 762,943 `p88_digit` and
   324,069 `p88_number` entries. Full decoder context exposure is approximately
   16% lexer, 54% closures and 12% Map; these are contextual exposures, not
   independently attributable speedups. Test the narrow numeric transport first.
2. **Complete scalar query:** what is the attainable gain from computing
   `Pair.snd(String.cmp(a,b))` without rebuilding the preserved string roots?
   Measure two ordinary checked programs against an independent lexicographic
   oracle before designing an automatic general known-result projection.
3. Integrate only an economically justified result. Do not write a large cache,
   generic profiler or new IR. A source-level ceiling alone is not a compiler
   optimization, and a native decoder proxy is not a complete request timing.

## Fast loop and gates

Use exact Phase128 checked API, pinned upstream/Base and scalar-borrow runtime.
Root owns one guarded CPU3 execution lane; bounded agents prepare disjoint
fixtures and independently audit contracts. All semantic code stays in Bend.
Keep exact inputs, output oracles, commands, failed attempts and resource costs.
Measure clean alternating paired runs separately from diagnostic profiles.

For carrier work, authenticate the complete carrier and format identity outside
its routing stamp; compare all reconstructed products and source requests, not
just counts. Preserve malformed input, Unicode, index/span/readiness bounds,
source/Base identity, diagnostics and versioned invalidation. Old decimal format
must retain a correct path. Never inject unchecked native Term graphs.

For scalar work, preserve ordering, evaluation, retained roots, aliases, effects,
nonowning scalar results, stack safety and an owning fallback. Require a cheap
unrelated transfer screen before broadening compiler machinery.

If the small experiment succeeds, bind a new exact checked source/runtime
receipt, run finite/independent controls, then acquire hosted → N1 → N2 and
compare full QBE bytes. Run focused19 on both images and ordinary45 on N2.
Compare cold native requests against Phase128 and pinned upstream. Check the
historical runtime wrappers separately, retaining geometric slowdown, mean
positive log-slowdown and per-case regressions. No promotion before qualification.

## Ambition and stopping rules

**1×:** cheaper Base materialization and a quantified scalar-query ceiling;
request gains should follow measured exposures. **10×:** if numeric transport
leaves reconstruction dominant, test a flat decoder or immutable checked seed
with correct identity/ownership, eliminating intermediate parser state.
**100×:** eventually preserve checked semantic facts and complete borrowed query
regions across compiler passes. These are research scopes, not speed forecasts;
no broad implementation without a decisive small result.

Disk currently has under 0.5GiB free. Reclaim only verified immutable duplicates
with a receipt before large acquisition; do not delete unique evidence or the
qualified compiler. Keep RSS≤6GiB, available memory≥16GiB, bounded files and time.
Report acquisition/validation costs separately from target execution gains.
