# Private frame placement and one more preserved GPR

A fixed stack pointer permits using RBP as a callee-preserved scalar home throughout a generated worker. The existing PUSH/POP still preserve the caller's RBP. Every frame access through the old RBP moves to an exactly equivalent RSP-relative address, including positive incoming arguments. The return restores RSP with LEA, preserving flags. A selected scalar can therefore survive external runtime calls without inserting saves at each call. This experiment is independent of RCX/R12 pool changes, earlier regional overlays, and tail coalescing.

The independently seeded BST32/64 screen adds a frame-pointer-elision placebo. It retains the same functions' RSP-relative layout and ordinary spill memory accesses, isolating the value of RBP promotion from frame addressing and layout. A second diagnostic changes only the product.bst.down owner. Source advancement requires replication at BST64 in both layouts and improvement over the rebasing placebo in both.
