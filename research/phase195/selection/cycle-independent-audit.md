# Independent residual-cycle audit

Reviewed frozen `parallel-cycle-v2.bend`, its sole `x186_p_ready` hook and finite Bend/C controls. No semantic blocker was found for canonical frames produced by the maintained frame builder. No checker, compiler, target or timing job was run in this audit. Exact source/API pins are in `cycle-independent-audit.json`.

The unchanged zipper first validates vector lengths, legal full-word homes and unique destination homes. Home identity uses physical kind/index, so source aliases with different names remain dependencies. Self copies disappear only after this mapping. The old ready-move rule drains a destination only when no pending source still reads its home; consequently the drained prefix cannot destroy a residual source. On deadlock, all residual sources are snapshotted before any residual destination is published. This preserves fanout and multiple independent cycles without requiring a scratch register to survive a helper expansion.

All loads/stores are 64-bit. A preceding U32 truncation remains an executed publication; later full-word self-copy deletion does not restore its old upper bits. RAX/R10/R11 retain exactly their existing selector scratch roles. The prototype introduces no call, flag-dependent operation, new allocation, or live XMM state. R12/RCX homes from the independent pool experiment remain compatible because the snapshot sequence does not use either as scratch; that composition still needs its own machine qualification.

Bank capacity, alignment, frame containment and overlap with residual stack homes/reads are checked. Independent review found v1 lacked a lower bound protecting the saved-register area; v2 requires bank-end minus bank-size at least 40 and adds an explicit negative control. Full-frame disjointness, including previously drained/self values, remains the canonical frame builder's contract; the residual check is not a general validator for arbitrary hand-built overlapping frames. New pool state storage appends after existing frame objects, so it does not overlap the pre-existing tail bank.

Refusal returns `None` before any emitted sequence is used, discarding planned prefixes and preserving the original whole-vector fallback. Fuel is bounded by the existing 64-value domain. The eight forced machine fixtures cover two/three-register cycles, mixed register/stack cycles, two cycles, fanout plus constant ready moves, physical aliases, caller homes, and prior U32 truncation; the independent C observer checks 704 cases per route. Source checking and actual observations are still required.

Prepared immutable metadata only: `cycle-api-source02` uses the qualified Phase194 selected-source02 parent; `combined-cycle-api-source02` uses exact Phase195 combined-api-source01. Each replaces only `x186_p_ready`, adds the exact v2 module/hook/controls, and exports the usual seven roots plus `p195cy_controls`/`p195cy_emit`. The frozen acquire argv files are `cycle-api02-argv.json` and `combined-cycle-api02-argv.json`; root owns execution.
