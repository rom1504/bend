no remaining matcher arguments; exact constructor identity and declared live
arity2–8; a nonbuiltin, zero-parameter/nonindexed enclosing ADT; and a bounded
nondependent live constructor telescope. Its hit must be exactly that many
distinct live lambdas followed by the same constructor with those variables
once each in declaration order. No general normalization, call/effect,
observation, let alias, field permutation, duplication or mutation is added.
The raw predicate is not a replacement for the independent original frontend
and native IR verifiers. Invented finite-control terms test admission only and
must never be emitted/executed as native runtime nodes.

The hit lowers the original scrutinee in the original environment and destination.
This preserves normal drops for unrelated owners, return/local conventions and
the miss branch/fresh counter. The constructor test remains. There are no field
bindings, take, reconstruction, uniqueness guard, borrowed pointer or reuse
credit on a successful hit. Static/shared owners need no special handling:
the original reference is transferred unchanged. Specialized Word/primitive/IO
representations are excluded. A private target expecting an unboxed NQShape
uses the exact prior fallback, retaining its existing worker admission.
