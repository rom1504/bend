# P70-008: reserve observer planning for owners without an admitted ordinary worker

Registered before preparing or executing the candidate. The parent observed
that the active hidden-scalar-error diagnostic did not reach its observer
adapter: an existing admitted private NF call bypasses the scheduler hook.
This is consistent with Phase70's deliberately local scheduler substitution.

Hypothesis: skipping observer planning when the exact original owner is already
in the final ordinary NF-ready set removes redundant analysis and C helpers,
while retaining the important non-tail reconstruction cases rejected by ordinary
workers. Map/String/Tape are motivating structural cases, never name rules.

The source base is `observer-integration.bend` SHA256
`994f9f771f109d7e38b7bd21b2dd3b344a415d91a7c5bc1ae71fd6735d80fb1b`;
the observer-emission02 checked B1 used for source inspection is
`d59577dbd15cd31b8c04bf6243d70fb3969c365f07f7a933ca152253f2a85a5e`.
All earlier checked permission, typed schema/origin proof, ordinary admission,
raw/device fallback and worker representation facts remain requirements.

The optional patch adds one lazy guard inside `no_route_one`, after direct-entry
eligibility but before `no_observer_plan`. It consults the existing ready list
for the **exact original owner**, not `$product.owner`, source spelling,
annotations, elapsed cost or a benchmark name. Ordinary retry/admission has
already finished. Observer additions only extend ready with distinct private
names, so this membership test continues to identify the original route.

This is a compilation-cost policy, not a new semantic proof or dead-code
theorem. An ordinary-ready function can still be called through the scheduler
from a dynamic/nonflat caller and might benefit from borrowing there. The rule
forgoes that potential runtime gain. It also forgoes simple fixed-prefix
observer optimizations even though their typed identity proof succeeds.
Existing private NF callers already bypass the observer and are unchanged.
Owners with only an admitted `$product.` worker remain eligible in this first
scope; determining complete call-path redundancy would require more analysis.

`no_observer_plan` itself remains unchanged and query acceptance must match the
baseline. Emission admission gains a separate `ordinary-worker-already-ready`
reason: a sound accepted plan may intentionally have no emitted observer.
Version affected emission oracles explicitly; do not relabel prior semantic
acceptance as a proof refusal. Original runtime goldens remain unchanged.

First validation: qualified B1 source build, unchanged semantic plan queries,
exact retained observer bodies/hooks for nonflat witnesses, and an explicit
report of skipped owners. Compare the relevant pre-existing ordinary worker
signatures/bodies as well. Run the existing semantic/error controls through
their selected routes. A skipped adapter cannot qualify observer-specific
error handling merely because its ordinary fallback preserves the error.

Then use alternating baseline/candidate native-emission requests with a small
multi-family subset, recording plan attempts, accepted/skipped owners, emitted
C bytes and Clang time separately. The predicted saving is the measured time
spent planning/emitting already-ready owners; there is no justified whole-
compiler percentage yet. Ready-list membership costs remain and must be
included. Reject the policy if important observer paths disappear, compiled
program speed regresses materially, or compilation savings are negligible.
Broaden runtime/B1/B2 checks only after a useful fast-loop result. No host
algorithm replaces the Bend analysis, and no production change is selected by
this registration.

Initial status: prospective source-only experiment. Parent owns all target
execution and any decision to enable it. The completed outcome below supersedes
this initial status; the original proposal and diagnostic images remain frozen.

## Compiler02 causal screen, registered before execution

The now-complete compiler02 diagnostic profiles attribute 251.7 ms of the B1
Numeric request and 54.9–69.1 ms of the three B2 requests to named observer
stacks. These are inclusive sampled unions, not estimated removable time.
The pinned source audit finds exactly one emitted observer, `String.cmp`, in
each Numeric/Array/Lexer C; its ordinary worker is absent, so P70-008 should
retain all emitted C in the Numeric discriminator.

Before paying for another compiler build, use a bounded saved-API factorial:
compiler02 unchanged, occurrence-insertion rollback, ordinary-ready skip, and
both. Use both the real checked B1 image and genuine B2 image. Four balanced
rotations put every arm in every within-stage position; alternate B1/B2 stage
order. This is eight independent Base preparations plus 32 clean Numeric
requests, not a compilation-speed suite or a shipping candidate. All requests
must reproduce the exact already-qualified compiler02 Numeric C bytes. Any
output difference fails this experiment and requires separate source analysis;
there is no permissive structural equivalence rule or retrospective oracle.

The generated-source modifications preserve exact original bytes, replacement
functions, offsets, API hashes, reverse recovery and commutation of the two
independent substitutions. B1 retains the existing `nt_choose` closure/
trampoline convention; B2 retains its direct conditional convention. The
observer edit is only the lazy owner membership guard inside the existing
eligible-entry branch. Source producer and derivations are in
`observers-emitter/derive-ready-ablation-v1.py` and the retained
`observer-ready-ablation-images01/derivation.json`; the methods lane owns the
prospective execution plan and resource guard. Root alone executes targets.

Compare main effects and interaction within each compiler stage, reporting
each request and all four rounds. Do not treat the full observed observer
union as removable: `String.cmp` analysis, adapter validation and lowering are
deliberately retained. If gains are small or unstable, keep P70-008 unapplied.
Only a useful exact-output causal result justifies a new Bend source build and
broader semantic/runtime qualification.

## Outcome: not selected

Root completed all eight preparations and 32 requests in
`selfhost/build/phase70/compiler02-factorial01/`. Every request emitted the
exact qualified Numeric C. The complete data-only reduction is
`compiler02-factorial01-summary.json`, bound to plan SHA256
`747edf83b39f5a56ede3d717bcb62a587de06024a2866a3ee818aca1ca069070`.
All four requests per arm remain in the report; none was discarded.

Ratios below one favor the ordinary-ready skip:

| Stage and occurrence policy | Skip/base median ratio | Geometric mean of paired round ratios | Faster skip rounds |
| --- | ---: | ---: | ---: |
| B1, occurrence insertion on | 1.00354 | 1.00320 | 3/4 |
| B1, occurrence insertion off | 0.94565 | 0.96954 | 3/4 |
| B2, occurrence insertion on | 0.99787 | 1.00501 | 1/4 |
| B2, occurrence insertion off | 1.00069 | 1.00732 | 2/4 |

There is no stable B2 benefit. The apparent 5.4% B1 median gain without
occurrence insertion is not convincing cross-stage evidence: B1 arm samples
mix roughly 2.38–2.41 s requests with roughly 2.63–2.65 s slow requests, and
the paired result and factorial interaction do not reproduce that median
effect consistently. The profile's large observer union was therefore not a
valid estimate of removable work. The tiny B2 median differences also have
the opposite sign from the paired geometric means.

P70-008 remains **unapplied and not selected**. Keep the exact ordinary
observer-routing policy, the original frozen source patch, the API diagnostic
images and all receipts. No further observer optimization is scheduled in
this phase. The independent occurrence-insertion optimization is being removed
by root in checked03: on the ordinary observer route it was 2.22% slower by
B2 medians and slower in all four paired rounds. That separate selection does
not make this observer skip useful.

Future investigation may reuse already-validated wrapper layout/constructor
facts to avoid repeated book scans while preserving malformed-plan refusal.
It requires a new hypothesis and causal screen; it is not implemented or
selected by this experiment.
