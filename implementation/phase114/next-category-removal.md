The next bounded experiment should keep **canonical F32 values in the floating-point register domain across private arithmetic and calls**, with the existing full-Term ABI at generic boundaries. This removes a category that survives the operand-buffer experiment. Another general nonescaping-product pass is less well supported by the inspected hot paths: local-fold and ray already use their flat product workers. This proposal does not explain the entire 5.386× broad runtime gap or predict a multiplier.

The information loss is explicit in source. `selfhost/src/back/native/flat.bend:nf_scalar_kind` collapses U32/F32/Char/Bool into `N_W32`; this is not an F32 certificate. `phase111/segment/model.bend:N111Type` has only U32/U64/Ptr, and `phase113/direct/model.bend:P113DFunction` stores result width, not result representation. `phase113/direct-emit/emit.bend:p113e_formals`, `p113e_arguments` and `p113e_private` consequently emit `l` throughout. `phase112/float/emit.bend:p112fp_binary_text` explicitly recreates the integer word after every arithmetic result.

A small first profile should admit only closed acyclic workers with exact canonical F32 parameter/result types and supported arithmetic, comparison and copy flow. Recover these facts from the checked pre-erasure telescope and result type; retain an explicit `F32Bits` versus `F32Value` distinction through local flow and call signatures. Emit `s` formals/results and float temporaries inside this region. Convert once when entering/leaving an ordinary Term worker or a remaining generic runtime primitive. Keep all other functions on their current ABI. Do not infer F32 from `N_W32`, remove ownership operations for unknown values, or change public descriptors, the allocator or the trampoline.

Missing invariants are finite but real: exact types at every admitted call/result; consistent representation at branch merges and local reassignments; correct boundary bitcasts; and preservation of operation order, F32 rounding, signed zero, NaNs, infinities and comparison behavior without reassociation or contraction. Start with one result and no owning fields. Existing original-graph verification remains mandatory; the new typed projection needs its own closed signature/value-flow check. Changing the function header alone would be incorrect.

The smallest ordinary-source experiment is a closed arithmetic helper chain returning F32, including both comparison branches and a nine-or-ten-F32-argument call so actual register/stack ABI transport is observed. Verify that calls survive ordinary inlining before treating it as an ABI witness. Reuse the qualified float semantic cases, then test the unchanged ray source. The mechanical success criterion is removal of intermediate GPR/XMM round trips and integer-only call transport while complete outputs remain equal; only then time it. If machine conversions disappear without useful runtime improvement, stop instead of widening the pass based on the 10.83× ray gap.

Cost is a small typed signature/value-flow pass, a typed private emitter path and explicit generic-boundary adapters, plus ordinary compiler/semantic qualification. It is materially larger than the operand-store deletion, but smaller than general tagged-sum escape analysis or a new heap representation. No new runtime object is required. Multi-result float products, recursive regions and array origin proofs are separate follow-ups.
