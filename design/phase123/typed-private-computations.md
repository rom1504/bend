## Correctness and cost

Transformations operate in Bend on the existing structured plans/IR. Python/JS
tools only compose exact declarations, transport checked APIs, run independent
oracles and retain receipts. No host-language optimizer enters ordinary output.
Retain exact arity, operation order, word widths, native ownership and explicit
stack safety. Known predicate identity is not permission to assume unknown Terms
are unboxed Booleans. Finite nested layouts must not admit recursive storage or
unproved sharing/escape. Independent boundaries include0,1,2^31,UINT_MAX and
unknown branch inputs; output equality alone must not hide refused activation.

Use existing checked-hosted API acquisition and prepared Base, with independent
parent IR verification. Freeze every attempt, including refused/neutral ones.
Start with two programs and semantic controls; inspect generated activation and
machine code, then require transfer to an unrelated program. Once the retained
candidate is stable, perform one original45 screen and a paired hosted compiler
cost screen. Full native image acquisition is deferred unless these results
justify its cost and the available disk permits it. Do not relabel hosted results
as N1/N2 throughput or promotion.

predicate implementation/proof audit. Root owns integration and one serial CPU3
