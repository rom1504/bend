# Persistent local F32 lanes, full-Term ABI

This is the local-only specialization of the checked `combined-source08` renderer. It removes typed-call candidate analysis, dependency plans, typed formals, adapter functions, alternate function symbols and float backedge variants. All existing ordinary calls use `p113e_call_emit`; parameters, results and loop arguments remain full Terms. Original Phase125 verification and all request-bound entry gates remain unchanged.

The local files contain 220 physical lines. They reuse four frozen Phase114 modules (325 lines) for operand-buffer audit, exact scalar rendering and local lane facts. Compose the nine modules in `modules01.json` in order. The only parent override is `p113ah_private_chunks`; the four intra-module replacements are `p114so_group_call`, `p114fl_text`, `p114fl_result`, and `p114fl_bind`. Do not include the earlier Phase126 typed modules, analysis controls, ablation or plan types.

The comparison reference is `selfhost/build/phase126/combined-source08/compiler.bend`: local-source06 behavior plus the `flow-v02` Boolean diamond hook and finite-selector integration. Primitive/group/fact and branch-kill definitions are exact selected declarations, with only the local helper prefix renamed. Dispatch removes the permanently empty `floats`/`plans` fields and their unreachable branches. The selected 64-fact cap, word transport, per-operation rounding, double-precision `sqrt` followed by F32 truncation, and 9-site allocation remain exact.

Backedges still snapshot every full-word input before any parameter assignment, using the same `%p126_next_N` spelling and traversal order. Function prologues retain the harmless empty chunk that was formerly produced by `p126t_words([])`. Labels, site counters, word locals, emitted operations and existing diagnostic strings are deliberately unchanged. This permits byte-exact QBE comparison rather than merely relying on complete-output equivalence.

`p126l_emit_one` retains the previous dispatch predicate: no array-body operations and at least one audited operand buffer. Other functions call the existing `p113ah_function`, so the independently composed specialization `render-entry.bend` still handles finite tables. There are no new public/private ABI variants or global data.

The parent should first check the composed API and require byte-identical QBE against combined08 for the existing float boundary/state controls, active ray, plain ray and numeric recurrence. These witnesses should include ordinary calls, parallel backedges, conditionals and Boolean diamonds. A mismatch must be explained before treating this as equivalent cleanup. No compiler/API/target execution was performed while writing this module set; only declaration identity, dependency names and delimiter checks were done offline.
