# P55-002: identify the remaining full-image emission cost

Hypothesis: decomposing the existing final library sequence exposes a specific
remaining expensive phase after emitted reachability. The diagnostic must preserve
the exact invalid-analysis branch and produce the same bytes as the ordinary
library call on a restricted image. Subject source and77 roots remain fixed while
the checked generator changes. No dump/reload of a transformed book, host semantic
rewrite, export narrowing or hidden fallback is permitted.
