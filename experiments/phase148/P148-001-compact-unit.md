# P148-001 — one compact body across optimization and admission

Status: completed experiment; reject current adapter for production performance.

Hypothesis: preserving numeric identities and physically contiguous instructions
across actual scalar optimization and admission removes repeated name resolution,
wide records, temporary lists and ownership work. A smaller verifier environment
alone is insufficient evidence. Include conversion and final decode/cleanup.

Prediction: at least2× on a complete affected native region would support broad
extension. This is a decision target, not a whole-compiler forecast. Compare
exact transformed functions and errors, then the independent final verifier and
emitter. Original arithmetic/epoch/predicate behavior remains the semantic oracle.

Falsifiers: conversion dominates; native arrays cause expensive transport;
branch cloning dominates; direct workers disappear; scalar optimization choices
or errors change; only one synthetic family improves; cold time does not transfer.

The [design](../../design/phase148/README.md) records1×/10×/100× scope and gates.
The [fixture audit](../../research/phase148/fast-loop.md) identifies retained real
functions and independent contexts. No full compiler rebuild is justified until
small native evidence supports one.

## Result

Corrected source and81 fixed controls pass, as do ten supplementary optimizer
controls and two explicit refusals. Complete native pipelines give new/old
0.9936 on compiler functions and1.0279 on Map. The diagnostic successor gives
0.9907 full and0.9905 without rendering. Adding pack/unpack before the old
pipeline gives1.1623; this includes decoded-tree ownership and is not an
additive conversion clock. The2× complete-region discriminator is not met.

The first unsafe array-bearing wrapper interface failed native execution despite
hosted success. The affine successor passes exact output checks. Current ordinary
scalar arrays still use8-byte slots/runtime calls. Profiler01 is rejected for
overruns; profiler02 passes unchanged quality gates and identifies remaining
runtime transport. All failures and method versions are retained.

Do not integrate or launch full self-hosting for this candidate. Preserve the
qualified Phase147 compiler. Next test cheap native access, then a producer-led
compact region or shared frontend identities. The larger plans remain conditional.

[conclusions](../../research/phase148/conclusions.md) separate observations from
future hypotheses.
