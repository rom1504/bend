installed selection, and does not reuse the Phase134 qualifier's hardcoded

## Reuse existing target supervisors

Root wraps every target command in the existing CPU3 process-tree guard, with
the current memory/disk floor. Do not nest guards or run parallel performance
work. Acquisition and self-emission use:

```sh
python3 -B selfhost/tools/performance/phase130/native-request.py \
  --image IMAGE --source selfhost/build/phase137/integrated-source03/compiler.bend \
  --carrier-receipt selfhost/build/phase130/base-carrier01/receipt.json \
  --out REQUEST_OUT --seconds 1200

python3 -B selfhost/tools/performance/phase123/build-aligned.py \
  --source REQUEST_OUT/program.ssa \
  --runtime selfhost/build/phase128/runtime-borrow01/runtime.o \
  --out IMAGE_OUT --seconds 180
```

| Step | IMAGE | REQUEST_OUT | IMAGE_OUT |
|---|---|---|---|
| Q1/N1 | qualified Phase134 N2 | `phase130/p137-acquire01` | `phase111/p137-n1` |
| Q2/N2 | Phase137 N1 | `phase130/p137-self01` | `phase111/p137-n2` |
| Q3/N3 | Phase137 N2 | `phase130/p137-reproduce01` | `phase111/p137-n3` |

The table uses build-relative paths. The default contract requires **Q2=Q3**
in complete raw bytes; pass `--expected-qbe` pointing to Q2 for the Q3 request.
Q1 may differ because it was generated by the old optimizer. Do not require
Q1=Q2 before determining the actual output. If Q1=Q2 genuinely holds, the
explicit `q1-q2` qualification mode can finish at N2 instead; no failed equality
is silently relaxed and the required coverage generations change accordingly.

Use the existing focused and ordinary supervisors:

```sh
python3 -B selfhost/tools/performance/phase125/native/coverage.py \
  --image IMAGE --runtime selfhost/build/phase128/runtime-borrow01/runtime.o \
  --out FRESH_PHASE111_OUT --suite focused --seconds 120 --build-seconds 30

python3 -B selfhost/tools/performance/phase125/native/full45.py \
  --image IMAGE --runtime selfhost/build/phase128/runtime-borrow01/runtime.o \
  --out FRESH_PHASE111_OUT --partition all45 --seconds 120 --build-seconds 30
```

For Q2=Q3, run focused19 on N2 and N3, and ordinary45 on N3. For Q1=Q2,
focused19 covers N1/N2 and ordinary45 covers N2. An early N1 focused screen is
useful but does not substitute for the required generations. Focused19 means
16 exact-output executions plus three independently constrained expected
refusals. Full45 means45 exact ordinary outputs, not timing wrappers. These
legacy supervisors deliberately retain their pinned prepared-Base transport;
bootstrap requests use the compact carrier. The qualifier checks each contract.

After all receipts exist:

```sh
python3 -B selfhost/tools/performance/phase137/native/qualify.py \
  --source-manifest selfhost/build/phase137/integrated-source03/manifest.json \
  --checked-api selfhost/build/phase111/p137-integrated-api01/report.json \
  --finite selfhost/build/phase137/integrated-finite01/report.json \
  --policy q2-q3 \
  --acquisition selfhost/build/phase130/p137-acquire01/report.json \
  --n1-build selfhost/build/phase111/p137-n1/report.json \
  --self-emission selfhost/build/phase130/p137-self01/report.json \
  --n2-build selfhost/build/phase111/p137-n2/report.json \
  --reproduction selfhost/build/phase130/p137-reproduce01/report.json \
  --n3-build selfhost/build/phase111/p137-n3/report.json \
  --first-focused N2_FOCUSED_REPORT --final-focused N3_FOCUSED_REPORT \
  --final-full45 N3_FULL45_REPORT \
  --out selfhost/build/phase137/native-qualification01.json
```

This adapter invokes the frozen Phase131 `V.emission`/`V.coverage` and Phase128
`Q.build` authenticators. It validates source/runtime/carrier identity, exact
argv, toolchain and machine options, actual emission/build lineage, complete
outputs, refusal stages and all pinned inputs. It does not launch those tools.

## Comparison with upstream

After qualification, `native/timing-plan.py --qualification REPORT --out PLAN
--tag p137-final-timing01` prepares a manifest using the unchanged Phase130
three-source timing runner. Only the two native role bindings change: fresh
qualified Phase134 N2 versus fresh qualified Phase137 final image. The upstream
TypeScript/Bun compiler, source Base, independent outputs, QBE/Clang toolchain,
machine options, limits and rotated27-observation schedule stay frozen.

Root executes the emitted job under the quiet CPU3 guard. Use the runner's
existing summary for request time and ready-executable stage sums separately.
Native request emits QBE with prepared Base; upstream emits C from source Base.
The different runtime build policy means ready sums cannot be relabeled as
compiler-only speed. Program executions in this screen check correctness;
they do not establish generated-program performance.

Preserving ordinary45 outputs does not prove generated-program runtime is flat.
For that separate metric, compare the native-generated45 timing wrappers to the
retained measured products first. Exact products permit clearly labeled reuse
of their measurements; changed products require the usual controlled runtime
screen. No historical ratio becomes a fresh Phase137 result automatically.
