# Two-input constructor permutation

In qualified tree-bitonic, the two-Node arm of warp_zip exchanges the original left node's right child and right node's left child. Its original path destructures two nodes, reconstructs two inner nodes of exactly the same constructor, and builds one outer node. The earlier Phase68/69 spare reuses two allocations while extracting and publishing all four fields. The proposed path moves only the two changed words between two distinct, owned raw dynamic nodes whose element publication policies match. No allocations, frees, keep or drop for the inner boxes. The outer construction retains its original runtime operation. Every refusal returns to the untouched original code before any write.
