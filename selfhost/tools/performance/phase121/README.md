# Phase121: native construction elimination

The compiler changes are in Bend: **`fusion03.bend` + `callback02.bend`**.
They compose onto qualified Phase118; Phase120 numeric modules are not included.
The source recipe is `candidate-recipe.json`. Python composes declarations,
supervises processes and compares independently expected outputs. JavaScript
invokes checked Bend APIs. Neither host harness implements these optimizations.

See the [design](../../../../design/phase121/construction-elimination.md),
[report](../../../../implementation/phase121/README.md) and
[backend guide](../../../../docs/self_hosted/native-fusion.md).
All `selfhost/build` paths below identify this checkout's frozen evidence. Use
fresh output names for reruns; never overwrite a recorded source or method.

```sh

  --out selfhost/build/phase121/reproduce-new
```

## Semantic controls and admission

`controls02.json` pins three standalone source programs and full expected stdout,
generated by independent arithmetic models. Set `P118_CASE_MANIFEST` to that
file for emission. Pass these names: `list-controls`,
`renamed-pipeline-controls`, `callback-controls`.

Run the unchanged Phase118 `functional-v2.py` with `--emission REPORT`,
`--out FRESH_PHASE118_DIR`, `--label UNIQUE`, and `--manifest controls02.json`
(use its complete repository-relative path). Separately run:

```text
bun admission-v2.mjs API_REPORT EMISSION_REPORT admission-checks.json FRESH_JSON
```

Use the pinned `selfhost/.bootstrap/bun-1.4.3/bun` and full script paths.
Nine literal acceptance/refusal expectations must agree with both the checked
Bend inspector and actual private function emission. These expectations include
renamed helpers, changed arithmetic, shared/escaping values, reversed composition
and a user-defined primitive-looking name. Successful output alone does not
prove that fusion activated. Finite controls are not a general correctness proof.

## Compiler cost, machine evidence and broad comparison

Reuse `phase118/cost-v2.mjs` under the guard. Set:

```text
P118_PARENT_SELECTION=implementation/phase118/selection.json
P118_PARENT_API_REPORT=selfhost/build/phase111/p118-safe-api03/report.json
P118_RUNTIME_REPORT=selfhost/build/phase118/runtime-extend01/report.json
P118_EXPECT_EMISSION_REPORT=THE_MATCHING_CANDIDATE_EMISSION_REPORT
```

Arguments: candidate API, source manifest, fresh Phase118 output directory, and
case names. This measures complete hosted requests with separate authenticated
Base preparation per API. It does not measure native N1/N2 execution or upstream
compiler time. First use the list128, closure64 and recurrence1024 cases.

`machine.py` authenticates binaries and records selected-function disassembly;
`--functions p121.stream p121.callback` finds the new workers. Static counts are
not executed-instruction counts. `summarize.py` preserves original45 eligibility;
`analyze-broad.py` adds the unchanged family weighting, round spread and emitted
QBE size. Run the full original45 once after the fast gates, with the same
`screen.py --rounds 3 --scale 4`. Preserve the zero-work sentinel; exclude it only
from ratios as the original manifest specifies.

## Retained attempts

- `diagnostic/`: rejected helper ordering; first emission reports an unfilled law.
- `diagnostic-v2/`: corrected source-only ceilings, independent list/map controls
  and renamed controls. Only measured cases count as evidence; map controls were
  not executed after the map diagnostic was neutral.
- `diagnostic-closures/`: source-only closure-elimination ceiling.
- `fusion01.bend`: initial passing list implementation; `fusion02.bend` has a
  checker-rejected affine binder; `fusion03.bend` fixes it and adds review repairs.
- `callback01.bend`: conservatively refuses checked erased-lambda definitions.
  `callback02.bend` adapts only the analysis view before the original full checks.
- `debug.bend`/`debug.mjs`: diagnostic adapter refusal localization.
- `admission.mjs`: failed host Bool decoding; selected `admission-v2.mjs` checks
  the actual native JavaScript Boolean representation. Compiler output was valid.

Do not rerun preparation scripts over their frozen generated controls. Retained
manifests pin their generators, source prefixes, upstream sources and independent
expected data. `seal.py` archives small receipts including failed attempts and
machine evidence; `seal.py replay ARCHIVE` verifies payloads without extraction.
Large APIs, source compositions and native products remain external with pins.
Installed production and qualified native Phase118 selections are unchanged.
