# Normalization and substitution attribution

No normalization change is promoted from these measurements. A fully checked
Bend fast path improved isolated annotation and small warmed B1 programs, but
fresh H runs barely changed and a larger B1 pipeline did not improve consistently.
The next investigation targets repeated substitution of closed telescopes.

[Archived reports and hashes](analysis-evidence/normalization-manifest.json)
retain every sample, artifact identity and incomplete attempt. Raw generated
APIs remain under `selfhost/build/phase4/analysis-*`.

## What the successful compiler actually does

The frozen Phase 3 B1 API is `8787894920cc8959ab0abec28ddae0ea0dc05ad7665dc6f4d43f845445e60923`;
H is `360bb62bec910e8148a8c24ee63c1a350a8fda06c206bdd5f04c153a006804de`.
The pinned canonical Base and runtime are unchanged. The frozen host snapshot is
`selfhost/build/conformance-host/2b692463e833d36a96edba2adf3ceb53b7f1432dbcb42803ddebb779d7df1749/`;
its rewritten `typed-driver.mjs` has SHA `b8f7ef8bb2077c14518914aa5a9b88c73e2e6728799b84ec273802f732515951`.

Disposable counters on the checked B1 workers preserve exact emitted JavaScript.
They perturb execution, so their durations are not performance measurements.
On the real `tests/flatten/literal_rows_cubic.bend` input, annotation makes
451,867 weak-head normalization calls. Of these, 286,785 repeat an identical
immutable `(book, term)` pair; 418,660 return the original term. The leading
input tags are `All` (225,435) and `ADT` (160,016).

The same annotation performs 2,205,021 substitutions, including 2,108,392
non-variable node rebuilds. There are 531,176 repeated immediately remembered
`(term, binder ID, replacement)` triples and 321,067 non-application leaves.
These counts are opportunities, not avoidable-time percentages. Disposable
WeakMap memoization and leaf/closed-fact variants on `list_sort` did not provide
a convincing general improvement; their short initial series also warmed down
substantially and is not used for a speedup claim.

## A checked weak-head fast path

The first source overlay returns `All` and `ADT` unchanged before entering
`norm_eval`. Its exact behavior follows from the existing evaluator: neither
tag takes a special `norm_eval_node` branch, and `norm_args` with an empty
argument list returns the original term. No child, book lookup, binder or
residual constructor metadata is evaluated or changed. `Var` is explicitly
excluded because it can hold a reducible payload.

Version 1 combines the tag tests with `||`; the actual H emitter evaluates both
as `Bool.or`. Version 2 uses nested `kc` choices so `All` skips the second test.
Both overlays pass the pinned compiler's complete source, ownership and
closedness checks. Component capsules contain the actual Bend-generated `wnf`
assignment and preserve all other frozen H workers. They are explicitly **not**
new whole-compiler fixed points.

Version 1 passed 77 direct exact-term controls plus 31 normalization, 43 kernel
and six specialization checks. Its small source tests preserve generated bytes,
execution (`6` and `42`) and the exact invalid-type diagnostic/phase. The H
capsule independently passed the 77 direct controls and 31 normalization checks.
The first component-test attempt omitted the annotation API environment variable;
that setup failure is retained separately from the corrected successful gate.

## Measurements and limits

All samples use physical CPU 2 and Node v24.18.0 with a 4 MiB stack. Other agents
use other physical cores on the same host. Prepared Base work is outside the
compile timer; a new capsule's first process still builds its own cache, so
process-wall numbers must not be confused with uniformly warm cache costs.

| Experiment | Control median | Candidate median | Interpretation |
| --- | ---: | ---: | --- |
| B1 v1, warmed `list_sort`, three measured pairs | 2.152 s | 1.823 s | Small complete pipeline, exact output |
| B1 v1, warmed `tree`, three measured pairs | 0.950 s | 0.881 s | Small complete pipeline, exact output |
| B1 v1, fresh `literal_rows_cubic`, three pairs | 50.101 s | 53.774 s | Mixed individual pairs; no general gain |
| H v1, fresh `list_sort`, three pairs | 5.709 s | 5.665 s | Essentially unchanged |
| H v2, fresh `list_sort`, three pairs | 5.337 s | 5.261 s | Small difference, insufficient for promotion |
| B1 v2, prepared literal annotation, three pairs | 11.617 s | 9.742 s | 1.19× isolated phase; not an end-to-end claim |

The prepared annotation test captures exactly the same arguments from an
accepted full compilation, warms both APIs once, alternates their order and
runs explicit GC outside each timed interval. Every annotated result equals the
control structurally; the 707,748-node input graph remains unchanged. This
separates the phase from loading and cache/JIT history, but cannot establish a
whole-source compiler benefit.

An earlier dual-API large run was killed with exit 137 during the shared host
resource incident around 14:40–14:56 UTC. Its incomplete report is retained and
its timings excluded. Memory pressure is plausible but not proven as the cause.
The completed fresh-worker replacement caps each child at a 3 GiB heap; observed
maximum RSS was approximately 0.8–1.3 GiB. The prepared experiment retained both
APIs and reached approximately 1.6 GiB RSS.

## Reproduction and next hypothesis

The archived configuration files contain exact paths and output expectations.
Use a fresh output directory for every command. The principal tools are
`analysis-real.mjs` (counters), `analysis-checked.mjs` (checked B1 gates),
`analysis-fresh.mjs` (alternating fresh workers), `analysis-capsule.mjs` (checked
Bend H capsule), `analysis-h-gate.mjs` (H exact controls), and
`analysis-prepared.mjs` (same-input phase isolation), under
`selfhost/tools/performance/phase4/`. The prepared tool requires `--expose-gc`;
pin its parent to CPU 2. Fresh-worker tooling pins its children itself.

The follow-up is to attribute closed, application-free substitution roots to
actual compiler operations and test a reusable fact for the exact immutable
telescope. Merely proving the substituted variable absent is unsafe:
`subst_node` invokes `core_rebuild`, which beta-reduces application nodes. A
safe unchanged-term case excludes **all `Var` and `App` descendants**. A fact
must be recomputed or discarded when normalizing a `Ref` or `Ann` reveals a new
telescope; the syntactic fact about the old reference says nothing about its
unfolded definition. This extends the guarded
[Phase 3 substitution experiment](../phase3/emission-analysis.md), rather than
repeating its invalid absent-variable shortcut.
