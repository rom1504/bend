# Placement-view v1: correct finite controls, insufficient machine change

Root-owned source/API, own finite controls and all six emitted-program oracles passed. The first five-round balanced screen (`selfhost/build/phase195/screen-runtime01/report.json`) did not establish benefit: editdist 1.01266× baseline, local-pair 1.06549× with roughly 6% dispersion; other cases were near 1.0. This candidate is not qualified or selected on that evidence.

Bounded disassembly of `selection-dev-build01` versus Phase194 `native45-02` shows the same modest change in both row kernels: **77→74 loop instructions, MOV56→53, explicit frame accesses20→19, frame3136 unchanged**. The final masked store index gains a direct register home; the two minima and their intermediate publications remain spilled. CMP still copies register-resident inputs through R10/R11. Thus projection did reach allocation, but the hoped-for large pressure reduction did not materialize. A three-instruction static reduction is not evidence that the timing should improve.

The zero-read deletion contract remains limited to certified private predicate temporaries. Their whole-function dynamic observations are exhausted by the exact syntactic corridor counts, including copies and empty Ifs, and the selected emitter performs no original predicate writes. Projection therefore removes only analysis reads/writes absent from actual emission; it does not remove an emitted runtime read. External copies, protected parameters/setup, source overwrites and failed certificates retain original placement. Machine controls exercise simultaneous live old values and independent widths; they are finite evidence, not a correctness proof.

Preserve v1 files unchanged. The next experiment `physical-select-v2.bend` targets the actual residual CMP/CMOV snapshots and publications with original allocation, so it should be measured separately from v1 rather than attributing a composition result to projection. Hybrid/global-regional allocation work belongs to the separate architecture investigation.
