## Decisions and order

1. Pin a stable Bun executable and record its version/revision/hash. Compare
   unchanged upstream TypeScript on Bun and Node, unchanged JS B2 on both hosts,
   and current native B1. Use six-source rotated serial fresh/five-request
   screens, exact complete output C and stable input hashes. Measure process
   startup/Base/request/output separately where existing APIs expose them.
   Native's authenticated prepared Base differs from upstream's source loading;
   report both actual workflows rather than claiming identical internal work.
   Upstream CLI/bundling is a separate screen with telemetry disabled; distinguish
   a local package from an actual released binary. Adopt Bun reference naming
   prospectively and preserve Node history; denominator changes are not gains.
2. Explain repeated native growth with bounded diagnostic counts of string
   append/copy/allocation/destruction where feasible. Reuse exact native C and
   existing phase clocks; diagnostic derivatives have distinct identities and
   do not enter clean timing. Compare complete C for every diagnostic request.
   Increasing time alone does not prove a leak or a particular allocator bug.
3. Prototype general consume-once NC_Code composition. Destructure hit before
   lowering miss, transfer owned fields once, preserve eager miss work, first
   error, fresh names and order. Compare full products on tiny nested/error
   controls before acquiring a full candidate. If gains justify it, test an
   ordered output-chunk representation flattened once; no workload-name rules.
   Preserve full emitted C and the JS development gate. Test a changed native
   image in live mode before authorizing its exact cache consumer.
4. Audit native B2 feasibility. Start with assembled single-source compiler;
   identify only the effects needed for self-emission. Tiny native file IO
   controls precede an allowlist extension and a self-emission attempt. Native
   B2 and native B3 remain distinct qualified artifacts; ordinary installed JS
   B2 stays available. Do not silently expand foreign trust or cache admission.
