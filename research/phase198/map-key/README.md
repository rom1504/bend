The pinned Base implements a Patricia trie over String. At each visited trie node, a bit position is split into a character index and an offset in a 33-bit alphabet. Offset zero distinguishes a present character from the end of a string. Offsets 1–32 select a bit from that character. Lookup, insertion, replacement and deletion repeatedly pass the original key to this operation.

The selected Phase198 N2 executable already contains a borrowed reader. Its Map128 symbol `$p118borrow.read.Map.bit.go` starts at 0x406eef. The positive-index edge at 0x407254 decrements the character index and jumps back to 0x406f22 with the next cons as the new key. Every new call receives the root again. The hot ordinary constructor path reads the heap's head and tail fields, stores them in two slots of its 2,592-byte frame, then reloads both before testing the index. The zero-index data-bit arm reads the raw low 32-bit character value. The borrowed worker contains no constructor rebuilding and no character unboxing call. Its fallback helper checks tag/layout and its shared-object path follows the reference header. The compiler has therefore eliminated the source-level String reconstruction while retaining repeated scans over boxed String spine cells. The selected N2 Map128 ELF hash is `7c19ccabba9036e0ae4f2601feaef82f2c53469b293de517f00e2d1dd880c9f4`.

The [independent cursor implementation](cursor.py) reads actual linked cells and reproduces all 3,323 probe values. Another 2,104 scalar checks cover empty strings, wide characters, non-Unicode U32 boundaries, reversed indices and very large positions. The cursor calculation resets at each individual seek, put, insert or pop operation. It restarts at the root for a decreasing character index. Neither input had a decreasing index within one of those operations. A cursor caches the last selected character and the borrowed pointer to its suffix. These counts price out pointer walks, not time. [Per-operation and per-position results](traces.json).

A general compiler rule could carry a private cursor across recursive calls to a read-only indexed observer when its owning key is proven unchanged and alive until the walk finishes. Its state would bind the owning root, index, terminal state, last raw character and suffix. Different roots and decreasing indices restart the lookup. The existing public Map workers frequently return to the work loop. A pointer into the old worker's stack cannot cross that transfer. A raw address keyed across operations can alias a new allocation after reclamation. Such a rule needs a checked lifetime across every segment, or explicit ownership of the cursor suffix with its corresponding reference-count operations. Keeping a process-wide address cache has no such proof.

It answered all 3,323 churn queries but could not cover either leading nonbyte character in the record workloads. Only the two-character pivot design below was compiled and timed. ## Two raw characters at the current root's differing position

The Unicode record workload constructs department keys beginning with `部門`. An eager byte prefix from character zero cannot represent either character. In the independent whole-program replay, it answers zero of 3,829 probes on record aggregation 256 and adds 512 cons reads. The current Patricia root already supplies a bit position separating at least two live keys. The alternative reads two characters beginning at that position's character index. A new split before the current root, or a later query outside these two positions, uses the original observer.

The aggregation replay performs actual department lookup, insertion, update and ordered rendering. These are semantic traversal counts. They exclude scalar operations, reference-count work, packing overhead and any change in how the compiler passes products. [Per-workload counts and oracles](window.json).

[pivot.py](pivot.py) emits the private generic Map operations and [pivot.bend](pivot.bend) implements the actual two-word reader. The triplet of scalar parameters carries an absolute character index and two U32 slots. A missing character is encoded as 0xffffffff. The two exceptional input words 0xfffffffe and 0xffffffff both encode as 0xfffffffe and take the original read path with the owning key. All Unicode scalar values fit directly. Null and missing are distinct. An empty tree or a leaf uses the original operation directly. The independent 18-key control includes two distinct long keys sharing 32 nonbyte characters, empty and embedded-NUL keys, U+10FFFF and all three upper U32 boundaries. Its 32-item replay takes 103 ordinary fallback paths, including 21 for the escape encoding, and the full map digest is 2641268989.
