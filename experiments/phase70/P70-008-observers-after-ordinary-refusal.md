# P70-008: reserve observer planning for owners without an admitted ordinary worker

Registered before preparing or executing the candidate. The parent observed
that the active hidden-scalar-error diagnostic did not reach its observer
adapter: an existing admitted private NF call bypasses the scheduler hook.
This is consistent with Phase70's deliberately local scheduler substitution.

Hypothesis: skipping observer planning when the exact original owner is already
in the final ordinary NF-ready set removes redundant analysis and C helpers,
while retaining the important non-tail reconstruction cases rejected by ordinary
workers. Map/String/Tape are motivating structural cases, never name rules.

The source base is `observer-integration.bend` SHA256
`994f9f771f109d7e38b7bd21b2dd3b344a415d91a7c5bc1ae71fd6735d80fb1b`;
the observer-emission02 checked B1 used for source inspection is
`d59577dbd15cd31b8c04bf6243d70fb3969c365f07f7a933ca152253f2a85a5e`.
All earlier checked permission, typed schema/origin proof, ordinary admission,
raw/device fallback and worker representation facts remain requirements.

The optional patch adds one lazy guard inside `no_route_one`, after direct-entry
eligibility but before `no_observer_plan`. It consults the existing ready list
for the **exact original owner**, not `$product.owner`, source spelling,
annotations, elapsed cost or a benchmark name. Ordinary retry/admission has
already finished. Observer additions only extend ready with distinct private
names, so this membership test continues to identify the original route.

This is a compilation-cost policy, not a new semantic proof or dead-code
theorem. An ordinary-ready function can still be called through the scheduler
from a dynamic/nonflat caller and might benefit from borrowing there. The rule
forgoes that potential runtime gain. It also forgoes simple fixed-prefix
observer optimizations even though their typed identity proof succeeds.
Existing private NF callers already bypass the observer and are unchanged.
Owners with only an admitted `$product.` worker remain eligible in this first
scope; determining complete call-path redundancy would require more analysis.

`no_observer_plan` itself remains unchanged and query acceptance must match the
baseline. Emission admission gains a separate `ordinary-worker-already-ready`
reason: a sound accepted plan may intentionally have no emitted observer.
Version affected emission oracles explicitly; do not relabel prior semantic
acceptance as a proof refusal. Original runtime goldens remain unchanged.

First validation: qualified B1 source build, unchanged semantic plan queries,
exact retained observer bodies/hooks for nonflat witnesses, and an explicit
report of skipped owners. Compare the relevant pre-existing ordinary worker
signatures/bodies as well. Run the existing semantic/error controls through
their selected routes. A skipped adapter cannot qualify observer-specific
error handling merely because its ordinary fallback preserves the error.

Then use alternating baseline/candidate native-emission requests with a small
multi-family subset, recording plan attempts, accepted/skipped owners, emitted
C bytes and Clang time separately. The predicted saving is the measured time
spent planning/emitting already-ready owners; there is no justified whole-
compiler percentage yet. Ready-list membership costs remain and must be
included. Reject the policy if important observer paths disappear, compiled
program speed regresses materially, or compilation savings are negligible.
Broaden runtime/B1/B2 checks only after a useful fast-loop result. No host
algorithm replaces the Bend analysis, and no production change is selected by
this registration.

Status: prospective source-only experiment. Parent owns all target execution
and any decision to enable it.
