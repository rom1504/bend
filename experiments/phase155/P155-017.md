# P155-017 — Replace the eager token list with a one-way fused lexer/parser cursor

Status: **rejected-static**. [Overall report](../../implementation/phase155/README.md).

Family: [frontend](frontend/README.md).

**whatWorkDisappears:** Intended token-list/FInput construction and reversal; currently coupled to persistent parser positions and checkpoint identity.

**scope:** Reject the proposed local one-way substitution, not all possible future lexer/parser fusion designs.

**reason:** The actual parser requires repeatable lookahead, rewind with a newer context, synthetic-token pushback, and exact original-token checkpoint identity. A one-way consuming cursor violates those interfaces; a persistent cursor without memoization may rescan source. No bounded replacement preserving these contracts is provided, so this row must not be performance-tested or scored as a measured loss.

**limitations:** Source audit only. No target run, native counterexample execution, throughput number or impossibility theorem. A redesigned memoized/token-buffer parser remains separate work.

This screen is not production qualification or a whole-compiler speed claim. See the
frozen specification and independent audit before choosing a transfer experiment.
