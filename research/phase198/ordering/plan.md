# A runtime comparison returning an ordinary Bend constructor

ABI11102 returns an allocated-free, packed Ord value for U32.cmp and Nat.cmp. The shared runtime reads the constructor IDs at bind time from the program whose object owns the generated function. Its two scalar inputs are already in an explicit scratch buffer. The verified module has access to the same constructor dictionary before placement. A successful selector requires exact types and arity, the correct state parameter, three distinct nullary constructor identities below 65536, and the original fallback for every other call shape. The low-word and full-word operations differ on inputs with nonzero high bits. Dynamic descriptors that rebind another program are outside the private function contract.

Physical counts motivated this test. On one complete Unicode-64 benchmark invocation, 769 of 779 measured runtime primitive dispatches were Ord comparisons. The generic edit row had 1,079 out of 1,373, and the Map/set program had 84 out of 171. These are call counts. They leave string ownership work, child pointer loads and general Bend execution unaccounted for.

Emit a word/quad compare, three immediate tags and two conditional moves. MOVABS preserves flags. Use all three arbitrary IDs from the verified program. The independent C fixture deliberately gives equality ID zero and less-than ID 65535. Compare both the textual assembler and direct object results using full-width adversarial operands, then time the complete checked-source products. The outcome depends on the cost of the remaining argument buffer stores and the larger caller, including instruction placement.
