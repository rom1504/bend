Start with the [completed report](../../../../implementation/phase90/README.md)
and [native usage guide](../../../../docs/self_hosted/NATIVE_HOST.md).

run Node or replay the entire experimental history. The adjacent public asset

For the short compilation-speed/output check, use [final-screen01](final-screen01/README.md).
Its completed six-source/two-round campaign took about 47 seconds including
setup and final verification. It compares upstream TS/Bun, genuine JS B2/Node
and native07 with explicit clock boundaries. Use a new output directory for
each run. Full input preflight runs no targets. Historical raw image/oracle
dependencies are preserved in the evidence capsules; it is a benchmark method,
not a standalone portable package.

Full native self-emission takes about 164 seconds; building its optimized C
takes about 308 seconds. Use the small screen and mechanism-specific controls
before repeating those gates. [Runtime migration](runtime-migration01/README.md),
[native comparison](native-comparison.md), [formatting checks](broad-tokens02/README.md)
and the [bootstrap recipe](bootstrap/compiler07-cycle.json) bind the respective
methods. Recorded recipes retain their preparation-time status; actual outcomes
are in the completed report and receipts, not inferred from a planned command.

`evidence01` through `evidence05` are immutable successive capsules, including
failed approaches. `runtime-migration01/public-assets01` is the smaller usable
native asset package; `runtime-migration01/cli-evidence01` preserves public
requests outside the main Phase90 raw directory. `finalize.py` joins the final
completed qualification; `execution-ledger.py` accounts for guarded jobs without
executing targets. Never silently rebind a historical image to changed runtime
assets or overwrite an earlier attempt.
