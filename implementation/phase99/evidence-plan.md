## Compact index and archive reuse

[index.py](../../selfhost/tools/performance/phase99/index.py) writes a small
navigation index of source recipes and suite reports, copying declared statuses
and pinning every indexed receipt. It does not requalify a result or collapse
failed attempts into successes. Deep raw guard/output files stay in their trees.
Run it once all result writers have stopped, choosing a fresh index filename:

```sh
python3 -B selfhost/tools/performance/phase99/index.py \
  --out implementation/phase99/evidence-index01.json
```

[evidence.py](../../selfhost/tools/performance/phase99/evidence.py) is a tiny
adapter over the pinned, tested Phase98 archive algorithm. It verifies the parent
method hash and checks that only phase names in string constants change. This
preserves content deduplication, 64 MiB parts, exact modes, verification and
missing-only restoration without copying another archive implementation.
The prior [Phase98 evidence capsule](../../selfhost/tools/performance/phase98/artifacts/evidence01/receipt.json)
and upstream/toolchain acquisitions remain explicit external dependencies.

After all Phase99 method, report, index and evidence writers are closed:

```sh
python3 -B selfhost/tools/performance/phase99/evidence.py seal --frozen \
  --out selfhost/tools/performance/phase99/artifacts/evidence01
python3 -B selfhost/tools/performance/phase99/evidence.py restore \
  selfhost/tools/performance/phase99/artifacts/evidence01/receipt.json --verify-only
```

The adapter selects existing Phase99 build/method/proof/design/research/report
roots and the inherited public-host/document roots. It excludes its own archive
output and public release capsules; if a new public capsule is created, pass its
receipt with `--public-assets`. Sealing retains failed and partial attempts and
requires space for both temporary archive and split parts plus the existing
160 MiB reserve. Never seal while a build, collector or document writer is active.
No production archive or index has been generated by this preparation.
