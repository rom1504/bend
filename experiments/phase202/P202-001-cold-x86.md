# Cold x86 compiler acquisition and reproduction

The objective is 37 seconds from compiler source to a freshly linked native x86 compiler, including emission, without reusing compiler-source products. Use the established single-core Phase198 request. Pin source, Base, prepared Base carrier, runtime, output and producer separately. Reusing that previously qualified Base carrier is part of the frozen request definition.

1. Run the saved Phase201 compiler on its own source and compare the fresh object and executable with the independently acquired product. Use the existing physical sampler on this diagnostic run. For clean timings, acquire the new source with Phase201 and reproduce that identical source using the new compiler, with no instrumentation in either role.
2. Remove the complete intermediate ELF body byte list. Validate all sections before opening stdout. Test a late-invalid relocation for zero output. Count encoded section lengths from validated facts if exact section ordering, padding, symbols and relocation controls pass.
3. Replace the linear string catalogue in x86 opcode decoding with first-character dispatch followed by exact suffix checks. Test all supported spellings and near misses against an independent table, then compare generated objects on real source.
4. Test early reuse of a repeated pop/apply continuation. Require agreement on arguments, state offsets, output and relocation as well as the surrounding verification and hygiene rules. A template mismatch must fall back to ordinary lowering. Only use this in the research image if the focused controls pass.
5. The strongest end-to-end comparison is two distinct compilers processing the same new source to identical linked executables with the same runtime. Also measure the original frozen Phase198 request when the time budget permits. Distinguish physical-profile timing, controlled standalone execution, acquisition, self-reproduction and broad qualification.

The full-scope target requires eliminating more than 90% of the historical 373.57s. These candidates attack specific repeated work. The full profile will establish which categories still dominate if they fall short. Keep the certified installation available throughout.
