# Actual-query scalar-consumer ceiling

`prepare-v01.py` freezes four small programs from exact qualified Phase134
compiler declarations. It only copies source and writes identities/oracles; it
runs no compiler or target. Existing frozen outputs must remain byte-identical.

`cases-v01.json` is consumed by the coordinator's emission/build harness. Cross
both source compositions with baseline and width16 producers. The two families
are `queries` (real `f_find`, `lookup`, constructor ownership) and `record`
(unrelated nine-field label observer). No production compiler file is edited.

Run each native product without arguments for the23-line independent oracle in
`expected-v01.stdout`. A positive numeric argument runs the timing loop: three
lines are the one-iteration value, modular repeated checksum, and milliseconds.
Use the per-case `timed.once` field (`127` or `1`) to validate every timing sample.
The initial10,000-repeat suggestion is only a calibration point. The supervisor
must bound execution, select enough repeats for a stable interval, and preserve
both inner and total process clocks.

See [the investigation note](../../../../../implementation/phase137/query-notes.md)
for semantic assumptions, source changes and limits. Actual compiler names are
used to construct a controlled65-row book; this is not represented as the real
compiler's checked book or profile distribution. Inspect native worker admission
and reference-transfer counts before inferring the optimization mechanism.
