actual completed `emit-self-v7.mjs` report. It verifies the exact method hash,

After root's actual guarded Clang build:


The second command accepts `--check-only` and optional `--self-source`. All eight
real live/cache controls remain mandatory. The old exact-C oracle cannot simply
be waived: `whitespace_oracles.py` requires the actual four-case default-CPU
preprocessing proof from pinned `whitespace-check-v2.mjs`, its completed outer
guard/input receipt, successful identical Clang commands, retained unchanged
headers and effects, and complete equal preprocessed output bytes. It links each
old C digest to the independent old B2 oracle. Every new live/cache result must
then match the corresponding **new raw C** digest and length exactly.

The CPU proof does not qualify GPU branches or arbitrary raw `N_Segment` bodies.
It does not qualify the whole compiler's semantics or execution speed. Public
cache/image admission, broad conformance and native fixed points remain separate.
