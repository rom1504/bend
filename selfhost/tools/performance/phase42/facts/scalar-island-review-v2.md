# Scalar-island static gate scope correction

The Phase40 controller required entire emitted raytrace module identity. The actual checked16 module fails that condition: it adds the inert Nat.add runtime snapshot and guarded acyclic helper alternatives in sixteen generic public sections. This is an intentional broader source-emission difference, not an unchanged-module claim.

The protected full G[colf] and G[rowf] sections are byte-identical to Phase39, including all private scalar helper declarations, entry validation, dependency arrays, proof opening/closing and original fallback bodies. G[colf.px], G[colf.px.go] and G[subray] are also byte-identical. The versioned [controller](list-scalar-island-controls-v2.py) retains the original fixture Nat headers, absence of Nat structural tree workers, private leaf call, host/local/dependency guard checks and absence of a new private scalar root. Replacing the scalar-island path with the old regressing Nat worker would violate both full protected-region identity and worker/root refusal assertions; this correction does not accept that shape.

V2 records moduleByteIdentical=false and every changed public-section baseline/candidate hash. Removing exactly the three inert runtime metadata hunks and replacing exactly those sixteen sections must reconstruct the complete baseline byte-for-byte; differences anywhere else refuse. Its candidate hash pins the actual checked16 emission, not a future image. The complete behavior/performance of the changed generic helper regions remains the responsibility of the actual checked-image semantic/runtime gates; static protected identity is not an equivalence proof for those changed regions.

The original controller and its failed integration03 report remain retained. The successor needs a fresh bounded root run, exact selected API/runtime/Base/attempt and raytrace emission receipt bindings, plus an explicit collector assertion for all three checks and protected hashes. No prior receipt is relabeled. Python syntax was checked; the facts owner did not run targets or change production source.
