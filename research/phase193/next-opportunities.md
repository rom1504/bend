# Next opportunities after the Phase193 public-plan adapter

The next substantive experiment should test **bounded value identity before
selection and placement**, with the exact borrowed equality/order workers as
compiler witnesses and unrelated scalar/control workers as transfer controls.
A second, more semantic option is specialization of an already admitted
borrowed observer's neutral accumulator state. Neither requires a new String
representation or a compiler-helper name recognizer. Tiny reflexivity folding
is a useful low-cost first falsifier, not the main parity hypothesis.

This is an offline planning note. No targets, compiler jobs or samplers were
run, and no compiler source was edited. Estimates below are engineering judgment
for bounded experiments, not measurements, confidence intervals or promises.

## Evidence cutoff and the current adapter

The source-audited adapter consumes the original bounded public-fusion and
ready-tail plans; it preserves runtime return, captures, snapshots and complete
fallback. Its finite controls pass, including the independent pending-outer-
continuation observer. See [public-fallback-audit.md](public-fallback-audit.md).

At this note's cutoff, the observed real compiler-helper kernel improves
49.3172→45.5090 ms, or 7.72%, in twenty balanced pairs. The four selected
development cases have geometric candidate/parent ratio 0.923694; Map improves
19.81%, expression 4.95%, tree 1.79%, lexer 2.75%. These are kernel/development
results, not a held-out suite gain or a compiler-request gain. Qualification and
actual compiler-cost results belong to the root-owned campaign report as they
arrive. See [research-economics.md](research-economics.md) and
[compiler-hot-transfer.md](compiler-hot-transfer.md).

After freezing this adapter, compare future candidates against that exact
selection. Phase192 profiles are directional evidence, not a measured residual
budget after the adapter: removed dispatch and changed helper composition can
change both leaf shares and register pressure. A modest final Phase193 result
does not erase the established source coverage correction or justify expanding
its recognizer during the same evaluation.

## Ranked bounded experiments

Percentages are prospective reductions in elapsed/runtime for the stated
scope, conditional on successful implementation and real hot coverage. Zero or
a regression is credible in every row. Suite means the complete native44
geometric aggregate, not the selected four-case screen. Compiler means the
fixed small map/set request unless explicitly broadened. Bounds are judgment
bands to choose an experiment, not probabilities; they must not be added.

These are elapsed hands-on/research-lane planning budgets for a *prototype and
first falsifier*, assuming the current prepared assets and serial lane are
available. They are not measured agent costs, guaranteed completion times or

required broader legality work ends the bounded experiment; it does not silently
turn a two-hour test into a global optimizer rewrite. Rank 5 can be executed
first as rank 1's cheap mechanism test without calling it a separate major win.

## 1. Value identity: reuse one fact mechanism, then select before placement

[string-machine-frontier.md](string-machine-frontier.md) identifies repeated
integer self-tests, reconstructed raw/boxed Boolean predicates, repeated CID
extraction and stack transports in the exact current compiler ELF. The more
recent authenticated [compiler-profile witness](compiler-profile.md) counts
97→213 instructions on one continuing unshared equality path and 101→154 on
one ordering path. These are selected static paths, not dynamic averages.

Source evidence explains why another independent peephole is insufficient:

* `back/x86/expression-reuse.bend` tracks bounded aliases/expressions, clearing
  state at branches; `x190_local_values_body` tracks local width/copy facts.
* `back/x86/predicate-normalization.bend` separately tracks exact 0/1 facts.
  Its current equality simplification covers Boolean constants, not all
  reflexive integer operands.
* `back/x86/regalloc.bend:x185_fact_body` deliberately excludes scalar-Return
  bodies because the reused private-body simplifier lacks that terminal model.
* The joint allocator has bounded name candidates; a mutable spelling can
  represent unrelated definitions. Phase192's numeric witness retains three
  XMM→GPR→XMM pairs around independent F32 definitions of the same `value` name.

The smallest general next slice numbers *definitions* within one bounded pure
region and resolves operands before rebinding destinations. Reuse the identity
conventions from the existing Phase192 path-fact prototype; do not enable its
whole expression/path machinery merely to get local identities. Fold exact
integer self-comparisons, carry canonical 0/1 and width facts, and present the
result to selection before register placement. Replace or shrink overlapping
local walks if practical, so an extra pass does not tax every compiler request
for a few target instructions. Keep Return/Result/Again terminal handling exact.

First falsifier: the four known reflexive tests must disappear, and at least
one additional *hot* repeated expression or transport in the same two readers
must disappear for a general-value prototype to justify its extra complexity.
Observe a numeric or lexer/control witness independently. If only the four
self-tests change, retain the tiny fold if economical and reject the larger
identity machinery at this scope. Do not raise allocator bounds to manufacture
coverage. Floating definition-versioned homes are a separate follow-up, with
NaN/full-word publication controls, as described in the
[Phase192 architectural survey](../phase192/architectural-survey.md).

The later 3–8% suite band requires gains across several families; it is not
supported by a single borrowed-string witness or promised by global SSA. Full
dominance/phi construction, loop value numbering and MemorySSA are outside this
experiment. Existing definition identity can eventually serve integer, floating,
predicate and address consumers, but those benefits need separate measurements.

## 2. Borrowed-observer state specialization: stronger potential, narrower proof

`core/consuming-strings.bend:p88_string_eq_go` carries `same`; its only continuing
SCon/SCon arm has `same=True`, then tail-calls with character equality.
`bend2/base.bend:String.order.go` similarly continues only for `EQ`, then
tail-calls with `U32.cmp`. The exact order machine path calls `p111_rt_op` once
per continuing character. Repeated accumulator decode/match work is therefore
connected to an actual source recurrence, not inferred solely from assembly.

`back/qbe/ownership.bend:p118b_lower` already consumes `NO_Loop` and `NO_Match`
from admitted observer plans. `back/qbe/borrowed-regions.bend:p128bs_functions`
builds the borrowed reader and an outer guard/ownership adapter that retains the
owned fallback and disposes of the roots. This is a possible semantic boundary
for a bounded variant that starts in a known neutral state, keeps that state on
continuing edges and returns the actual nonneutral scalar result on exit.

Investigate whether the existing observer plan proves the needed behavior before
writing a new recognizer. The general admission would be a scalar accumulator
with one known continuing state and a checked tail recurrence; source function
names and literal String layouts are not admission criteria. Preserve the outer
guard, root lifetime/drop behavior, source match ordering, layout checks and
fail-stop behavior. Skipping a match or load merely because ordinary typed
strings look valid is not enough. If the plan cannot establish that reordering
or omitting the next terminal iteration is observationally safe, stop or retain
that terminal iteration. This is why specialization costs more than reflexivity.

A useful first witness removes the repeated neutral-state decode on continuing
iterations without code-size explosion or new native recursion. Check ordinary
list/tree read-only predicates with scalar state as unrelated transfer cases.
Do not claim that the order runtime call disappears unless a separately checked
general U32 comparison/result representation lowering actually removes it.
QBE also calls that helper on the retained path, so this is potentially beyond
matching QBE machine selection, with a correspondingly stronger proof burden.

Before any full-image build, emit the unchanged compiler helper closure and
inspect the actual borrowed worker plus a second observer. Test equal strings,
early/late mismatch, empty/unequal lengths, Unicode words, shared/static/RFC
roots, malformed IR refusals and complete cleanup. Then require a balanced
compiler-helper runtime screen and ordinary-program transfer. A real compiler
request remains necessary before assigning any kernel improvement to the
compiler.

## 3–5. Small residual mechanisms and known negative evidence

[ownership-frontier.md](ownership-frontier.md) identifies repeated metadata
checks in `p125_rt_take2`, with 5.22%, 1.89% and 0.60% of weighted samples at
the named metadata PCs in tree, expression and lexer. These PC shares are not
removable ceilings. The compiler's whole helper is 5.66% of its sampled CPU,
and most of the helper must remain: field copies, RFC/view/count behavior,
static boundaries and reclamation are useful work. Preserve the existing
runtime contract and refuse blanket call-site expansion: both Phase186 inline
unique-take variants regressed despite attractive static work removal.

[region-control-frontier.md](region-control-frontier.md) provides an authored
generic constant-edge matcher and independent state oracle. It removes two of
six instructions on admitted loop edges while preserving TEST flags and all
stores. Coverage is only four scan, two warp, six eval and one lexer-gen edge
in retained objects. This is a small optional experiment; the failed scoped-
frame expansion and speculative deletion of scratch stores remain excluded.

Reflexive folding has the clearest low-risk machine witness and the smallest
measured budget. `p112_special_selected` emits `eq(word,word)` for canonical
Chr/U32/F32 representation matches, so ordinary scalar-pattern workloads also
qualify. The comparison is integer-word equality even for F32's representation;
do not fold floating `x==x`. Reuse existing termination rules for branch pruning
and let the dead-write pass remove unused condition assignments. Do not remove
the Return-safety guard from the older shared simplifier.

## Magnitude, nonadditivity and a useful decision even if Phase193 is modest

The two exact borrowed reader leaves total 0.5913s of the 5.6607s Phase192 x86
request, about 10.45%. A hypothetical 30% reduction of both leaves, with all
else fixed, saves about 3.13% of the request; 50% saves about 5.22%. Matching
their QBE leaf estimates saves about 0.2318s, or 4.10%. These sensitivity
calculations explain the specialization band; they do not measure causality or
include new compiler-pass overhead. Entirely eliminating both leaves would
still save only about 10.45% under this fixed-share model.

Matching the complete QBE request 4.0933s from 5.6607s would reduce CPU by
27.69%, not halve it. QBE is a comparison point, not a universal upper bound.
The qualified Phase192 suite is 2.208723× mature C; a hypothetical 10% suite
reduction would still be about 1.988× C. Reaching parity from that baseline
requires roughly 54.72% less time. Neither 213 versus 97 static instructions
nor any sum of helper shares supports a 2× end-to-end speedup claim.

The hypotheses overlap heavily: value identity can remove checks that observer
specialization would remove; specialization changes lifetimes; fusion changes
dispatcher/ownership demand; certified take changes shared metadata work.
Measure each against the frozen adapter, then measure the composition. Even
independent percentage reductions compose multiplicatively, and these are not
independent. Additional compiler passes can erase their own generated-compiler
benefit. Keep small-request compilation, full-source acquisition, user runtime,
memory, correctness and total research cost separate.

The useful next decision is therefore concrete: preserve the Phase193 adapter
result and its limitations, spend one bounded session on exact integer/value
identity in the hot borrowed workers, and stop unless actual emitted hot code
and an unrelated workload improve. If identity gives only cosmetic changes,
the existing observer-plan boundary supplies the next semantic experiment.
If both fail, the ownership certificate is still a measured source-connected
candidate. None requires inventing a new benchmark, claiming recursive research
acceleration, or treating a modest current gain as permission for global SSA.
