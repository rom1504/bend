# Phase65 independent semantic review

Baseline is commit `49431ba`, installed Phase64 State09. Compiler targets remain
root-owned, serial on CPU3 with the established guard. This reviewer performs
source/data work on CPU0 and does not modify production files, installed images,
Git state or closed Phase64 evidence. A proposed control is not a passing result.

## First discriminators

- **Typed facts:** Compare the complete enclosing document, call/SCC facts,
  layouts, host wrappers and emitted module under the old and new private
  producers. A weak-head-normalized annotation type is convertible to its
  original type but changes the public annotation structure; retain original
  public behavior and isolate ownership. Include recursive parameterized aliases,
  partial/overapplication, erasure, rewrites, native/generic layouts and refusal
  budgets. Check actual emitted API declarations before instrumentation.
- **Prepared Base products:** First partition observed work by exact Base
  definition identity, then compare complete annotations in Base-only and real
  request contexts. The annotation environment does not allocate fresh IDs;
  suffix-dependent native stop sets, checked-versus-raw Base, generated
  specializations and request-global SCC facts remain distinct boundaries.
  Annotation equality does not prove lowering or call-graph reuse sound.
- **Structured output facts:** Preserve physical-line marker recognition,
  duplicate-edge ordering, unknown/malformed refusal and full scan budgets.
  Concatenated chunks can split or form markers. Emitter-owned structured facts
  may avoid rediscovery; public/raw text keeps its exact scanner fallback.
- **Composite term reuse:** Substitution canonicalizes every App even when the
  target binder is absent. An unchanged return therefore requires canonical
  metadata, exactly two children and no newly exposed lambda. Nonmatching Var
  nodes do not traverse their attached children. Preserve source spans, removed
  names and KLambda quantity-presence metadata. Compare entire terms and full
  compilation results, not only semantic tags or reduced query counts.

The measurement owner retains minimal successors of existing build, strict36,
export95 and final qualification factories. Focused controllers will use actual
reachable declarations and existing recorded fixtures before broad validation.
No Phase65 correctness result or promotion is asserted yet.

## Reviewed candidate boundaries

The constructor-index experiment retains `constructor_exists` as its independent
oracle. Its prepared index contains immediate children of each non-BookCache
outer definition, including Def and ADT children, rather than only Ctr nodes or
all descendants. Ready prefix admission already excludes Absent and BookCache
children. Exact-name index buckets preserve full-hash collisions. The three
private consumers retain the old name, bound, readiness, error and hash guards;
public raw prefix operations remain unchanged.

`controls/prefix-world-constructor-v1.mjs` is a successor of the passed Phase64
context-v5 controller. It retains all complete checker/result/context, TODO,
maximum, specialization and fallback assertions and adds fifteen direct
membership cases. `PHASE65_CTOR_ONLY=1` explicitly selects only Base preparation,
eight maximum controls and the new membership cases; that receipt is not a full
matrix qualification. The actual State03 checked API has all 29 required
function declarations. No compiler target was run by this reviewer.

The small substitution candidate is justified by a constant-size structural
predicate: at most two leaf children, unchanged mismatching Var payloads, and
exactly canonical Apps whose function is not a lambda. Returning the outer term
preserves spans and KLambda quantity-presence metadata. The old substitution
remains the fallback. This proof does not support a recursive rescan on every
substitution entry or a generic semantic-equivalence shortcut.

The normalized-annotation-head candidate changes the stored public annotation
type. It remains a diagnostic snapshot experiment. Its controller compares full
plan documents, call/SCC facts, layouts, complete modules and independent values
against the original recursive annotation formula; it also binds the actual
snapshot source and verifies that intended aliases were genuinely pruned.

Base annotation reuse has a narrower possible ownership contract. The current
annotation call chain uses exact name lookup and term operations, without book
maximum allocation or whole-book constructor scans. Closure checks must include
implicit literal type names as well as explicit Ref/ADT nodes. Precomputing
stopped or unselected unsafe bodies can change termination, so a pinned Base
producer observation cannot establish arbitrary public-prefix demand equivalence.
Native stop selection must precede reuse.

## Additional focused controls and optional products

The Boolean membership alternative keeps the original lookup as its oracle and
preserves first-match Absent masking and BookCache termination at any list
position. Its focused root receipt passed 29 raw lookup cases and 535 enclosing
constructor queries, including 501 actual Base names. The ordinary missing-name
cases also confirm that the Bool path avoids constructing `missing()` values.
No cache schema changes are required by this alternative.

The constant-size composite substitution candidate passed its focused value and
identity controls but was rejected by the performance owner. Its smaller
leaf-only successor passed 225 full substitution/beta cases plus the 40 inherited
predicate controls. The first leaf controller stopped at a missing `subst_node`
declaration: the optimization made this unchanged helper unreachable. That
failed preflight remains preserved. The v2 controller explicitly records the
raw-helper dynamic skip while verifying its exact unchanged source body and
retaining all mandatory substitution/beta comparisons. These additional receipts
are pinned in
[`reviewed-focused-receipts02.json`](../../selfhost/tools/performance/phase65/controls/reviewed-focused-receipts02.json).

Two independent H2 controllers are now source-reviewed and frozen, pending root
execution. `controls/base-annotations-host-v1.mjs` exercises the real sidecar
writer/reader against a real decoded frame4 graph, using a clearly labeled mock
product. It checks header and parent-graph identity, corruption, reference
subtypes, no-hit and refusal read order, deletion/replacement and optional
fallback. It does not claim semantic annotation correctness.

`base-products/annotation-controls-v1.mjs` separately uses the real owned API and
Bend producer. It requires the independently counted 12 cached definitions and
seven actual Map definition-object reuses, compares entire annotation graphs
and complete modules, and checks request-specific stops, readiness, loader
errors, full-hash collision refusal and the public injected-API fallback. Numeric
and Lexer misses must never read the product body. The cloned helper/runtime
closure is pinned against the checked snapshot. Performance provenance now also
pins the separate products directory before and after every worker, including
no-hit requests and explicit baseline absence.

The two structured-output proposals were deferred before candidate builds after
actual generated-B2 censuses found zero eligible sites in four representative
requests. The first closure observer preflight incorrectly assumed a direct
helper body; its preserved failure led to a successor instrumenting the actual
SCC state. That activated the enclosing path but still found zero eligible Nil
arms. Generated call structure must be inspected before accepting any wrapper
counter as proof of opportunity.
