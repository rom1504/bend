# P67-002: bounded compilation-speed experiment

Registered October 8, 2026. [Design](../../design/phase67/native-speed-and-proof.md) ·
[Results](../../implementation/phase67/README.md).

Inspect existing evidence and current code for one repeated-work reduction,
especially on Map/set. Limit initial investigation to about twenty minutes.
Require a credible material affected-source benefit before spending target time.
Use an isolated patch and a small same-campaign baseline/candidate screen.
Do not force an implementation if prior experiments or current profiles fail
to support it. Deferral, negative evidence and meaningful gains remain distinct.
