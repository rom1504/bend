# Direct x86 speed in a thirty-minute experiment

Start from the qualified Phase198 progress compiler. Its measured native45 execution ratio was 1.2781× mature Bend C. Work on three independent questions.

1. Can the compiler recognize a modular scan in the already verified, fused array worker and lower it to the measured SSE2 computation? Check the real packed-array guard and fall back on other representations. Compare a different element count, capacity, initial state and independent transfer program. A typed compiler change and a linked SIMD runtime leaf must be distinguished from a source-level kernel ceiling.
2. Do three previously measured rules (word primitives, constant division, public tail transfer) compose on this baseline and transfer across the complete catalog? Check the combined compiler source, acquire an independent native N1 and give it the ordinary benchmark sources. Link both timing arms with the identical live runtime and compare against mature C. Record compiler cost separately.
3. Can producer-register reuse be implemented as a checked compiler rule and reproduce the two-layout edit-distance evidence? Require complete output and actual object change on ordinary sources, retaining refused cases.

Use one guarded execution lane and parallel source preparation. Run short admission and oracle tests before timing. The portfolio, scan and spill experiments each have their own baseline and scope. Preserve each fallback and keep the installed compiler available. Native release promotion requires a separate complete qualification.
