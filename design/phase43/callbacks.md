# P43-004: known callbacks before fusion

Baseline is installed Phase42 checked16. Closure points remain roughly 8–9×TS;
list512 is already 0.605×TS through total-U32 fusion. The first-order list
pipeline is not callback evidence. No additional fusion is proposed before a
known-callback win.

Phase39's rejected prototype added exactCode globally and regionProofCovers at
every callback. Direct versus scoped improved about 4–5%, but both regressed
against original. The corrected smallest falsifier retains every materialized
callback/input/result list and passes each dynamic U32 capture as an argument
to the known offset worker. It admits once at the existing default public scalar
interface, adds no exactCode, and tests one private proof token at the callback
edge. Full descriptor and host validation remains at entry. Raw, partial,
overseaturated and foreign entries retain the original runtime.

The actual composition-chain ablation clones only the proved closed chain inside
that scalar entry. It retains original trampoline construction and all composed
function descriptors. Known offsets become partial fn descriptors with explicit
capture slots, adding one capture array per offset; this cost is admitted. A
bounded iterative consumer walks the known composition chain, computes each
original addition in order and passes capture/value to a named scalar worker.
No closed-form sum or chain fusion replaces construction. Generic composition,
returned closures and public chain functions retain their original behavior.

Expected conditional family gain: 1.2–2× if dispatch dominates the original
materialized chain. Unchanged speed or regression is possible. The smallest
falsifier is direct versus same-admission scoped and original in three alternating
serial rounds at 64/256; a direct loss stops source work rather than growing proof
machinery. A fixture gain alone does not qualify actual closure points.

A reusable production proof would track a finite lambda identity set, exact
capture schema and saturation at each application. Producers must remain inside
one scalar admitted component, capture values must be source evaluated once,
and escaped/foreign function fields refuse. Specialization keys include exact
source identity and erased-slot layout. Recursive composition requires bounded
iterative application; native recursive lambda invocation is insufficient.
The proposed proof is not present in JPure, so these are saved-output experiments.

Controls require complete three-stage materialized values, fresh descriptors and
capture arrays, changed/retained captures, distinct callback identities, unchanged
aliases, ordered errors/demand, every dependency/host mutation, raw/staged/extra
calls and proof cleanup. Error construction can reenter: a private active flag
alone is insufficient. The corrected edge requires the current nonnull proof
object to equal its captured token; foreign callback reentry during suspension
must use generic code. Counter modules are never timed. Root owns execution.
