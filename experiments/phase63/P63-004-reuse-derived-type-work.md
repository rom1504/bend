Registered after State05 fresh-process CPU profiles, before candidate measurement.

The State05 Map profile spends114ms in recursive host marshalling. The same
constructor's fields are converted once to select an iterative recursive tail,
then converted again to emit non-tail fields. Compute immutable field-converter
rows once at the original depth/fuel, choose the final self-recursive field and
render from those rows. Preserve field order, shadowed names, empty converters,
refusal fragments and generated bytes. Root integrates the small reviewed patch
as State06, alongside the separately measured decoder; this combination cannot
attribute all end-to-end gain to the field plan.

Larger hypothesis under review: checker-produced application nodes carry the
already instantiated callee telescope. Backend argument lowering discards these
annotations and normalizes/substitutes the telescope again. Retain authenticated
annotations for exact saturated calls, while preserving the original route for
partial/overapplication, missing annotations and uncertain shapes. Compare exact
lowering outputs on dependent, erased-effect, alias, borrow and closure cases;
then check broad raw bytes and self-reproduction. Raw versus annotated actual
substitution is an explicit equivalence obligation. No gain is established yet.

Stop a candidate on semantic mismatch; small cases and profiles precede expensive
self-host rebuilding. Algorithms remain in Bend. Keep generated-program artifacts
identical unless a separately justified backend change is qualified.
