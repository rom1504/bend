# Phase64 representation discriminator

This lane investigates one bounded representation change: a compact constructor
for canonical post-check `Ann(term, type)` wrappers. The proposal and rejection
conditions are in [the report](../../../../../implementation/phase64/representation.md).
No production compiler source is changed by these tools.

`static-census.py` reads Bend source and writes a new, non-overwriting inventory:

```sh
taskset -c 0 python3 selfhost/tools/performance/phase64/representation/static-census.py \
  --output selfhost/build/phase64/representation-static02.json
```

Root alone may run the following controller under the existing serial resource
guard. It performs two real compilations per source; do not run it beside a
latency or profile target:

```sh
node selfhost/tools/performance/phase64/representation/census.mjs \
  selfhost/build/phase63/checked-state09 \
  PATH_TO_NUMERIC_SOURCE PATH_TO_MAP_SOURCE \
  selfhost/build/phase64/representation-census01
```

Use the exact Numeric/Map source paths in the current Phase64 bindings. Add Lexer
only if allocation evidence warrants it. The final output directory must be new.
The controller verifies the checked attempt, binds its frozen driver and runtime,
checks named-layout API identity, observes annotation return graphs, restores the
original entry functions, and requires the entire resulting driver observation
(including generated bytes) to equal its uninstrumented run.

Counts are retained graph shapes at an API boundary. They are **not** total
allocations, timing measurements, a compact-layout speedup or counts of inlined
`kid`/`ks` operations. The additional graph walks deliberately invalidate timings.
Public `inspect({api: ...})` would disable private ready-world permission; the
controller therefore retains the exact object returned by the owning driver's
`loadApi()` and observes its annotation entries in place. It supplies no foreign
API object to the driver.

`census.mjs` was written but not executed by the representation agent. The
source-only census was executed; its recorded input identities and inventory are
in `implementation/phase64/evidence/representation-static01.json`. Parent/root
must run any target and append the result before treating the dynamic census as
validated tooling.

An isolated source candidate is now in `compact-annotation-v1/`: six before/after
Bend files, `candidate.patch`, and a hashed manifest including all preservation
arms. `make-annotation-patch.py` reproduces this structure into a **new** directory.
It does not edit live source or execute a compiler. The patch changes only the
source side and is not eligible for promotion before the host ABI/cache boundary
and correctness gates are resolved. Fresh profile attribution puts the entire
annotation stage at only 0.81–4.10% of sampled allocations across the three probes;
prioritize whole-work-removal opportunities ahead of this pilot absent further
evidence of costly downstream annotation reads.
