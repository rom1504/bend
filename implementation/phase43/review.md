Initial static review read AGENTS, experiment README, current steering and ledger,
the Phase42 generated-JS architecture, and current jpure/tree/finite/region/emit
and runtime proof boundaries. No compiler, program, timing or profiling job ran.

Recommended evolving existing JSPlanContext child1 into reusable typed call and
layout capabilities. BookCache zero-based child0 remains source, child2 remains
scope-owned flat context. Cache reuse alone does not solve missing String,
parameterized-ADT and nested-graph lowering. Exact typed lexical callees can
replace repeated helper expansion, while independent recursion and ownership
checks retain the original boundaries. The design records a minimum adversarial
matrix rather than introducing a validation framework.

Guard proposal preliminary review: full regionHostGuard remains unchanged.
Immediately following it, exact original Object/Array prototype key sets establish
absence of generic marker hooks, so duplicating those absent-marker checks is
unnecessary. Primitive prototype markers/chains, Function.call and every dependency

runtime guard state may survive an invocation. Concrete source patch is pending.

Products source review approved the separate computed-U32 prefix grammar and
Nat-first wrapper criterion for a qualified build. Prefix expressions retain
original let evaluation once and in order; the component's existing 512-node

The root reported saved-output gains, which are not evidence of source activation.

String admission review checked exact native String/Char constructor telescopes,
zero-arity literal wrappers, covered canonical literal substitution and all three
native matcher consumers. Native-match-v2 retains project-based SCon/Chr fields,
including original codePointAt/codePointAt/slice demand order. Branch-local field

were sent to owners: family classification must include normalized aliases and
nested typed containers; the reduced AfterHost guard must enforce the same String
family gate. Syntactic constructor-name scanning alone is not a typed capability.
Per-entry family-once validation is appropriate; no successful guard is cached
across invocations. Actual lexical activation, Unicode, Error reentry, mutable
literal binding and deep-stack controls remain required before promotion.

The total-U32 guard source hook selects its guard and emitted body from the same
successful j_fusion_root_prefix result. That prefix proves normalized U32 input
and result types plus the existing exact pipeline grammar. An empty body retains
the prior full host guard and flat/generic selection. The runtime keeps imul and
broad dispatch/protocol/global checks while dropping float/DataView operations
absent from this kernel. Static review found no blocker for qualification; exact
omitted-hook traces and actual fusion activation remain execution obligations.

A proposed product pair lane can establish local shell ownership by allocating a
fresh buffer only on positive entry, exposing it to helpers solely through
immediate Tuple destructuring, and restricting other parameters to scalars. Both
field RHSs must finish before writes. Whole-shell aliases and generic observers
must be refused; zero iterations return the original shell. This is a proposed
invariant, not an implemented or executed admission claim.

Combined String v3 addresses normalized family classification with a bounded
work queue, specialized constructor telescopes, conservative unknown/exhaustion
and repeated-owner type argument traversal. Thus repeated ADT specializations
cannot hide a String argument behind the owner seen set. The new arithmetic
helper prefix requires an exact U32 telescope, independently valid acyclic direct
plan and primitive-only source body with shared 512-node traversal. Static review
found no new qualification blocker. Reduced AfterHost helpers must still carry
the String-family gate when that separate patch merges. Family constructor-list
expansion precedes the queue fuel check, so compiler cost remains an observation
rather than an inferred aggregate bound on telescope materialization.
