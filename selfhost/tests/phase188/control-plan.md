# Phase188 typed machine boundary controls

The root owns compiler and target execution in the single Phase188 guarded lane. These scripts transport source, authenticate inputs, serialize emitted bytes, and observe external tools. All instruction selection, typed sequence construction, rendering, encoding, relocation, and ELF production remain Bend.

`prepare-api.sh OUT` captures fresh x86 source with the finite fixtures' maintained definition references added as roots before extraction. Both base and x86 profile module lists are scanned. This lexical selection is metadata only; the pinned upstream checker still decides validity. It exports the nine focused Phase186 groups and the frozen Phase187 parser/encoder/ELF controls.

`semantic-controls.mjs` defaults to inline, callee, private, parallel, expression, arguments, floatvalues, xmm, u32float: 160 exact admission rows. All original C observers and expected outputs are unchanged. Five copied Bend fixtures have explicit type/render adaptations recorded in `fixture-adaptations.json`; their originals remain frozen. `legacy-adapters.bend` renders typed operations only at the test observation edge. Its String register adapter accepts only the two registers actually used by the frozen fixtures (r10/r11); unknown names become an invalid register. Two fixtures retain their literal assembly observer setup and return `P188TextOutput`; the other seven return typed `X181Output` rendered by the checked `x188_render` export. These two test-only String fixtures do not establish a direct-object path.

`prepare-typed.sh PARENT_SOURCE OUT` extracts a separate checked API for `typed-controls.bend`. `typed-controls.mjs` requires 36 exact rows, emits the typed program directly without the parser, and independently GNU-as assembles its rendering. Controls cover Empty/Join nesting and both chunk orders; scalar and XMM widths; low-byte REX registers; zero/negative/minimum displacements; full U64 values; section/symbol/alignment/data directives; exact byte bounds; invalid width/register/data/zero count; first-error identity; and undefined local labels. The C observer performs 143 observations of raw U64/U32 arithmetic, comparison, canaries, stack memory, forward/backward branches, external transfer, RIP references, typed data, and F32 publication. Both ELF products must print the exact expected stdout. The direct object must retain exactly the RIP, external-target and data-pointer relocations, with no resolved `.L` branch relocations. `.data` and `.rodata` must match GNU-as exactly. Code widths may differ from GNU-as because local branch relaxation remains disabled in the Bend encoder.

The frozen Phase187 writer-only `p187el_object` directly calls `x187_elf` on an explicit object. Its seven-relocation expectation remains seven; it does not pass through the new local-branch resolver. The diagnostic assembly entry and typed builder may resolve local branches, so expectations from those routes must be interpreted separately.

`native-catalog.py` retains the Phase187 native builder/oracle protocol. It adds `--baseline-report`, defaulting to `selfhost/build/phase187/native45-final05/report.json`. Use `--all --build-reference` and the same explicitly bound new producer for both object and assembly roles. Every complete stdout/count oracle must pass. Fresh GNU-as `.o` files must equal the retained Phase187 assembly objects byte for byte; formatting changes are not compared. Each linked `.text`, `.data`, and `.rodata` section must also equal the corresponding retained role. Old receipts, objects, binaries, source inputs and expected outputs are authenticated. `runtime-manifest.py` then freezes the completed paired acquisition for the existing balanced runtime loop. No speed claim follows from these correctness gates.

Example root lane, from the repository root:

```sh
sh selfhost/tests/phase188/prepare-api.sh selfhost/build/phase188/controls-sourceNN
python3 -B selfhost/tests/phase188/job.py --rss-mib 3072 controls-apiNN 180 128 selfhost/.assets/bin/bun selfhost/tools/build/hosted.mjs acquire --source selfhost/build/phase188/controls-sourceNN/compiler.bend --exports selfhost/build/phase188/controls-sourceNN/exports.json --out selfhost/build/phase188/controls-apiNN --engine selfhost/.assets/bin/bun --upstream selfhost/.bootstrap/upstream-phase182
python3 -B selfhost/tests/phase188/job.py controlsNN 120 128 selfhost/.assets/bin/bun selfhost/tests/phase188/semantic-controls.mjs --api selfhost/build/phase188/controls-apiNN/report.json --assets selfhost/manifests/assets-native.json --out selfhost/build/phase188/controlsNN
sh selfhost/tests/phase188/prepare-typed.sh selfhost/build/phase188/controls-sourceNN-source/compiler.bend selfhost/build/phase188/typed-sourceNN
```

Acquire the typed API with the same guarded command, then run `typed-controls.mjs` with `--api`, `--assets`, and a fresh `--out`. Reuse `job.py`; never nest guards. Only metadata syntax checks were run by the test author. All actual source checks, machine observations, native builds, and timings must be reported from root receipts.
