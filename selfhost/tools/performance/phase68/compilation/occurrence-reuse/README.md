# Local occurrence reuse: source proposal and fast controls

The immutable `candidate-v1.json` records exact before/after source and the
`candidate-v1.patch` (+6 lines, no new functions/types). Both source and
`controls-v1.mjs` have independent source review. No live-source application or
target execution is performed by these proposal files.

The root executor runs the controller under the existing CPU3 guard:

```text
node controls-v1.mjs candidate-v1.json BASELINE_ATTEMPT CANDIDATE_ATTEMPT FRESH_OUT
```

The two attempts must be real strict checked derived B1 images. Every frozen
source input must agree except the declared bridge/flat replacements. The
controller appends diagnostic exports without changing original module bytes,
compares complete NC_Code values, and wraps the existing occurrence collector to
count actual helper calls. It exercises 3,520 pairs plus direct equivalence of
prepared-live and ordinary lowering. These counts are finite test evidence,
not a whole-request timing benchmark.

Require three complete C outputs identical to the qualified immediate baseline
next. Only then measure fresh B1/B2 requests. If another production change
lands first, rebase into a new immutable proposal and retain the original;
do not weaken the source-inventory check.

`profile-census.py` is CPU0 data-only. It computes inclusive sampled unions from
the existing actual09 profiles and records exact inputs. Do not confuse its
sample counts with function invocation counts.

The frozen successor `candidate-v2.json` / `candidate-v2.patch` rebases those
same edits onto the actual Products10 snapshot. `rebase-v2.py` records the exact
replay and complete source provenance. Use `controls-v2.mjs` for its changed
product target shape and renamed `nf_bind_boxed`; it retains the original 3,520
pairs and adds four product call-edge/bundle-result cases. The strict Reuse11
build and actual controller pass. The independent full-C plan is generated by
`prepare-c-equality-v1.py`; it pins the actual Products10 oracle producer and
does not rebuild native executables when entire C bytes agree.
