# Phase198 native qualification

This campaign qualifies the frozen Phase197 minimum-plus-decrement compiler while preserving the installed/default compiler and the mature C runtime reference. The source is `selfhost/build/phase198/selected-source01/compiler.bend`, SHA-256 `e0b08475a80ee226d032e4554e88468e82df2559ae767ed2b7f4cea9f56e0b53`. It is an exact copy of the checked Phase197 full-source assembly. `source-audit.json` binds the source, original source-check receipt, exact executable bodies of all seven checked API roots, and unchanged non-x86 profiles.

Every target job uses `job.py`, CPU3, the shared build guard, explicit memory/disk/time limits and the existing 5 GiB reserve. Each job closes under the mandatory `selfhost/build-retention/phase198` policy. The first N1 wrapper initially attempted an unsupported close-receipt location; the target succeeded, the failed close is recorded, and the successful close was performed without rerunning the target. Source, baseline, tools and runtime are pinned in the job receipts. No concurrent target jobs are permitted.

Replay argv are JSON arrays in `selfhost/build/phase198/*-argv*.json`. Load the array and pass it directly to `subprocess.run`, from the repository root. Replays require fresh output names; existing evidence is immutable. The native sequence is N1 acquisition, N1 native45, N1-to-N2 self-build, N2-to-N3 exact-object reproduction, N2 native45, cross-generation object/section comparison, native64 and runtime10. The selected compiler source and original Phase194 assets remain the same throughout. Experimental compiler rules or runtime changes require separate evidence and do not enter this reproduction chain.

The frozen baseline is qualified Phase195 N1, with its exact source, image and qualification receipts retained. Broad timing uses its existing native45 products and the mature C products from Phase195 references. It does not rebuild or infer a replacement baseline. `compiler-cost-plan.py` authenticates the Phase195 compiler source/image against its original qualification before compiler timing.

`broad-runtime-summary01.json` authenticates all 45 cases (44 timed, one correctness-only), three balanced role positions, and independent outputs. The full result remains unchanged even where follow-up diagnoses noise. `regression-summary01.json` separately reports the frozen five-case, six-pair follow-up. It confirms the fold128 slowdown and preserves every noisy observation. The later five-case minimum/decrement/combined ablation uses the same checked Phase197 APIs and exact common preparation, with no benchmark-specific compiler changes.

`summarize-native.py` refuses to produce a complete final native summary before all required receipts exist and pass, including exact N2/N3 compiler-object identity, all 45 program objects and 135 linked sections, 64 conformance cases and ten runtime controls. `summarize-broad.py`, `summarize-regression.py` and `summarize-compiler-cost.py` are offline authenticators, not target runners.
