`selfhost/build/phase111/p130-native01-n1/program`, SHA-256
`a25e4c7f55a6a48829bf9d148498d6392b98fe1ab66b9664d99ce1987715c2c5`.
Call that producer **N0** within this successor chain:

1. N0 compiles the exact checked source S, producing Q1 and N1.
2. N1 compiles the same S, producing Q2 and N2.
3. N2 compiles the same S, producing Q3 and N3.
4. Q2 and Q3 must be byte-identical. Focused19 must pass on N2 and N3;
   ordinary45 must pass on N3.

The final code-generation policy is declared explicitly. Equality of Q1/Q2 does
not waive step 3. This is a raw-QBE fixed point, not an ELF-byte fixed point or a
mathematical correctness proof.

unchanged aligned builder for each product. Use the final-specific binder:

```sh

  --producer selfhost/build/phase111/p130-native01-n1/program \
```
