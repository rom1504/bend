# Reassociating the continuation of a structural fold

A single recursive child may appear under a constructor tree made by a total builder. Match the consumer on the actual checked constructor identities. If it defines only wrapping U32 leaf projection and binary addition, subtraction or multiplication, interpret each constructed node in that algebra. Folding the result requires no intermediate heap tree. This remains true for a different set of constructor names, a different order of algebra cases, constants, seeds and discriminants.

A second decision concerns the recursion itself. A surrounding expression with one distinguished recursive value x and only these operations denotes A*x+B modulo 2^32. The interpreter descends with two word accumulators m,b representing the context m*x+b. Under a local context a*x+c, the next context is (m*a, m*c+b). The starting context is (1,0). At a leaf of value y return m*y+b. This gives bounded native stack independently of the input count. For subtraction with the varying child on the right the multiplier can be negative modulo 2^32. Multiplication of two variable-dependent children is outside this linear fragment.

The implementing certificate must connect the checked Match arms to the scalar argument/return types and the *actual* source binders. A check on syntax alone could confuse competing ADTs with identical field or constructor names, a packed Boolean with a word, integer overflow with mathematical Nat arithmetic or a recursive call with an alias. Restrict to an independently checked plain datatype and total U32 primitives. Refuse arbitrary calls, effects, dependent result types, floating-point reassociation, unknown shapes and unbounded search. Keep the normal compiler for refusals. Generated private worker bodies cross the same final verifier as other private loops. The unchanged source input and native C output are independent oracles.

Test the first-stage optimization with the ordinary expression workload, extra seeds including word overflow and zero length, and an independently authored datatype with different constructor names, subtraction orientation, constants and operator choices. The ideal-source experiment and the compiler's actual output must be timed separately. We may find fast scalar loops improve the expression cases substantially without making the remaining heap-heavy families faster.
