## Correctness and promotion

Required controls depend on the transformation: exact public/raw/staged calls,
partial/oversaturation, erased arity, full values and alias graphs, constructor
field demand/order, native/host/DataView mutation, error reentry and deep tail
cycles. Source purity, output checksums and matching TS alone do not discharge
all those observations. Keep proof, representation and lifetime facts distinct.

A retained source candidate needs checked B1 plus focused frontend and new owner
controls, applicable inherited owners, normal compile-cost comparison, clean
paired execution on changed families and canaries, and justified integration
gates. Report existing conformance gaps separately. Source/module/definition
counts and emitted bytes accompany speed results; no line reduction claim if
code only grows. Release installation requires artifact lineage and ordinary/
relocated CLI verification; otherwise report an uninstalled candidate honestly.

is not proved by another seed of the same tuned algorithm.
