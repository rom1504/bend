# Independent observer review

This lane reads source and retained data. Root owns all compiler, Node, Clang,
and native execution. The review covers the checked analysis04 query image and
observer-emission02 integration; it is not a formal proof or GPU qualification.

## Admission and ownership

Permission is an explicit Boolean threaded from the checked host entry. The
raw entry passes false. The checked whole-program packed/effect certificate
excludes unknown foreign code and rewriting; the existing audited Base effects
have no root identity or mutable-handle observation. A future effect added to
that whitelist requires this identity-safety audit too. No book marker, private
name, generated C text, or successful structural query grants permission.

The root schema admits narrow immutable recursive ADTs with immediate scalar
fields. It excludes arrays, handles, function fields, unproven representations,
and parameterized roots. Constructor descriptors come from the actual checked
definition. Exact ordered field origins prove reconstruction; branch facts do
not escape their successful arm. Recursive transitions preserve each root's
original parameter slot and exact scalar kind, require strict descent, and keep
the observation as the exact tail result. Cross-branch root maps, changed or
reordered fields, duplicated roots, and demanded work after recursion decline.

The borrowed residual only reads descriptors, computes immediate operations,
branches, and updates by-value cursors. It never passes a borrowed environment
to ordinary ownership lowering. A separate owned adapter retains the original
roots and delegates the final wrapper to existing lowering. Each retained root
and the scalar result occurs once. Fresh binders, a reserved adapter span, and
private-name checks prevent collisions. The public hook is installed after the
ordinary worker route, only for exact nonbang direct entries whose observer and
adapter both pass final dependency admission. Rejected and raw/device routes
keep the prior body. Existing ordinary/product private calls are not globally
retargeted; the substitution is at public scheduler entries.

## Demand

Primitive operations remain explicit ordered residual lets even if their result
is unused. Zero-arity references decline because evaluating them can fail.
Native Succ/U32/F32 constructors decline when virtualizing them could erase a
check. Typed literals preserve their kinds instead of passing through generic
native compaction. The partial-factory concern was investigated against actual
`jd_arity`: a demanded let before a returned lambda stops eta raising, so the
factory executes after its first actual argument. It remains an adversarial
fixture, not a claimed known bug.

The retained twenty-case structural batch admits all nine requested positive
core observers and refuses all five required core negatives. The hidden scalar
error and partial factory are admitted with demanded operations still present;
their execution must be checked separately. Zero-arity and successor controls
decline. Forced-true foreign diagnostics can have valid structural plans while
their production effect permission is false. All false-permission queries
decline. These are structural results, not native-result claims.

## Actual residual and emission

The full Map.bit.go residual preserves character-index/bit-offset ordering,
unsigned character operations, Nat predecessor semantics, and error arms. Its
recursive transition advances only the string cursor and character index.
String.cmp compares unsigned character fields, advances both tails only for EQ,
and returns LT/GT on the correct arms. Their wrapper root order and generated
field/scalar identifiers are consistent with their schemas.

The actual twenty-control C audit finds twelve selected private worker/adapter
pairs with public hooks and eight expected absences. The reachable user foreign
case has observer permission zero. All seven semantic refusals have permission
one but no selected observer artifacts. The two Map benchmark observers also
pass the source audit. C presence alone is not path coverage.

Root's actual native twenty-case gate passes all twenty self-hosted candidate
goldens. Upstream passes fifteen and returns a value instead of the expected
failure in five unused-overflow cases: hidden scalar, post-recursion, zero-arity,
partial factory, and successor. A separate pre-observer compiler01 gate passes
all five failure goldens. Thus the observer preserves the existing self-hosted
demand behavior; the upstream discrepancy predates this change. The full paired
gate is not a twenty-case paired conformance pass. Retained reports are
`observer-emission02-controls20/execution/selected/{candidate,reference}.json`
and `compiler01-observer-mismatches05/execution/selected/candidate.json` under
the Phase70 build directory.

`prepare-active-path-v1.py` records actual adapter entry without changing error
policy, ownership code, or seq flags. Its marker must be present before comparing
the original result/error. The first straight-line hidden-error diagnostic
returned its expected overflow but did not enter the observer adapter: an
ordinary private worker bypassed the public hook. That failed coverage run is
preserved; it does not establish observer demand coverage. The recursive-v2
source successors reconstruct the original root after recursion, which forces
the ordinary non-tail worker path to decline. Their demand behavior still
requires actual adapter-entry markers and runtime qualification.
`prepare-error-diagnostic-v2.py` separately emulates
host shared-error visibility to check pre-entry, post-observer, and loop-poll
failure branches. The production host runtime exits immediately on err_post;
err_seen is device-only. Therefore these are explicit host diagnostics, not
production asynchronous cancellation or physical GPU tests. They terminate at
the failed adapter and claim no normal teardown or leak property.

The initial C-audit v1 rejected an existing hook only because generated segment
lines are indented. Its immutable v2 successor matches whitespace between the
same exact hook tokens. No compiler semantics changed for that method fix.

## Independent compiler-work checks

The occurrence insertion shortcut is sound under the actual collector's empty
seed and uniform singleton-marker invariant. A mask of zero means the same
complete U32 ID; generic insertion would reconstruct an identical path. No raw
or legacy index enters this internal collector. This claim does not extend to
arbitrary externally supplied index/marker helper arguments. The proposed
controls compare complete index values and ordered live/drop/share results, not
only membership, and separately observe actual insertion work.

The JS protection successor retains every original non-nc_ public root, all one
hundred wrappers, runtime bytes, and the identical 2,992-function dependency
closure. Native observer classification does not widen the excluded roots or
function set. This establishes unchanged generated nonnative closure bytes for
the compared images, not exhaustive language conformance.
