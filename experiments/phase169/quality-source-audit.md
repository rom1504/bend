new code therefore performs two scalar-permission scans, zero unshared scans

wrappers must still derive authority from the real request; mode2 must remain

initially. This removes one repeated permission/unshared derivation without a
global cache, hash trust or weakened verifier. Do not implement it before the
current full equality/timing gate establishes the need.
