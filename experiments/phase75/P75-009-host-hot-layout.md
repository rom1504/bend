# P75-009: hot host scheduler placement

Alignment alone recovers tree but not Array.map. A minimum bank of seven does not recover Array.map either. Test generic hot/64-byte alignment on every host scheduler function, which allows Clang to organize/align frequently executed blocks. First saved-C tree/Array.map then all twelve families only if beneficial. This is a layout diagnostic, not a benchmark-name production rule. Require full runtime and correctness gates before selecting.
