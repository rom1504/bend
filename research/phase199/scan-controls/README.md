# Fused scan controls

The measured direct worker accepts a state pointer, two-word result destination, 64-bit natural fuel, starting U32 index, owning array handle and incoming carry. The SysV registers are RDI, RSI, RDX, RCX, R8 and R9 in that order. On return it writes the original handle to the first word and the carry to the second, then returns status zero. At zero fuel the supplied carry passes through unchanged, including its high bits. Every positive iteration uses modular U32 addition. It stores the new carry XOR the unmasked U32 index and advances the index modulo 2³².

Under the verified array version, the guard checks that the entire high handle byte equals four and the low 40-bit word location lies at or above the compiled heap boundary. The full-byte check excludes the RFC bit and excludes uniform eight-byte tagged cells. The lower bound excludes static storage. An admitted handle identifies contiguous four-byte unsigned cells starting at the corpus base plus eight times its word location. The capacity is two raised to the exponent stored in the low five bits of the handle's auxiliary field. Addressing uses the index masked with capacity minus one. The fallback performs the original dynamic runtime operations, including RFC resolution, uniform element retention and sink, and the original result credits. [Existing x86 guard and fallback](../../../selfhost/src/back/x86/program.bend) · [Runtime array representation](../../../selfhost/src/runtime/qbe/runtime.c)

The source-level ownership argument also uses the verified serial loop body. It contains one read and one write through the same origin, and preserves the order of chunks, with no observer, callback or atomic inside the admitted loop. A raw handle by itself establishes the direct representation. Any outside alias observes the original completed array state.

The selector controls take the real normalized candidate worker captured from the prior checked compiler, exercise its checked selector, and compare every rejected structured body with the exact input. The ABI harness links the emitted program object and original serial runtime, uses linker wrapping to redirect process entry and observe helper calls, then enters a real initialized runtime. It tests unique allocated arrays, genuinely shared RFC handles, static packed cells and a separate bound descriptor with uniform word cells. Each trial compares the complete array, original owner, carried value, hidden result-buffer canaries and native status against an independent scalar recurrence. Starting indices cross the U32 boundary, capacities range from 1 through 256, and fuels include zero, short tails, exact laps and multiple laps.
