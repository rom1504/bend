# Qualified native89: final engine comparison

The new native B1 (`8bacae26…`) wins five of six fresh-process cases against
pinned upstream TypeScript on Bun. Map remains slower, especially across repeated
requests. The six-source cold geometric mean is **0.4924× upstream time**;
this is a limited workflow screen, not general compiler parity.

The native compiler uses its authenticated prepared Base. The reference worker
loads upstream source and prepares its own state. Process clocks include the
guarded compiler process, imports, preparation, request and output, but not the
outer Python authentication/launcher. They exclude Clang and generated-program
execution. These workflow boundaries are deliberately explicit.
