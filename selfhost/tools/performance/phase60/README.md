This is an unchanged-image comparison of genuine Phase58 B2 with pinned upstream
TypeScript. It compiles 23 distinct library inputs underlying the maintained 45
runtime points. It does not time execution of those generated programs.

- [Catalog](catalog.json): complete input, output, adapter and inherited runtime
  qualification mapping; generated by `make-catalog.py`.
- [Latency methods](latency/README.md): exact first/later windows, separate CPU
  and allocation profiles, private preparation, guards and replay commands.
- [Diagnostic analysis](analysis/README.md): stage partitions, profile ancestry,
  family classification and retained unknown samples.
- `analysis-clean.py`: all-source clean statistics and SVGs.
- `run-screen.py`: replay a frozen short-subset plan and record whole-command
  elapsed time without adding a second process guard.
- `accounting.py`: deduplicated target costs, separate runner costs and an
  explicit post-resumption cutoff.
- [Preservation/publication](publication/README.md): verify historical and
  installed artifacts, close writers, stream and verify the evidence archive.

Materialized methods and raw campaign files live in ignored `selfhost/build/phase60`;
the published archive preserves them. Use fresh output paths for replay. Exact
paths and identities intentionally describe this campaign's workspace and image;
a different compiler candidate requires new honest bindings, preparation and
qualification. Replaying the old image is not evidence about a new one.
