# Experimental commutative right-home selector

`commutative-select-v2.bend` plus `commutative-hook-v2.bend` adds a bounded physical-operand alternative to `x190_binary_direct`. Only U32/U64 add, multiply, AND, OR and XOR qualify; both operands must have register homes and the destination must equal the right home. The operation is emitted at the same statement position, with the original width. Other cases use the exact previous function body under the name `x194_cr_previous`. Setting `x194_cr_enabled()` False disables the alternative. V2 delays the left-home frame lookup until the toggle, right-home equality, width and operation checks pass; the original v1 files remain preserved.

The motivating real diagnostic is register-pressure-few: its baseline positive kernel loop has eleven `mov right,r11; mov left,destination; xor r11,destination` sequences. XOR can consume left directly when destination already contains right. This is a general physical-operand identity, not a source-name or benchmark match. No memory effect, read, definition or control edge moves; the same machine instruction consumes the same operand bits with operands commuted. No allocator or global SSA change is needed.

Flags: the hooked scalar ALU contract publishes a scalar value; subsequent ordinary branch selection establishes its own TEST/CMP. Existing fused compare/branch and predicate/select paths emit their CMP and consumer together, and do not insert unrelated scalar Bin operations between them. The whitelist excludes shifts, subtraction, division, comparisons and floating instructions. Add/logic defined arithmetic flags are also symmetric; IMUL's defined overflow/carry outcome is symmetric while its other flags remain undefined in both paths. This is a source audit of current consumers, not a general flags-liveness proof.

`commutative-controls.bend` checks ten exact one-instruction rendered forms and seven refusals. Its 50 emitted functions invoke the actual hooked `x185_physical_selected` with controlled physical homes: right alias, both aliases, left alias, distinct destination, and constant-left refusal/fallback. C checks eleven-by-eleven full-word edge inputs, U32 zero extension and unsigned wrapping, plus unchanged input memory. These controlled-home functions isolate selection; actual allocator coverage belongs to the separately compiled diagnostic. The direct and rendered object routes share the same typed selection and are not three independent emitters.
