# P160-002 — source work absent from the native image

The maintained QBE assembly includes8,265 declarations/3,085,157 bytes. Exact
root-main lexical closure produces5,007 declarations/1,697,879 bytes, retaining
all mapped runtime owners and complete selected law/definition pairs. This is
a build-input candidate from one maintained tree, not permission to delete
shared JS/C source or stop checking arbitrary user declarations.

First gate: independent upstream whole-book validation and zero unresolved
holes; emit only a small API to keep this admission cheap. Then a bounded native
build and ordinary complete compiler-output oracle can test whether removed
metadata changes behavior. Native self-reproduction is later qualification,
not justified merely by static reachability. Record actual cold costs and
whether the compiler still produces identical output on the original full source.

Potential benefit is less parsing/checking and construction of metadata for
this compiler image. It does not make retained algorithms faster by itself,
and1.7MB instead of3.1MB cannot plausibly explain the entire old seconds/minutes
gap. Preservation of runtime owners is evidence, not a semantic theorem.
