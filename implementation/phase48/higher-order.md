# Phase48 function-flow implementation status

The isolated H candidate adds `function-flow.bend` and
`function-flow-root.bend` to the frozen Phase47 array06 compiler. Its emitter
fallback and manifest are saved overlays; shared maintained emitter, JPure,
region and runtime files remain untouched. Root owns all builds and execution.

The first slice transports typed literal/known leading-lambda functions through
immutable lexical aliases, saturated helpers and singleton factory-prefix Lets.
Live scalar actuals receive administrative bindings exactly once, in source
order; copied binders are renamed above every original request ID. Erased
arguments require exact quantity and runtime-absence proof. Unknown functions,
matcher-selected factories and function escapes remain for complete admission
refusal. No source-program names select eligibility.

The root planner cheaply detects a real higher-order edge before scanning the
original book for fresh IDs. It installs one separately named normalized root in
an analysis-only view, runs complete JPure and worker admission, and emits through
the existing guarded private worker entry. Public fallback syntax, source identity
snapshots and original primitive scans use the original book. Removed factory and
helper dependencies remain in the original public fence. Private entry index is
explicitly zero; the isolated adapter uses baseline's two-argument worker API.

The independent v2 source/catalog tests six selected roots, noncommutative

later actual, and an unused but demanded failing actual. Returned, unknown and
matched function roots must remain generic. Controller v1 is preserved;

Bounds are 64 rewrites, 2048 nodes per copied function, 8192 input nodes,
32768 output nodes and depth128. Every child, including annotation/type metadata,

the complete candidate. Per-eligible-root whole-book fresh scans and repeated
normalization are compiler-cost risks to measure after semantic qualification.

The actual Morning blocker is a separate finite matcher-selected factory family:
String/List matching occurs when the factory is created, then each selected
lambda captures constructor fields. Recursive factory creation precedes a later
argument. Eta expansion across that match would change demand. The follow-on
design preserves factory-prefix evaluation as a private first-order closure-data
producer and application as an existing private matcher/direct graph, with
recursive factories retained as SCCs. Exact typed capture/arm facts must be
collected before constructing that extension. The first slice does not qualify
Morning or claim broad higher-order coverage.

A bounded saved-API factory-role diagnostic is now available for root execution,

matched-family extension separate from H02 qualification and to defer its larger
