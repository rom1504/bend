# Immediate ownership operations in direct x86

Earlier dynamic counts recorded 2,097,150 scalar retains per raytrace repetition. Map128 and record256 mixed thousands of scalar retains with real constructor and RFC operations. The integrated Phase199 raytrace object still calls the retain ABI twice in its direct pixel worker. The new Bend lowering recognizes existing verified scalar calls to `p111_rt_keep` and `p111_rt_sink`. Its unsigned test accepts only unsigned terms below 2⁵⁷. These are the complete high bytes zero and one. Retain then returns the original 64 bits and release returns zero. The remaining 254 high bytes execute the original runtime call, including RFC bytes 0x80 and 0x81, static storage, closures, constructors, arrays and the all-ones hole. The test reads no heap or descriptor data. [Prior dynamic evidence](selection.json) · [Checked lowering source](fast-ownership.bend)

Call liveness, frame outgoing arguments and the parallel-move plan remain those of a real call. The guard reads a local using R10, computes a possible return in RAX, allocates one function-local label and branches over the ordinary call for an immediate. R10, RAX and flags are reserved scratch and have no persistent homes. The slow arm reloads all original arguments using the existing snapshot-aware call builder, including when the input is already in a transient argument register. Both paths use the ordinary destination store. The label counter's last U32 value falls back to the unmodified call. The guard requires two exact typed arguments and a named U64 result. Prior scalar lowering handles every other statement.
