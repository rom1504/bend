# Observer emission proposal

Source-only lane. No production files, Phase69 evidence or installed images are
modified. Root owns every compiler/Clang/native run and integration decision.

Design: [observer-emission.md](../../../../../design/phase70/observer-emission.md).

`observer-emitter-v1.bend` is an **unparsed and untested proposal**, not installed
compiler code. It consumes the residual/descriptor contract negotiated with the
analysis lane. It deliberately accepts scalar NOp expressions but refuses
ordinary NFCall in v1; actual first Map/String candidates need no new scalar
callee admission theorem. It preserves existing primitive code, NC_Code,
NF_Worker envelope, constructor tests and simultaneous self-tail moves.

Only a plan accepted by origin/identity, layout, scope/type and boundedness
validation may reach this emitter. Its defensive checks detect absent names,
duplicate binders, wrong field counts, wrong residual tags and unsupported read
storage, but do not replace the semantic proof. Raw books cannot grant the
checked permission. Borrowed locals never enter ordinary ownership lowering.

`observer-adapter-v1.bend` prepares a second owned NF_Worker which retains the
original roots, calls the observer, and lowers the result wrapper through the
ordinary native implementation. A tiny scheduler hook selects it only after
the existing entry check and preserves the exact prior body under fallback.
Separate private functions avoid label collisions in the scheduler switch.
The adapter checks root indices, wrapper leaves/shells and a 64-ID fresh span.
The plan supplies the next `nc_id` counter, never an absolute Var ID. A bound of
294967231 preserves the reserved descending temporary range throughout the
span; the collision scan includes every formal parameter, result and wrapper.

Root must skip the entire observer planning/worker/adapter pipeline when raw
mode passes False; a C macro alone is not authority. Both files remain unparsed
and untested. Analysis must additionally validate scalar kinds, descriptor
owners, compatible loop slots and canonical literal atoms. No candidate is
ready for production solely because these source files exist.

`query-plans-v1.mjs` is a source-only controller awaiting root execution. It
appends a serializer to the exact checked B1 bytes, intercepts the checked
native entry before C generation, and invokes the actual compiled Bend
`no_observer_plan` with False and True for each requested canonical definition.
It serializes the real plan/schema/analysis records and KTerms; no host origin
analysis or reference-plan substitution is involved. True is a diagnostic
analysis request after checking, not a production foreign/bang certificate.
The original API, source graph, runtime, actual foreign inputs and controller
are hashed; progress and each result are persisted to a fresh Phase70 directory.
Root owns execution under the usual resource guard, for example:

```sh
node query-plans-v1.mjs CHECKED_API INPUT_BEND FRESH_PHASE70_OUT Map.bit.go String.cmp
node query-plans-v1.mjs CHECKED_API V4_FIXTURE_BEND FRESH_PHASE70_OUT strand:probe strand:compare
```

The controller refuses a raw native entry and an accepted False-permission
plan. Structural refusal with True is recorded as a valid query outcome.
Neither `complete: true` nor an accepted plan qualifies generated C, runtime
behavior, the production admission boundary or performance.

`integration-v1.patch` is a concrete, unparsed production proposal against the
five file hashes in `integration-v1.derivation.json`. It also requires copying
`observer-adapter-v1.bend` and `observer-integration-v1.bend` to their recorded
production destinations. The analysis/layout/literal/plan modules are the
separately qualified analysis lane; this patch does not replace them. No patch
has been applied by this lane.

The patch passes an explicit Bool through native compilation and all final
worker stages. `nc_compile` supplies False; `nc_compile_checked` supplies the
existing audited `packed` permission. The already computed live and bang lists
filter candidate names once. Actual plan creation happens after ordinary and
product workers have finished retry/admission and after ordinary scheduler
wrapping. A single direct-entry index prevents generating unused routes.
The two new workers are retained only when both pass existing admission;
otherwise the complete prior route is returned. Private names are checked
against the book and all ordinary, product and previously accepted observer
workers. Those scans occur only for successful plans, not every live function.

Root must first qualify actual Bend plans, then review/apply these source
changes, then run checked source/emission, runtime, permission/fallback and
performance gates. Raw False performs no observer analysis, entry-index
construction, worker creation or adapter wrapping. The new C macro is merely a
routing guard. Rejected optional plans never enter ordinary retry and cannot
alter ordinary candidate admission.
