# What the profiler changes about the next optimization cycle

The next cycle should optimize a measured semantic computation, with the small
name-search proxy as its first execution test. A new broad compiler profiler or
universal IR is not a prerequisite. Full compiler acquisition remains a promotion
cost after a small experiment demonstrates useful work removal.

| Priority | Experiment | Cheapest decisive evidence | What would falsify it? |
|---|---|---|---|
| 1 | Qualify the transport admission repair | Existing49 finite checks and exact-QBE capability proof, then one justified repaired-source native checkpoint | Any new output/ownership failure, or failure to reproduce the expected transport capability in the adopted source |
| 2 | Admit the real equality walker as a scalar-result borrowed observer | Actual five-function proxy, unchanged independent answers; generated loop has borrowed reads instead of takes; event counts and clean runtime both improve | The archived observer cannot legally admit this shape, loses root lifetime/alias safety, or removes calls without improving runtime |
| 3 | Eliminate guaranteed-unused late candidate preparation | Byte-identical Map QBE; prepare/candidate/lowering entry counts stop repeating; complete request cost falls | The work is required by a dependency, output changes, or complete request cost stays neutral |
| 4 | Separate lookup algorithm from comparison ownership | Two-factor list/index and owning/borrowed comparison; include index construction and repeated queries | An index wins only when its preparation cost is omitted, or equality gains do not transfer to real searches |
| 5 | Preserve existing constructor provenance | Prepared metadata supplies the parent ADT provenance with exact duplicate precedence; emitted QBE remains identical | Another provenance rule or cached-book case requires the original scan |

These are experimental priorities, not promised speedups. The proxy's14.65×
gap is not an estimate of full-compiler acceleration. Its54.20% destruction/
reclamation bucket is also not the entire cost of ownership: takes, keeps,
sinks, field transport and ordinary comparisons remain. Conversely, entry
counts include immediate/shared-value checks, not just actual object frees.

## Preserve the facts that make the borrowed experiment legal

Use the actual checked Bool result, not an arbitrary U64/Term that could carry
an owned pointer. Retain the roots through the complete private traversal.
Keep early mismatch, aliases, empty/shared/static values, Unicode, fallback
and explicit-stack obligations. The existing scalar-observer V2 is an
unselected bounded prototype; its earlier checks do not establish admission
of this particular compiler walker or full-image safety.

First require transfer to an unrelated list/text observer. Then try a genuine
compiler request. Declaration lookup returning an owned KDef is a later step:
borrowing its traversal may still require a retain at the selected result's
escape boundary. Scalar-return legality must not be generalized to that case
without a separate ownership argument.

Any new helper must also satisfy the independent live-register-bank contract.
Porting only the observer and forgetting its helper admission could recreate
the global regression just measured. A small shared helper-effect description
may eventually remove this duplicated knowledge, but must preserve the final
verifier's independent obligations. Do not replace verified admission with a
blanket helper-name allowance.

## Keep the research loop inexpensive

The first proxy calibration executes in0.38s; the512-repeat pair gives clean
QBE/upstream observations in about1.6s total. A complete profiler recipe also
includes repetitions, diagnostic samples and counters: the recorded campaign
takes about31s. Its checked emission and machine build take about9s, excluding
already-acquired compiler tooling. This is a practical first loop before a
roughly7.5-minute full-source request or14-minute hosted image acquisition.

Use clean timing for acceptance; counters establish work removed; samples
rank remaining costs. The 8/13ms periods work here. Faster2/3ms sampling caused
overruns and provided no accepted quantitative improvement. Reuse recorded
samples for new symbolization, owner joins and CPU-window analysis.

Keep source-to-QBE request time, generated-program runtime, compiler-image
acquisition, machine build and complete validated experiment cost separate.
Shared-name kernels deliberately amplify one hotspot. Full-source timelines
show other substantial computations, including provenance scans, verifier
lookups and final text construction. A proxy win must earn its larger test;
neither repeated self-compilation nor a sequence of commits demonstrates
recursive research acceleration.
