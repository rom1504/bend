# Phase205 native x86 fixed-work experiment

Freeze the Phase200 native45 weights and mature-C products. Use the Phase204 experimental direct-object source as the producer baseline. Recheck sources and the final lowered programs. The first gate reconstructs excess seconds and separates source ceilings from actual compiler gains.

Test whether the compiler can distribute a total, concatenation-preserving string transformation over repetition. The final result must remain observable and complete. Start with the checked split/join equations and the previously checked sequence identity. Identify functions by checked bodies, types and binder relationships. Preserve evaluation count and ordering for dynamic arguments. Reject unknown operations and observed intermediate bindings. Compare an unrelated packet workload and adverse inputs against independent expected output. Run a separate bounded experiment on constant-template unfolding for the higher-weight lexer family.

Use single-core guarded runs and the existing mature-C oracle. Measure changed objects, fixed batch seconds, per-workload elapsed time and compiler costs. Run all 45 only after an automatic optimization has changed a real program and passed focused execution. No installed-image promotion is planned.
