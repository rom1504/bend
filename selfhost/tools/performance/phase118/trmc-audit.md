## Why reuse cannot be inferred later

Runtime `ctr_take` at `phase117/runtime01/runtime.c:1029` returns a reusable cell
only after ownership transfer. An unshared dynamic constructor returns its
location; an RFC count-one owner releases its RFC and returns its underlying
location; a shared owner retains extracted fields, decrements its reference and
returns zero. A static constructor can return a location below `HEAP_OFF`.

`p111_rt_take` at line3900 immediately passes this result to `spare_free`.
Its public result is a field count. Once that call has executed, a later QBE
optimization cannot recover a unique-cell credit from the input tag or location.
The same physical address may already belong to the allocator or another node.

The mature reuse contract is small and reusable in a future helper: retain a
returned cell only when `cell >= HEAP_OFF`; at most one credit; free an older
credit before replacing it; consume it only for the same `Cls`; free unused
credit before publishing a completed result. Never reuse shared/static storage.
The first prototype intentionally tests destination passing without reuse, so
its value and additional runtime overhead can be measured independently.

## Isolated structured prototype

Files: `trmc.bend`, `trmc-originals.bend`, optional `trmc-controls.bend`.
The originals file contains four selected lowering bodies renamed for explicit
delegation. No C expression strings or native instruction text are generated by
this module. It emits existing `P113DStmt`/`N111Stmt` constructors only.

Overrides:

1. `p113pl_candidates`: retry only an ordinary boxed candidate rejected for
   `product non-tail self call`, arity1–8 and compact body at most512 nodes.
2. `p113pl_ctor`: reuse `ntr_eligible` and `ntr_sequence` when the private target
   marker is active. The sequence evaluates all prefix fields and all recursive
   arguments in their original left-to-right order before extending a node.
3. `p113pl_live`: consume only the private `NTRCons` marker into structured
   allocation/link operations and `P113DAgain`.
4. `p113pl_output`/`done`/`call_result`: finish terminal results, or preserve the
   destination across ordinary self-tail calls. Other expressions delegate to
   selected lowering unchanged.
5. `p113e_scalar_safe`/`stmt`: add two exact imports to the **direct** verifier.
   The generic segment import list and generic original program are unchanged.

The admitted worker has original full-word formals plus `root` and `parent`,
initialized to zero by a public wrapper. These two hidden values are not inserted
into source liveness environments: `root` owns the unpublished result, while
`parent` is a private raw cursor into it. Every backedge carries both. Every
terminal result is boxed if necessary, fills the outstanding destination and
returns the root. The wrapper retains the original public arity/result ABI.
All ordinary calls must still be admitted by the existing acyclic direct call
planner; native recursive SCCs are not introduced. Private self recursion is
represented solely by `Again` and parallel moves.

Runtime adapter implemented separately by the parent in `runtime-dest.c`:

```text
extend(state, parent, constructorId, prefixBuffer, prefixCount) -> rawNode
finish(state, root, parent, terminalResult) -> completedResult
```

`extend` allocates a normal boxed constructor, seals evaluated prefix values,
installs `TERM_HOLE` in its last field, fills/seals the preceding parent's hole,
and returns the raw new node. The compiler sets root only on the first step.
`finish` either returns its terminal result directly or seals it into the final
hole and returns root. It derives each parent's field count from its own CID,
so alternating constructor layouts remain valid. The runtime guards dynamic raw
CTR representation, arity2–8, exact last-field hole, and constructor identity.

This matches QBE's current **always-seal** constructor policy. C's cold-parent
exception is not imported: that is a separate representation certificate and
would otherwise silently change the baseline. A raw cursor may point at a node
whose owning edge has become RFC-wrapped; the cursor itself neither retains nor
drops that node, and the unpublished root protects its lifetime.

## Correctness boundaries and review requirements

* Parent API must independently verify its original lowered program. The
  candidate verifies the derived direct program using the additive import
  contracts. Do not describe new imports as accepted by the old verifier.
* Exact helper signatures, constructor arity, definite assignment, stack-buffer
  bounds, non-state buffer pointers and public signatures are machine-checked.
  The source-to-IR producer and private destination invariant are additional
  trusted lowering code, not a general ownership proof supplied by this verifier.
* Only final recursive field,2–8-field ordinary constructors, direct unbanged
  saturated self reference, no self reference in prefix or recursive actuals.
  Nonfinal recursion, multiple recursive children, mutual recursion, partial
  application and source dynamic calls retain generic fallback.
* Existing liveness partition/keep operations run over the sequenced source
  operands. Shared prefix fields and shared suffixes are not treated as unique.
  Source code never receives an incomplete root or private cursor.
* Allocation moves before recursive evaluation, as in mature TRMC. Source
  computations keep their order; allocation/OOM timing is not claimed identical.
  Existing runtime error posting is retained. `finish` closes the pending hole
  even on a compiler-generated failure-return suffix; no failure-input campaign
  is required or proposed.
* Stack is bounded by admitted acyclic calls and fixed local scratch. Input size
  no longer adds reconstruction frames for transformed constructor-tail edges.
* Empty/base-only execution calls `finish(0,0,value)`; ordinary self-tail steps
  preserve root/parent; mixed arities use each pending parent's CID; argument
  moves remain simultaneous; typed or boxed prefix fields stay full Terms.

## Fast falsification / ordinary correctness controls

The optional `p118t_controls()` export checks source admission/refusal, structured
backedge arity, terminal completion and no raw-pointer formals. These are finite
analysis tests, not malformed target execution. Parent should first confirm
`p37.list`, `dbl`, and `String.append` workers are emitted and reconstruction
frames disappear before considering broad timing.

Reuse qualified ordinary fixtures rather than adding large new campaigns:

* `phase102/fusion/fixtures-v3/construction.bend`: static/shared suffixes, live
  source aliases,30,000-cell stack safety, renamed user constructors, non-scalar
  prefixes, duplicate owned fields, argument swaps and full text observations.
* `phase102/trmc-cold/controls/mixed-construction.bend`: alternating arity2/4
  destinations and shared String terminal children.
* `phase102/fusion/fixtures-v5/refusals.bend`: nonfinal recursion, two recursive
  children and mutually recursive functions retain ordinary lowering.
* Original list128/list512 and map128/map512 fixtures provide transfer and scale
  evidence. Compare unchanged runtime policy and source to Phase117, then add
  reuse only as a separate variant if destination passing establishes value.

No speed gain is claimed by this source audit. An allocation-only improvement
would justify measuring consumed-cell reuse next; a flat result would direct
attention to constructor allocation/sealing and borrowed observation rather than
more continuation mechanics.
