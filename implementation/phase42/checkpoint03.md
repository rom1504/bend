It is a short three-round screen, not final whole-corpus acceptance. The layout
uses one fresh tagged object with direct fields inside an audited scalar-owned
graph. Original public workers retain byte-identical array representations.
Stack machines remain; native recursion and Number substitutions were rejected.

and two depth30000 cases. The renamed fixture passes40 oracles, two positive

admits. The original selected root carries checked annotations; only its

audit. All helper identities, guards and emitted bodies remain checked.
