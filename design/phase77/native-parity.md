One heavy CPU3 process tree; 2 GiB aggregate RSS, 4 GiB free-memory floor, Node
1 GiB heap/4 MiB stack. Checked B1 build is about33s; use focused controls and
three C sources before broad gates. Keep old/new image and tool hashes, fresh
output directories and every failed attempt. No quota claim from wall-clock time.

The first practical default-stage gain is about31% by existing measured B2/B1
ratios. Algorithmic parity still needs about48% less B2 request time. A retained
plan should show at least20% request reduction or convincingly remove a dominant
component before an 8–16h expansion. Library name overlap alone is not proof of
reusability. Do not multiply overlapping gains. Temporary program slowdowns must
be quantified and linked to exact artifacts, never hidden in an aggregate.

The source remains a Bend compiler implemented in Bend. JS host changes are
packaging, transport and benchmarking, not implementations of compiler algorithms.
