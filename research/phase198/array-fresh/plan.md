# Uniform fresh array with one observable scalar

A uniquely owned word array starts with the same seed in all physical cells. When a loop starts at logical index zero, advances one index on each iteration, and runs at most the capacity, each load sees the seed even after previous stores. If it reads only that cell, performs only pure total word arithmetic, writes only the same cell, and returns an unobserved array alongside an observed scalar, the scalar recurrence can be executed without the array. For a carry initialized to zero that adds the loaded word, its result is n × seed modulo 2³². A nonzero start requires a separate full-width no-wrap and extent proof. Strictly increasing indices alone do not establish distinct physical cells under the runtime's index masking. Aliases, escapes, calls that can observe the array, relevant effects or failure behavior and an observable final array require refusal or original evaluation.

The native45 incumbent's actual p113d product loop in local-fold is 445 bytes (116 disassembled instructions). Its hot backedge masks the logical U32 index at 0x3e83, reads (%rdx,%r8,4) at 0x3e86, adds the previous carry, xors the integer index, and writes (%rdx,%r8,4) at 0x3e98. The source capacity is 128. The primary point n=4096 and high variation n=8192 must run the original computation. The low variation n=128 is eligible. Its zero seed alone is a weak correctness test, so the proposed screen includes nonzero seeds, word wrap and both sides of the boundary. At n=130 and seed=0 the original result is one while an unconditional multiplication produces zero. At n=129, cell zero coincidentally still contains the original seed on its first revisit, so n=129 alone would miss the bug.

The unrelated complete-generic-row32 program emits a 1,380-byte p113d product row worker. The current-row read at 0x74d9 uses RDX as its base; the write at 0x7533 uses the same base and the next logical column. The next iteration consumes that write. The earlier candidate condition fails both the unique fresh-read test and the scalar-only observation test: the top-level serializer emits every one of the four arrays. The edit-distance parent has the same cell recurrence and swaps rows for the next iteration, making current contents observable there too. A row's left-neighbor value could be forwarded without deleting stores under separate dependence and masking proofs, but that is a different transformation.

The primary and high variation share the same capped array and cannot benefit from this theorem. Broad automatic recognition would need a second workload exercising the rule or a broader useful theorem. The ceiling measures potential under normal successful allocation. It does not certify skipping a potentially observable failed allocation or treating a heap budget as unbounded.
