# P78-008: lazy observer admission

The checked compiler16 retains erased source bodies but its short exact-C screen
does not show a clear improvement. Observer routing remains expensive. Bend's
Boolean operators evaluate both operands: `nol_scalar_specs` currently computes
scalar layout for every definition, including functions, and helper expansion
decodes intrinsic names for ordinary functions. Replace these pure, bounded
Boolean filters with conditional control flow. This applies uniformly to schemas
and symbolic helper calls, without naming a benchmark or special library helper.

Require a checked build, exact compiler11 C on the three-source screen, then
broader raw and observer execution controls if selected. No cached library work
or metric-boundary change. Reject the change if it adds complexity without a
measurable paired gain. Retain compiler16 as the ablation parent.
