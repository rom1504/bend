# P159-001 — physical cost of historical self-emission

Hypothesis: a compact compiler pipeline avoids enough representation/transport
work to explain its short execution without a uniformly superior runtime.
Measure the unmodified9c seed using the existing general sampler, including
checking separately. Exact emitted C and independent checker diagnostics are
mandatory. Samples identify exclusive physical locations, not logical inclusive
stage times. Use more than one sampling period to detect unstable rankings.
Do not infer causal savings from source size or static call counts.
