# Reverse-order local branch fixups

The production direct ELF builder stores text in descending address order. Its existing finish reverses the full text, walks forward as far as the last local branch placeholder, and reverses that constructed prefix again. This candidate checks and reverses the much shorter patch list, then consumes the descending bytes directly into the finished forward text. The loop drains the distance to the next patch without unpacking its relocation for every byte.

The frozen Phase198 compiler source has SHA-256 `72061fa57c75993b59eaf42e18c6b923eebea640c352d0f7b9cd1d27ce7be91d`. Its native reproduction took 372.659 s to emit the 32,448,072-byte object `b3a382d4600dcbb5e5fa797dffed49b25972962445911bd82fc69eb36de4a65a`. The object has 20,972,577 `.text` bytes. A local five-byte `jmp` beginning at `0x1400272` has in-place nonzero displacement `20 00 00 00`; the ELF does not retain a relocation at that offset. Thus the old path constructs and reverses at least 20,972,151 prefix bytes. Descending emission saves at least 41,944,302 logical byte-list visits before charging its short patch-plan pass and per-word encoding. This count measures the actual emitted cold object. It does not establish a percentage of wall time. The retained Phase193 same-request sample concerned a smaller program and primarily attributed cost to string and ownership work; it cannot price this traversal.

The production cursor starts with an empty builder, and its byte append maintains `textSize == length(text)`. Only the cursor’s final call is redirected. The diagnostic finish still accepts manually assembled raw builds. An ascending plan validates bounds, overlap and order before any patching. If this preflight refuses, the existing forward patcher determines the same first diagnostic. On an admitted plan, all structural positions are valid and every placeholder must independently contain four zero bytes. A malformed placeholder has the same diagnostic regardless of which one is encountered first. Ordinary text bytes and all non-text sections retain their values. External calls, relocation indices and ELF metadata stay with the existing writer.
