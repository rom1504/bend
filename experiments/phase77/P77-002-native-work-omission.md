# P77-002: compact scalar patterns and omit redundant host bodies

Hypothesis: compose Phase76 compiler10 scalar-pattern/reconstruction rules with
Phase75 compiler09 host-body omission, retaining newer safe admission, constructor
index and compact occurrence sets. Private host-plan permission is attached only
to checked requests without bang roots; raw/device paths retain generic lowering.
Expected compiler gain is substantial but overlapping, not the product of earlier
percentages. Correct temporary runtime regressions are permitted and measured.

First build and run the three-source compilation/semantic loop. Reject on semantic
mismatch, not C byte changes. Then genuine B2 and paired requests, twelve-family
runtime, raw/malformed cases, threading and selected native/frontend gates. Keep
all old evidence immutable. No benchmark names appear in compiler rules.

## Decision

Accepted under explicit user permission for runtime regressions. Combined B1/B2 take30.7%/23.1% less cold request time. Twelve-family runtime costs1.8% overall, expression14.25%, Array.map5.04%. All selected semantic/self-hosting gates pass. See the [completed report](../../implementation/phase77/README.md).
