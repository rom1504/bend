# P81-001: residual costs after rejected representation prototypes

Hypothesis: the residual cold C-request deficit has enough fixed metadata/text
work and repeated native representation work to justify a coordinated redesign,
while B1 has a separate generated-control-flow cost.

Correctness:77 exact-C requests, unchanged production. Measurement:54 clean
requests,15 CPU profiles,3 sampled allocation profiles,5 diagnostic region
requests; five sources, one CPU, strict memory guard. No general-language or
new runtime-performance claim. Decision: investigation complete; recommend
ranked fixed-work and per-function representation experiments. No promotion.
