# Phase79 fast discriminator

Build a checked candidate with `development.json` through Phase46 `job.py`.
`prepare-screen.py ATTEMPT OUT` freezes Phase78 B1 and candidate ordinary/library
roles in separate projects plus pinned TypeScript. Run `run.py --plan OUT/plan.json
--group prepare`, then `--group clean`; all target execution is serial and guarded.
Fresh request timing includes product read, checksum, decode and world admission.
Preparation is separate and must produce the optional artifact; a missing product
fails the experiment. Complete C must match the independently executed Phase78
oracle, with mismatches retained. No default release is changed by this experiment.

The prototype transport extends the existing Base arena, header binding and
annotation admission rather than introducing another cache protocol. Product
construction, signature checks and lowering remain Bend code.

The actual screen03/screen04 and profile03/heldout04 plans remain immutable.
`prepare-diagnostic.py PARENT NEW_OUT [--heldout HELDOUT_PLAN]` packages the
interactive derivations for future use; it was written after those runs and adds
its own pin. Profile/held-out workers explicitly bind the original preparation
plan instead of silently relaxing that identity check.

Decision: both prototypes were rejected. Restore their source from the frozen
snapshots or experiment patch in an isolated checkout; current production is
Phase78. Do not apply the experiment by overwriting the installed release.
